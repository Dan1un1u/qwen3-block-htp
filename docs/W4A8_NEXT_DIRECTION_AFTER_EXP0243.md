# EXP0243 后的方向：保留首 token 隔离成果，定位后续 A8 损失

状态：讨论提案，未授权新实验。EXP0243 软件证据有效、精度验收失败；source/evidence 以 index.yaml 和 PROJECT_STATUS.yaml 的 closure 为准。不得重跑已完成五前缀筛选或在本轮最终集调参。

1. 固定 C64 权重与 EOS+MSE 已有控制，首先做逐边界、逐层段 A8 消融。重点覆盖后段 SwiGLU、投影输出、残差及 head input，同时保留 attention/KV 对照，不能凭最大值大小直接宣布主因。A16 恢复仅是软件因果对照，不部署混合精度。使用独立开发与新的最终复核协议；PPL 主指标，短答辅助。
2. 若 MLP 中间值占主导，优先局部 R4 或可等价折叠的温和通道缩放；若 residual 占主导，再检验 residual R1。R4-only 在精确算术下不会改变原坐标 Down 输出。涉及旋转/缩放需由原始权重重新折叠并重新做 per-channel W4，设置匹配 W4A16 控制，不能直接复用旧旋转/LPBQ 权重。当前尚未启动这些改动，也不直接跳到学习矩阵或大范围 QAT。
3. 前缀策略还有真实请求条件的代价：EOS 使 F16 PPL +8.04%、C64 A16 +6.54%。优先验证利用实际已有 prompt/header 的离线 KV 是否可避免额外 EOS，统一请求模板、正文评分与同前缀 teacher；不得用本轮最终集继续筛选。长上下文、多轮聊天和自由生成未由短 PPL 复核替代。
4. 数值稳定性需持续验证：相同调用形状下 U8/浮点 QDQ cache 精确，但批量/逐 token 的 FP16 舍入经 A8 阈值可显著放大。设备阶段必须独立验证 DSP/HMX 的整数、缩放、非线性及 cache 语义，不以软件 PPL 宣称硬件等价。
5. 软件质量足够再单独登记硬件可行性。保持原生 HMX W4、per-channel 权重、既有物理约束，并计入前缀初始化/拷贝/额外 attention。prefill 或 decode 任一稳定慢于对照超过10%即暂停全模测试并讨论。当前无新设备测量，无 baseline promotion。
