# EXP0249 后续方向

本轮固定 C64 per-channel W4、既有 A8/R3 参数，补齐实际整数 attention 的软件参考，并完成12个冻结配置的独立256文档/4096目标 PPL。旧4组开发集逐token复现、设备抓取逐字节与随机算术检查通过。

主要失效首先发生在 QK score conversion：固定F3绝对窗口先饱和，再求行最大值；先舍入后乘 multiplier 又使有效网格变粗。R3在较完整的分数表示下仍有收益，但理想旋转保留 QK，本身不能消除这个输出窗口问题。截断与粗网格对 PPL 的各自贡献仍需单独消融，不能依据频率统计直接分配因果份额。

建议 EXP0250 先做 score clipping/rounding 的分离诊断。优先验证在原始HMX U8分数上求行最大值，以至少16位差值乘 multiplier 后进入指数编码，避开第二次U8截断；255*18=4590可在16位中保存，这只是算术范围证明，尚无速度结果。第11层原始载体无端点值而二次转换使77%至79%的行最大值截断，支持先试这一局部改法。只有第一阶段载体消融仍显示必要时再扩大HMX输出表示。先验证软件PPL恢复，再核实硬件实现与代价。之后重新评估整数指数/SOLE精度、K/V/AV载体剩余损失，最后复测无昂贵舍入补偿的朴素dense HMX R3。保持原生HMX W4线性层、无FWHT/蝶形、其他recipe冻结、单层Host wall任一阶段稳定慢超过10%停下讨论。不得直接进入全模设备或宣称当前软件PPL就是设备PPL。

无新设备运行、无速度报告、无模型参数变更、无基线提升。当前实验结束，active none、next250待讨论。EXP0248实验层0构建缓存/ABI114仍在，不是完整模型部署。新算法实施待用户讨论确认；已完成证据以 EXP0249-RESULTS 与 ledger 为准。
