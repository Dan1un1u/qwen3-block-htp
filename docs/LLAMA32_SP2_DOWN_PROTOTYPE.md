# L32-0008：Llama SP2 Down 原生 W4 原型

**结论：原生 HMX W4 可以精确执行这个 SP2 码本的 Down 整数点积，无需展开成 S8。** 本次为局部原型，不是完整 block 或全模型验收。

SP2 码本固定为 241 个值（零、带符号单幂、两个不同幂之和，指数 0～14），可用 8 位索引；最大整数幅值24576。尺度来自已冻结的 Llama middle 校准范围，与评测分开。原型输入为预先重构的 signed16 值，设备将其拆成低 U8 与高 U8；尚未融合 SwiGLU 生产。

保持原有 per-output-channel signed[-7,7] W4 与 FP32 权重尺度。四次不饱和 retain 转换按24/16/8/0指数读取累加器四字节，无额外舍入；HVX 重构并按 L+256H−32768*sum(W) 合并。decode 两分量复用64行tile；prefill 两遍计算。返回精确 int32 点积，最终 alpha*beta、输出重定标及残差尚未接入。

最终20个硬件功能用例、934,912个输出均与独立整数参考完全一致；其中 Llama 第0/7/15层、prefill/decode 的 SP2 输出共399,360个。包含K32/K8192、正负极值、零、进位、抵消和两种分量调度；CPU模拟器另验证22,049个累加器。
