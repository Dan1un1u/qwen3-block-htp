## 开关覆盖与诊断限制

QKV bit1 仅控制 Qwen 风格 QKV ring；本轮 Llama 的 w4u8_qkv_ring_dispatch_count 全部为0，实际 Llama 路径未经过该开关。因此 QKV 臂是无操作对照，不是“Llama 的 QKV 重叠无收益”的实验证据。全数保留其测量波动，因果结论标 N/A。当前 EPILOGUE bit12 改变 prefill 输出重叠，decode 原本 inline；LOOKAHEAD bit16 改变 decode O→Gate 预取，prefill不经过该路径。主文聚焦实际覆盖的机制。

trace 单独构建、独立数值检查；FARF 日志截断时完整时间线/利用率标 N/A。正式计时均 trace=OFF。首次局部 replay 命令行 repeat10 被旧入口忽略，仅实际执行1次，该测量保留但不计入正式结果；修复后通过明确 replay 环境入口运行十次，三层逐次重置所有层 KV，会话与输出均核对。
