# Direction after EXP0253

Do not assume replacing log2 attention with FlashAttention alone can pass model acceptance. Even removal of every internal attention quantization boundary leaves the conditional model outside the unchanged PPL gate. Keep floating attention as a diagnostic control; discuss before spending effort on a whole native replacement. Next useful attribution would freeze this floating core and separately restore only U8 Q/K, U8 V, and output-context QDQ in software, then test their union if needed. This isolates remaining attention boundary error from already identified downstream O/residual/MLP errors. These are diagnostic restorations, not proposed mixed-precision deployment. If restoring all attention boundaries still misses acceptance, prioritize those downstream boundaries. No new arms or changes to weights/other recipes are authorized automatically by this recommendation. Native R3 whole-layer numerical failure from EXP0252 remains unresolved and is separate from this software PPL gate.
