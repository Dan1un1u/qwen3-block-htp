# EXP0246 后续方向

在线稠密R3的软件收益已通过预先冻结的推进规则：L0、ALL相对原始A8及匹配重校准的PPL比值95%上界均低于1。按PC061继续单独登记EXP0247的dense-HMX单层实现与M64/M1真实Host wall门槛。

先固定设备FP16矩阵表示、归一化、舍入及U8量化的独立oracle，验证矩阵乘布局、Q/K同步变换、缓存前缀/追加与无重复旋转。保留原生HMX W4权重读取，不做W4到S8展开，不使用蝶形/FWHT。软件F32稠密矩阵乘不能替代设备数值检查。

真实单层比较必须包含在线矩阵乘、归一化、打包、同步和缓存成本，保持8MiB VTCM、零计时中间DDR/spill和每步一次FastRPC。五轮short、十轮配对formal，prefill或decode任一稳定Host wall慢超过10%即暂停并讨论，不进入全模型。不能将单层或GPU耗时外推成E2E token/s。

本轮未达到最终模型精度验收；其它recipe及基线仍冻结。设备性能关卡前不追加旋转训练或同时改变其它A8边界。
