Status: discussion proposal, not an approved experiment, numeric gate or baseline promotion. User has approved only PPL-primary reporting (PC049). Source remains clean on EXP0228; active none; next229.

A0 independent validation NLL3.54111245 is slightly lower than A3.54849745 despite qbh A being lower. Do not choose/promote only by the repeatedly inspected512-target diagnostic.

Proposed bounded W4A16 acceptance: freeze models A0 and A, no new optimization. Add a new independent fixed bilingual evaluation set with8192-16384 scored target tokens, multiple documents and encyclopedia/news-like domains, disjoint from calibration/training/checkpoint-selection validation. Use identical supported contexts/tokenization/masks and actual DSP F16/A0/A execution. Cache an original BF16 teacher as an additional named reference. Aggregate NLL before exponentiating; report overall and each language/domain delta, plus document-level paired uncertainty. A routine subset of2048 targets can serve future fast regression; full evaluation is for milestones. Standard English WikiText-2/C4 methodology is an optional reference (https://github.com/IST-DASLab/gptq); a fixed subset/short-context adaptation must be labeled as such, not a published full benchmark. Long-context acceptance would be separate.

Suggested engineering gates for discussion only: overall PPL ratio to same-scope FP16 <=1.05, each language/domain <=1.10, no nonfinite results or unexplained repeat discrepancies. These are project-specific tradeoffs, not academic standards and not yet measured/approved. If uncertainty crosses a boundary, add independent evidence rather than tuning on test outputs. Prefer the simpler A0 if A has no stable independent PPL advantage; retain A as the current qbh-PPL-best candidate. A single24-question short-task difference is no longer a model-quality veto.

After acceptance, suggested focus is W4U8 quality rather than more W4F16 rotation optimization. Freeze the accepted W4F16 reference and use byte-identical W4 integer weights/scales in W4U8 for initial activation-path attribution. The old W4U8 snapshot still uses older quantization and has failed repeated quality-statistic determinism; its huge PPL is provisional and is not proof of the intrinsic W4A8 limit. First recheck/repair reproducibility and software/device math agreement; next localize input/output activation quantization, zero-point correction, saturation, attention/KV effects and calibration mismatch with paired teacher-forced inputs. Any weight-dependent sums or activation calibration must be derived correctly for the new package, never copy stale qparams. Only then evaluate activation scale/clipping/granularity interventions under declared hardware cost. A W8A8 control, scaling transforms, learned rotations or mixed precision require separate explicit scope and are not automatic additions.
