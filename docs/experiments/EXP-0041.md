# EXP-0041 — HVX W4U8 common operators

## Approval and source

Approved by the user on 2026-08-29 to continue from the accepted EXP-0040
streaming W4U8 block and implement the remaining common operators with HVX,
using the existing FP16/HVX suite as the structural reference. The exact
source parent is `4a07e11536171371b918dd0167c7f493cc9b2ab2`.
EXP-0040 is an accepted W4U8 provisional parent; this decision does not replace
the user-selected `W4F16-EXP0038-NORMS` baseline.

## Current boundary and hypothesis

EXP-0040 reduced the complete W4U8 MLP ledger from roughly 1.5 million ticks
to about 63 thousand ticks, but left the original scalar U8 common-operator
path unchanged. At repeat one, Input RMSNorm, Q/K Norm plus RoPE, the two
residual paths and Post-Attention RMSNorm account for roughly 2.54 million of
the remaining 3.33 million block ticks. These operators are therefore a more
important target than further MLP tuning.

The current W4U8 block still expands Q, K and V to FP16 before QK, Softmax and
AV. Consequently, the current Softmax has FP16 scores and probabilities even
though the surrounding projection boundaries are U8. Replacing that Softmax
with a true U8-input/U8-output algorithm would also require a declared score
qparam and coordinated integer QK and AV contracts. EXP-0041 does not hide
that larger Attention change inside a common-operator port.

## Fixed contract

- The Execution Unit remains the real Qwen3-1.7B layer-14 complete block at
  `M=64`, one FastRPC invocation, one HMX owner, and an exact 8 MiB VTCM
  request.
- EXP-0040's packed-W4 integer-HMX projections, exact U8 SiLU-by-Up LUT,
  Gate/Up and Down schedules, weights, qparams and output reference remain
  fixed.
- U8-native operators retain asymmetric U8 inputs and outputs and the existing
  qparams. Their implementation authority is the current scalar U8 arithmetic,
  not W4F16 or FP16 teacher accuracy.
- No intermediate DDR, spill/fill, QNN path, extra FastRPC invocation, hidden
  host computation or persistent pre-expanded tensor is permitted.
- This experiment guarantees local arithmetic implementation correctness, not
  full-model quantization accuracy, perplexity or question-answer quality.

## Stage A — U8 RMSNorm and residuals

Implement HVX versions of Input RMSNorm, Post-Attention RMSNorm, both U8
residual adds, and where profitable the Post-Attention Residual-plus-RMSNorm
handoff. Reuse the FP16 implementation's vector reduction, row scheduling and
fused-boundary structure, while preserving U8 dequantization, zero-point
handling, saturation and rounding. Compare each real-shape output against the
scalar U8 Implementation Reference before enabling it cumulatively.

## Stage B — U8 Q/K Norm plus RoPE

Implement the real 128-channel Q/K head operation with HVX vector loads,
zero-point-aware dequantization, vector sum-of-squares, the existing gamma and
RoPE coefficients, U8 requantization, and a vectorized U8-to-FP16 bridge for
the retained Attention island. Q and K outputs at the declared quantized
boundary must match their scalar U8 Implementation Reference.

## Stage C — Remove scalar Softmax without mislabeling it

Enable the already validated standard stable FP16/HVX causal Softmax for the
W4U8 block's retained FP16-HMX Attention island. This removes the scalar
Softmax bottleneck while preserving the current QK and AV numerical contract,
but it is explicitly a bridge implementation rather than a true U8 Softmax.
A true U8-input/U8-output Softmax remains deferred until integer QK and AV can
be introduced in one separately attributable Attention experiment.

## Gates

U8-native operators must match the scalar U8 Implementation Reference; the

## Implementation result

The implementation completed on source commits
`adaa894f0bb1aed60347de53af07f43c552ccbc5` and
`23bdbee61ddfddb914f0cbcc2266f0cee12be0e7`. It adds an EXP-0041-specific
HVX U8 operator suite and enables it only for the W4U8 complete-block path.
Input and Post-Attention RMSNorm use vector U8 unpacking, centered square
accumulation, qfloat gamma application and U8 requantization. Q/K Norm plus
RoPE uses the same centered reduction with vector gamma/rotation arithmetic,
followed by an in-place vector U8-to-FP16 bridge. Both residual paths use a
Q14 fixed-point HVX implementation. Post-Attention residual plus RMSNorm is
exposed as one scheduling mode but intentionally remains a mathematically
equivalent two-pass VTCM implementation.

The retained Attention island now uses the existing stable FP16/HVX causal
Softmax and vector FP16-to-U8 output quantization. This is not a true U8
Softmax: QK and AV remain FP16 HMX and scores/probabilities remain FP16 in
VTCM. EXP-0040's exact U8 SiLU-by-Up LUT remains unchanged, so no second SiLU
algorithm was introduced.

Two implementation defects were rejected before formal collection. A qfloat
residual packing path produced a fixed 128-byte lane permutation despite an
otherwise identical value multiset, so the accepted residual uses the Q14
lane-preserving path. A shorter U8-to-half conversion saved only tens of ticks
but produced six complete-block differences of one U8 LSB; the accepted path
retains explicit vector unpack plus conversion and remains byte-exact.

## Formal evidence and outcome

Seven interleaved paired rounds were collected at repeat one and repeat ten
from source head `23bdbee61ddfddb914f0cbcc2266f0cee12be0e7` without a
device reboot. The immutable EXP-0040 Stage-B package was reused unchanged;
its manifest SHA-256 is
`7708b3aa2e65f6cddde55c7e812ffe6a325ee23f2221d066c810a38e3789acb3`.

At repeat one, median complete Host wall changed from 175.878021 ms to
16.728594 ms per block, a 90.4885% reduction, while median block ticks changed
from 3,333,542 to 307,034. At repeat ten, median complete Host wall changed
from 173.608365 ms to 16.033037 ms per block, a 90.7648% reduction, while
median block ticks changed from 3,329,620.4 to 306,469.3.

The repeat-one stage medians explain the gain. Input RMSNorm changed from
425,256 to 1,653 ticks; Q/K Norm plus RoPE and the Attention bridge changed
from 1,097,806 to 14,796 ticks; the complete Attention interval changed from
661,721 to 153,457 ticks, including Softmax from 227,732 to 5,316 ticks;
Post-Attention residual plus Post-Attention RMSNorm changed from a combined
719,435 to 1,936 ticks; and Final residual changed from 297,243 to 291 ticks.

Every formal candidate produced output hash `69f22eeb035e5ec5` with zero
mismatches and zero maximum U8 LSB error against the EXP-0040 scalar W4U8
Implementation Reference. The requested and acquired VTCM were exactly
8,388,608 bytes, the peak plan was 4,713,984 bytes, intermediate DDR reads and
writes were zero, and spill/fill was zero. Projection and Attention arithmetic
work was unchanged at 1,120 HMX commands, 512 FP16 tile pairs and 49,152
U8-by-S8 tile pairs per block. Therefore the measured gain comes from replacing
scalar common operators and their scalar bridges rather than skipping HMX
work.

The local gate passes and the evidence is valid. Adoption remains pending user
approval, and the selected baseline remains `W4F16-EXP0038-NORMS`. This result
only proves hardware implementation equivalence to the existing W4U8 scalar
path. It does not establish full-model W4A8 quantization accuracy.
