# EXP-0109 — Public common-layer consolidation and freeze

## Decision and scope

The user accepted the recommendation to end the public/common optimization
phase with one auditable consolidation. The source parent is the accepted
EXP-0106 integrated fair-and-fastest baseline. EXP-0107's F16F16 Gate/Up
group-interleaved producer-consumer schedule is included under its documented
gate exception. EXP-0108's `qkv_norms` carrier is excluded from the public
plan and remains rejected there.

This experiment is a consolidation, not a new optimization search. It must
produce one source revision from which the frozen fair F16F16, W4F16 and W4U8
cells and the selected fastest W4U8 cell can all be built and measured. No
recipe specialization starts in this experiment.

## Candidate

Start from EXP-0106 and integrate only the EXP-0107 F16F16 `gate8_interleaved`
runtime path. The W4F16 and W4U8 fair plans and the fastest W4U8 integrated
plan remain unchanged. The EXP-0108 `qkv_norms` public path must be absent from
the selected runtime and from the frozen public configuration.

## Gates

Static evidence must identify the accepted interleaved F16F16 path, the
absence of the rejected public QKV carrier, and unchanged W4 runtime tokens.
The real Qwen3 layer-14 M=64 block must preserve accepted output hashes and
independent byte-exact audits, request exactly 8 MiB VTCM, use zero
intermediate DDR and spill/fill, one FastRPC invocation, one HMX owner and no
QNN.

Formal repeat-one and repeat-ten evidence must reproduce EXP-0107's F16F16
Gate/Up and complete-wall improvement in ordinary and paired medians. It must
also report the same-source frozen fair three-recipe table and the fastest
W4U8 cell using the complete profiling contract. Unlike EXP-0107, unchanged W4
plans are validated as retained baseline cells rather than duplicated noisy
identity candidates.

## Freeze outcome

Completed and accepted on source commit
`42e2a33012929ccbb05e8c2741124b6fd539552c`. All gates passed. F16F16
Gate/Up improved by 8.36% at repeat one and 8.22% at repeat ten; complete Host
wall improved by 2.57% and 3.41%. The retained fastest W4U8 cell remained
4.69% and 10.57% faster than the fair W4U8 cell. Every selected cell preserved
its accepted output hash with zero mismatches and zero maximum LSB, exact
8 MiB VTCM, zero intermediate DDR and spill/fill, one FastRPC invocation, one
HMX owner and no QNN.

Formal evidence is retained at
`D:/llm_exp/results/qwen3-block-htp/exp0109/20260831T155519Z_42e2a3301292_formal`.
The frozen fair and fastest-W4U8 identities are tagged
`baseline-fair-exp0109-public-freeze` and
`baseline-w4u8-fastest-exp0109-public-freeze`. Future work must branch from
this frozen source as an explicitly named Recipe Specialization unless the
