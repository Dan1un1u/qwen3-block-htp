# EXP-0200 — Decode O-to-Gate direct-n cross-prefetch

## Decision and purpose

EXP-0199 is the fastest evidence-valid pending W4U8 decode candidate at
42.314 token/s. Gate/Up plus SwiGLU remains the largest interval at about 7.07
ms/token. The continuous Gate-to-Up ring still begins with a serialized one
MiB Gate packed-W4 transfer after post-attention residual/RMSNorm has already
finished.

EXP-0200 tests a cross-module lifetime: start the first Gate batch-thirty-two
weight and bias DMA immediately after O projection, let it progress while the
unchanged post-attention residual/RMSNorm runs on HVX, then consume that exact
prefetched slot as the first group of the existing Gate-to-Up ring.

## Controlled implementation

One runtime-selectable binary compares EXP-0199 without and with O-to-Gate
prefetch. The candidate may change only logical-M1 prefetch state, start/wait
placement, telemetry and experiment tools. The transfer uses the same known
one-MiB HMX-accessible expanded-weight slot and the phase-dead RoPE bias slot
already validated by Gate batch thirty-two. No new VTCM allocation or arbitrary
carrier address is permitted.

All weights, scales, qparams, arithmetic, HMX commands and tile pairs, QKV,
Attention, O math, residual/RMSNorm math, Gate/Up math, SwiGLU, Down, cache, LM
head, M64 prefill, F16F16, W4F16 and the no-QNN architecture remain immutable.

## Gates

Correctness requires byte-exact post-norm, Gate/Up, middle, hidden, cache,
selected-code and token outputs. Physical evidence requires exactly 8 MiB
VTCM, zero timed intermediate DDR, zero spill/fill, one FastRPC per pass, one
HMX owner, no QNN, zero decode expansion, identical weight bytes, DMA
descriptors, HMX commands and tile pairs, and one consumed cross-prefetch per
layer.

A five-pair short gate must lower Gate/Up wall and increase complete directly
measured decode token/s. A passing candidate completes ten rotated 193-step
pairs. M64 prefill is preservation-only. Adoption remains pending explicit
user promotion.
