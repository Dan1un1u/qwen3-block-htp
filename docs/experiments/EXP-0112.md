# EXP-0112 — W4U8 Gate/Up streaming release-fence hierarchy

## Decision and scope

The user authorized a continuing W4F16/W4U8 specialization loop. EXP-0112 is
a W4U8 Gate/Up-only experiment derived from the EXP-0111 source parent while
retaining the selected EXP-0109 fastest W4U8 runtime plan. It does not alter
the Frozen Public Baseline, W4F16, F16F16, QKV, Attention or Down.

## Hypothesis and factorial

Each 32-tile W4U8 Gate/Up streaming region currently ends the W4-to-S8 unpack
with a full barrier, executes another full barrier in its worker, then stores
the generation and performs an address release before HMX consumes the region.
The first region also executes a full barrier inside the bias copy. The
generation release should be the required publication boundary for all prior
disjoint VTCM stores.

Exactly three runtime-selectable cells are allowed. Control preserves the
internal unpack/bias barriers, worker barrier and release. `single_fence` uses
relaxed unpack and bias helpers but retains the worker barrier and release.
`release_only` uses the relaxed helpers and removes the worker barrier while
retaining generation store plus release. These modes are carried only through
the Gate/Up MLP handoff; all other pipeline users remain ordered control.

## Gates

All cells must preserve byte-exact final output and existing W4U8 intermediate
audits with zero mismatch and zero maximum LSB. They retain exactly 8 MiB VTCM,
zero intermediate DDR and spill/fill, one FastRPC execution unit, one HMX
owner, the same W4 bytes, DMA traffic and descriptors, HMX commands and tile
work, streaming region publication count and peak VTCM.

Static disassembly must show that ordered helpers retain their barriers,
relaxed W4-to-S8 and bias helpers contain no full barrier, and release-only has
no worker full barrier before the generation release. A candidate is eligible
only if Gate/Up-plus-SwiGLU and complete Host wall strictly improve in ordinary
and paired repeat-one and repeat-ten medians over five rounds. The fastest
eligible complete Host cell is selected. Closure requires PC-027 and PC-028;
passing does not promote a baseline without explicit user adoption.

`single_fence` is the sole eligible candidate. At repeat ten it lowers the
Gate/Up-plus-SwiGLU module from 676.432 us to 665.276 us and complete Host wall
from 1743.839 us to 1738.979 us. W4-to-S8 expansion ticks fall about 8.77%,
HMX-ready wait about 4.76% and expanded-slot wait about 11.09%. The additional
worker-barrier removal in `release_only` further lowers some local waits but
regresses both Gate/Up and Host at repeat ten, so it is rejected.

EXP-0112 therefore passes its local gate with `single_fence`. It is a valid
W4U8 specialization candidate and provisional source parent, but remains
pending user adoption and does not silently replace the selected baseline.
