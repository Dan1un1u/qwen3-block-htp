# EXP-0095 — Four-row native Softmax carrier shuffle

## Decision and motivation

The autonomous profiling-guided loop continues from the accepted EXP-0084
control. EXP-0094 proved that removing almost half of V-pack work does not
materially shorten the complete block, so the next experiment targets the
larger Softmax worker interval without changing its approximation or task
graph.

Static disassembly of the EXP-0084 path shows that each Softmax row invokes
the Hexagon 32-byte memcpy helper four times to assemble the QK score row and
four more times to scatter the probability row. The compiler did not turn
these eight small transfers into an aligned HVX tile operation; the function
also retains a 0x780-byte stack frame. EXP-0095 tests whether four adjacent
rows can be loaded as four aligned 128-byte physical tiles, transposed at
32-byte-quarter granularity in HVX registers, processed with byte-identical
Softmax math, inverse-transposed, and written as four aligned probability
tiles.

## Fixed contract

The Execution Unit remains the Qwen3-1.7B layer-14 complete block at M=64.
The exact EXP-0084 source commit, W4 bytes, asymmetric-U8 qparams, QK and AV
integer HMX arithmetic, log2/LUT Softmax approximation, causal mask,
saturation, rounding, task slicing, worker count, projections, residuals,
MLP, DMA graph and HMX ownership are fixed. Only the physical assembly and
scatter of four-row score/probability carriers may change.

Formal runs require one FastRPC, exactly 8,388,608 acquired VTCM bytes, zero
intermediate DDR and spill/fill, one HMX owner, no QNN, 25,444,352 weight
bytes, 512 weight DMA descriptors, 176 HMX commands and 49,408 U8-by-S8 tile
pairs per block. No new persistent or transient VTCM allocation is allowed.

## Serial gates

The static gate requires a four-row HVX shuffle helper whose hot carrier path
contains aligned vector loads/stores and register shuffles, no 32-byte memcpy
helper calls, and no vector stack spill. Correctness then requires byte-exact
final output plus Input-RMSNorm, QK, probability and AV audit boundaries
against EXP-0084 and the independent reference, with zero mismatches and zero
maximum LSB error.

Only after static, correctness and physical gates pass will five order-rotated
control/candidate rounds run at repeat one and repeat ten. Aggregate Softmax
work, additive Attention wall and complete Host wall must all strictly improve
in ordinary and paired medians at both repeat counts. PC-027 and PC-028 close
the experiment; baseline promotion remains a user decision.
