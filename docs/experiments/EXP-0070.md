# EXP-0070 — Batch both Q heads of each GQA group in HMX commands

## Parent and scope

EXP-0068 is the direct source control; rejected EXP-0069 is not inherited.
Preserve EXP-0068's six-context pool, Q/K preparation, log2 Softmax, SOLE LUT
templates, W4U8 projections, residuals, MLP, qparams, layouts, VTCM plan, and
all numerical bytes. Change only Attention HMX command cadence within one GQA
group.

## Hypothesis

EXP-0068 submits one two-score-tile QK command and one four-output-tile AV
command for each of sixteen Q heads, for thirty-two Attention HMX commands per
block. The two Q heads of a GQA group share the same ready K/V group and are
already owned by one Attention task. Submitting both heads' four QK output
tiles in one command, then both heads' eight AV output tiles in one command,
should halve Attention command handoffs without changing any HMX tile pair or
Softmax dependency.

## Gates

The control retains EXP-0068's per-Q-head QK2/AV4 commands. The candidate uses
per-GQA-group QK4/AV8 commands. Attention HMX commands must fall from 32 to 16
and total block HMX commands from 192 to 176 while all 49,408 HMX tile pairs,
weights, qparams, score/probability/AV bytes, tasks, DMA traffic, and every
non-Attention stage remain unchanged.

Final output and QK/probability/AV audit boundaries must remain byte-exact to
EXP-0068 and the independent reference. Exactly 8 MiB VTCM, zero intermediate
DDR, zero spill/fill, one FastRPC Execution Unit, one HMX owner, six Attention
contexts, and no QNN are mandatory. At repeat one and repeat ten, the
Attention ledger and complete Host wall must strictly improve in ordinary and
paired medians. Seven interleaved paired rounds and PC-027/PC-028 closure are
required.

## Result

The implementation uses the existing contiguous two-head GQA layout as two
HMX M tiles. One worker command now computes both heads' four QK output tiles,
and one worker command computes both heads' eight AV output tiles. Attention
commands fall from 32 to 16 and complete-block HMX commands from 192 to 176,
while all 49,408 tile pairs remain unchanged.

The formal seven-round comparison passes. At repeat one, complete Host wall
falls from 2,585,000 to 2,557,969 ns (-1.046%; paired -1.025%) and Attention
falls 4.655%. At repeat ten, Host wall falls from 2,139,989.5 to 2,124,156.3
ns (-0.740%; paired -0.457%) and Attention falls 5.208%. QK and AV HMX worker
time fall about 44% and 41%, and Attention pipeline wait falls about 51% at
repeat ten.

Final output, QK, probability, and AV hashes are byte-exact to EXP-0068 with
zero reference mismatches and zero maximum LSB error. The run retains exactly
8 MiB VTCM, a 5,306,080-byte peak plan, zero intermediate DDR, zero spill/fill,
one FastRPC Execution Unit, one HMX owner, and no QNN. EXP-0070 is locally
eligible and becomes the latest W4U8 candidate and provisional source parent;
the user-selected W4U8 baseline remains EXP-0055 until explicit promotion.
