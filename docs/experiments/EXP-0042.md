# EXP-0042 — Integer QK, log2 Softmax, and integer AV

## Approval and source

Approved by the user on 2026-08-29 to continue from EXP-0041 source head
`23bdbee61ddfddb914f0cbcc2266f0cee12be0e7`. The source branch is
`codex/exp-0042-w4u8-log2-gqa-attention`. EXP-0041 is the provisional W4U8
source parent; this does not promote it or replace the user-selected
`W4F16-EXP0038-NORMS` baseline.

## New hypothesis

EXP-0041 leaves an FP16 Attention island inside the otherwise asymmetric-U8
block. Q and K are normalized and rotated in U8, after which Q, K and V are
expanded to FP16. QK and AV use FP16 HMX, Softmax uses standard FP16/HVX, and
the result is quantized back to U8. EXP-0042 replaces that complete island,
rather than substituting an isolated Softmax callback.

The previous mllm/QNN custom-Softmax route could not control the adjacent QK
and AV HMX work or the compiler's cross-operator schedule. This standalone
runtime owns QK, Softmax, AV, VTCM buffers, HMX/HVX ordering and GQA task
publication. It is therefore a materially new execution hypothesis rather
than a retry of the rejected isolated-custom-op approach.

## Fixed scope and numerical contract

- The Execution Unit remains the real Qwen3-1.7B layer-14 complete block at
  `M=64`, with sixteen Q heads, eight KV heads and head dimension 128. KV-cache
  and decode shapes remain deferred.
- Declared Q, K, V and Attention-output boundaries remain asymmetric U8. K and
  V may be requantized inside VTCM into zero-centred S8 carriers solely for the
  signed HMX right operand. This does not redefine the model activation
  contract as symmetric S8.
- Integer QK uses U8 Q and S8 K. Its dynamically generated HMX bias accounts
  for Q zero point and the per-position S8 K sums. Integer AV uses U8
  probability with zero point zero and S8 V. HMX conversion produces the
  declared U8 Attention output directly.
- QK output is an internal U8 log2-score grid. Candidate fractional grids
  `F=3` and `F=4` bake Q/K scales, `1/sqrt(128)` and `1/ln(2)` into the HMX
  accumulator conversion. Saturation counts and score error are reported.
- The primary Softmax candidate uses tile-wise maximum tracking, four-bit
  log2 exponent codes, integer row sums and approximate log-based division.
  Causally masked elements are forced to exact zero rather than represented by
  the smallest nonzero exponent code.
- Device arithmetic is checked byte-for-byte against an independent host
  integer Implementation Reference. The current EXP-0041 FP16 Attention island
  is an accuracy diagnostic. Full-model accuracy, perplexity and question
  answering are not gates.

## Physical contract

- One Host-to-DSP FastRPC invocation, one HMX owner and an exact 8 MiB VTCM
  Prepared Runtime Session are retained.
- Scores, exponent codes, row statistics, probabilities and Attention output
  remain VTCM state. Intermediate DDR, spill/fill, a QNN path, hidden Host
  execution and persistent pre-expanded tensors are forbidden.
- The eight GQA groups are independent tasks. Each owns two Q heads and one
  K/V head. HMX executes one group's QK or AV while HVX workers pack K/V or run
  another group's Softmax. Generation-tagged ring slots prevent the HMX owner
  and HVX producers from reusing live storage.
- Probability is generated directly in integer-HMX activation-tile layout.
  A complete row-major probability tensor may not be introduced merely for
  compatibility.

## Milestones and gates

Stage A constructs a single-GQA-group micrograph for U8-by-S8 QK and AV. It
must prove the intended integer HMX instructions, dynamic zero-point
correction, exact host-reference output, fixed-VTCM residency and zero
intermediate DDR before the fused Softmax path is admitted.

Stage B implements the tile-wise log2 Softmax and fuses its U8 probability
carrier directly into AV. Hardware output must remain byte-exact with the
integer reference. Error against standard FP16 Attention is reported by
probability row sum, maximum and mean error, output U8 LSB error and cosine,
but does not stop implementation.

Stage C integrates eight GQA tasks into the complete W4U8 block. Formal
comparison uses repeat one and repeat ten against the unchanged EXP-0041 FP16
Attention-island control. Local adoption requires strict reduction of both the
complete Attention interval and complete Host wall at both repeat counts while
all physical gates pass. A performance failure is retained as valid negative
evidence and does not change the selected baseline.

## Implementation result

The implementation completed through source head
`d5f68b72b799a5c8df6c4f5cecfda218edc1e23d`. Q, K and V projections write
their asymmetric-U8 output directly into native integer-HMX tile storage.
Four HVX contexts claim eight GQA-group tasks; each task performs native-tile
Q/K Norm plus RoPE, packs signed K and V carriers, submits QK and AV work to
one mutex-protected HMX owner, and runs the four-bit log2 Softmax while other
groups progress. Probability is written directly into the AV activation-tile
layout, and AV output directly becomes the O-projection activation. No
row-major score, probability or Attention-concat compatibility tensor is
introduced.

The package-derived static stage hashes were not used as the implementation
gate because those tensors were generated from an offline projection and
Norm/RoPE path, while the integrated candidate consumes the actual device
outputs of the independently implemented U8 projection and HVX Norm/RoPE
paths. Audit-on instead exports the actual Q/K/V boundary plus score,
probability and AV stages after the timed experiment. An independent host
implementation then recomputes all three stages from those actual inputs.
This audit-only export writes 524,288 bytes to DDR and is explicitly excluded
from performance evidence; every audit-off formal run writes zero intermediate
DDR bytes.

The independent reference matched QK over 65,536 bytes, log2 Softmax over
65,536 bytes and AV over 131,072 bytes with zero mismatches and zero maximum
U8 LSB error. The causal mask had zero violations. The measured workload had
2,519 score-carrier saturations and 723 V-recentring saturations, while the AV
carrier had zero saturations. These are reported numerical properties of the
declared integer algorithm rather than hidden implementation mismatches.

## Formal evidence and outcome

Seven interleaved paired rounds were collected at repeat one and repeat ten
from source head `d5f68b72b799a5c8df6c4f5cecfda218edc1e23d` without a
device reboot. Both sides used the EXP-0041 `rms_rope_softmax` common-operator
mask, fused U8 residual/Norm boundary, W4U8 streaming MLP, identical package,
weights and qparams. The only changed model region was the complete Attention
island.

At repeat one, median Host wall changed from 16.735625 ms to 8.449844 ms per
block, a 49.5098% reduction. The exclusive Attention interval changed from
153,432 to 29,222 qtimer ticks, an 80.9544% reduction. At repeat ten, median
Host wall changed from 16.039531 ms to 7.701740 ms per block, a 51.9828%
reduction, while the Attention interval changed from 153,473.3 to 28,272.7
ticks per block, an 81.5781% reduction. The paired median direction was also
strictly favourable at both repeat counts.

Every formal performance run requested and acquired exactly 8,388,608 VTCM
bytes, used one FastRPC Execution Unit and one HMX owner, and recorded zero
intermediate DDR reads, writes, descriptors and spill/fill. Candidate
Attention executed 32 integer QK and 64 integer AV HMX commands per block,
with no FP16 Attention HMX tile pairs. All complete-block outputs retained hash
`69f22eeb035e5ec5` with zero differences against the retained W4U8 output
reference. No QNN dependency exists.

The local correctness, physical and speed gates pass, so the candidate is
eligible for adoption. Adoption remains pending user approval and the
selected baseline remains `W4F16-EXP0038-NORMS`. The current min-max U8
qparams still have poor diagnostic agreement with W4F16, so this result proves
the declared integer Attention implementation and speed path, not usable
full-model W4A8 accuracy.
