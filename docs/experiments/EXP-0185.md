# EXP-0185 — Session-native K tail without mutable DDR journal

## Decision and purpose

EXP-0184 proves that partial VTCM K-tail residency plus an HVX row update can
make Attention about 8.9% faster, but duplicating each cached K row into both
the canonical DDR tail journal and the prepared-session VTCM carrier leaves a
40 us/token maintenance penalty and unstable end-to-end gain.  Once a prepared
session owns the mutable carrier, the DDR copy is redundant for Attention.

EXP-0185 introduces a versioned session-native K format.  For seven cached
heads per layer, the mutable K tail exists only in VTCM between segment seals;
the eighth fallback head retains the segmented-v4 DDR row journal.  At row 31,
the exact complete native carrier is written to the existing immutable DDR
segment, so sealed-history ABI and long-context consumption remain unchanged.
The external mutable-tail bytes for cached heads are explicitly non-authoritative
and are not a legal state boundary during a prepared session.

The direct performance control remains EXP-0182.  All Attention math, qparams,
V cache, projections, MLP and LM head remain unchanged.  Correctness requires
exact consumed carriers, hidden hashes, tokens/codes and immutable sealed bytes;
it deliberately does not require stale, non-authoritative mutable DDR bytes to
match.  Physical gates require exactly 196 fewer K-tail write descriptors and
25,088 fewer cache DDR write bytes per ordinary decode token, exact 8 MiB VTCM,
zero timed intermediate DDR, zero spill/fill, one FastRPC and no QNN.

Five rotated 17-step pairs must lower cache carrier update, QK-Softmax-AV and
complete decode wall in 5/5 pairs before formal 193-step profiling.  Only the
user may promote a passing result.
