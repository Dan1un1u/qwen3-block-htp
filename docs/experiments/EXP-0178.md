# EXP-0178 — Decode W4U8 row-four common nonlinear operators

## Decision and purpose

EXP-0177 proves that logical-M=1 decode can avoid scanning dead rows of an HMX
carrier without changing valid output. Formal attribution now shows that each
decode token still spends about 0.552 ms in Input RMSNorm, 0.654 ms in fused
post-attention residual plus RMSNorm, and 0.195 ms in the final residual across
28 layers. Each helper still dispatches sixteen four-row tasks and processes
all 64 physical rows even though only row zero propagates to the next layer.

This experiment tests the same row-extent principle on those three common
nonlinear stages. It is not a retry of rejected EXP-0171: Gate/Up HMX,
streaming SwiGLU and its producer pacing remain byte-identical.

## Direct control and candidate

The control is byte-identical EXP-0177: row-four AV requantization plus the
existing six-context, 64-row Input RMSNorm and residual paths. The candidate
changes only logical-M=1 decode. It invokes the already-established exact
row helpers directly for physical rows zero through three, one complete
128-byte HVX carrier vector, for:

1. Input RMSNorm into native QKV activation tiles.
2. Post-attention residual plus RMSNorm into native Gate/Up activation tiles.
3. Final residual output that becomes the next layer input.

M64 prefill retains the existing 64-row pools. Rows four through 63 are dead
padding and must not influence row zero. The candidate may remove unnecessary
worker wake/join overhead for a single four-row task, but may not change the
underlying centered-square, square-root, gamma, affine residual, requantization
or shuffle-four arithmetic.

QKV, QK, Softmax, AV, O projection, Gate/Up, SwiGLU, Down, cache, qparams,
weights, embedding, feedback, LM-head, F16F16, W4F16 and the no-QNN physical
contract are immutable. Telemetry must report the requested and observed row
extent and distinguish pool64 from direct-row4 calls.

## Gates

The short gate uses five rotated 17-step pairs. Both cells must be byte-exact
on all valid stage boundaries, hidden hashes, token IDs and logit codes. A
padding-poison run must prove rows four through 63 cannot change any valid
output. HMX tile work and all unaffected module counters must remain unchanged.
The candidate advances only if the sum of the three target stage walls and the
complete decode Host wall are both lower.

A passing candidate completes ten rotated 193-step pairs, the independent
integer head audit and EXP-0163 transformer/cache regression. It must retain
exact 8 MiB VTCM, one FastRPC per pass, zero timed intermediate or full-logit
DDR, zero spill/fill, no QNN and zero ledger residual. Direct complete decode
tokens/s is the formal ranking metric. A local pass remains pending explicit
user promotion.
