# EXP-0051 — W4U8 QKV generation-safe head-pair HMX command

## Approval and parent

Approved by the user on 2026-08-30 after EXP-0050 reduced the Down critical
path and left QKV as 31.7 percent of the repeat-ten additive block ledger. The
implementation parent is EXP-0050 source commit
`67c112e298b49e96cbaa1a78b5223dad54040c42`. The source branch is
`codex/exp-0051-w4u8-qkv-head-pair-command`.

## Evidence-driven hypothesis

The current W4U8 QKV path uses one batch-four integer-HMX command for every
128-channel Qwen3 head. Q, K, and V therefore issue 16, 8, and 8 commands,
respectively. Simply delaying readiness until a larger batch completes is not
an admissible hypothesis: EXP-0037 showed that coarser Q-head publication can
erase a local projection gain by extending the QK Norm-RoPE join tail.

EXP-0051 instead tests a generation-safe head-pair command. One worker command
begins as soon as the first four-tile head is expanded, computes and publishes
that head immediately, then waits inside the same command while HVX finishes
the next four-tile head, computes and publishes the second head, and returns.
This should preserve the existing one-head readiness cadence while removing
one worker handoff per pair and overlapping second-head expansion with
first-head HMX consumption.

## Ordered milestones

Stage A applies the paired command only to Q. It adds equivalent-scope Q/K/V
projection and readiness telemetry and must reduce combined QKV and complete
Host wall at repeat one and repeat ten. Q commands must fall from 16 to 8,
while K and V remain at 8 each. Failure stops the experiment.

Only after Stage A passes may Stage B apply the same command to K and V. The
final QKV command count should fall from 32 to 16. First-head publication must
still occur before the second head is ready; a plain batch-eight command that
publishes both heads only on return is diagnostic only and cannot be adopted.

## Fixed contract and gates

- The Execution Unit remains the real Qwen3 layer-14 complete block at M=64.
- The direct control is `W4U8-EXP0050-DOWN-COMMAND-FUSION`; Attention, O,
  Gate/Up batch eight, Down two-chunk command, all tensor boundaries, W4
  values/scales, asymmetric-U8 qparams, and arithmetic remain fixed.
- HMX U8-by-S8 tile-pair count, QKV weight bytes and DMA descriptors, output
  codes, and per-head readiness order must remain unchanged.
- One FastRPC invocation, one HMX owner, exactly 8 MiB VTCM, zero intermediate
  DDR, zero spill/fill, and no QNN path are mandatory.
- Candidate output must be byte-exact to EXP-0050 and the independent
  implementation reference must report zero mismatches and maximum error
  0 LSB.
- A stage passes only if QKV additive ticks and complete Host wall are both
  strictly lower than their paired control at repeat one and repeat ten.
- Formal selection uses seven interleaved paired rounds on one stable boot and
  closes every PC-027 profiling field. A local pass creates only a candidate;
  baseline promotion remains a user decision.
