# EXP-0188 — Full-stack decode-only direct-n W4 HMX rollout

## Decision and purpose

The user approved the next step after EXP-0187 proved that integer HMX can
consume a project-packed signed-W4 `weight.n` carrier directly.  EXP-0188 tests
whether that local projection gain survives the complete token-generation
critical path.  It is a W4U8 decode-only experiment: M64 prefill remains on the
accepted EXP-0185 projection path.

The direct end-to-end control is the user-selected EXP-0185 W4U8
token-generation baseline at commit
`537650293920eb62c3cc49833df613246e8fb0b9`.  The implementation parent is the
evidence-valid EXP-0187 candidate at commit
`5e9ff6ade5ab10da8d3640d259e0867bc94cf422`.  EXP-0187 is not itself promoted by
this registration.

## Bounded implementation

The candidate may add the direct-n packed-W4 carrier to the full-model package,
select it only for logical-M1 W4U8 decode projections, and change the associated
decode-only VTCM schedule, telemetry and experiment tools.  It may not alter W4
values, scales, activation qparams, projection mathematics, Attention, KV-cache,
nonlinear operators, the M64 prefill dispatch, F16F16, W4F16 or the no-QNN
architecture.

The intended first integration covers the transformer projections whose exact
EXP-0187 arithmetic contract is available.  Any projection class that cannot
meet the same contract remains on the EXP-0185 path and is reported explicitly;
it is not silently approximated.  The final ranking boundary is the complete
continuous-decode token path, not the sum of local projection timings.

## Gates

Correctness requires every valid changed projection boundary and the complete
hidden-state, log2-code, token and cache-state sequence to remain byte exact to
EXP-0185, with the existing independent integer references retained.  M64
prefill must remain byte exact and dispatch the unchanged EXP-0185 projection
implementation.

The physical gate requires exactly 8 MiB VTCM, zero timed intermediate DDR,
zero spill/fill, one FastRPC invocation per pass, one HMX owner, no QNN, and zero
timed HVX W4-to-S8 expansion for every projection reported as direct-n.

A bounded five-pair short run precedes the ten-rotated-pair formal run over one
M64 prefill and 192 continuous decode steps to valid length 256.  The candidate
must produce strictly higher directly measured full-stack decode tokens/s than
EXP-0185 with reproducible pair stability.  Failure of correctness, the
physical contract, or end-to-end decode performance stops this line before any
M64 prefill direct-n experiment.

## Implemented boundary

The host deterministically repacks the existing W4 carrier into the empirically
verified HMX `weight.n` nibble-lane order at session setup.  No W4 value, scale,
activation qparam or projection equation changes.  Decode then feeds packed W4
directly to integer HMX for Q, K, V, O, Gate, Up and Down in all 28 transformer
layers: 196 direct-n projections per generated token.  Their timed QKVO and MLP
W4-to-S8 expansion is zero.

The LM-head direct-n diagnostic is deliberately not adopted.  The stable
direct-n grouping available for that shape changed tied U8-logit argmax results
and was slower than the existing group-16 implementation.  The formal candidate
therefore keeps the EXP-0185 LM head and reports its Expanded-S8 work.  This is
the explicit fallback permitted by the registered contract, not an unreported
approximation.

## Formal result

The five-pair short gate first improved decode by a median 16.606 percent.  The
formal gate then ran ten alternating-order pairs, each consisting of one real
M64 prefill followed by 192 continuous decode tokens through cache length 256.

| Metric | EXP-0185 Expanded-S8 control | Transformer direct-n | Change |
|---|---:|---:|---:|
| M64 prefill | 1277.275 token/s | 1274.424 token/s | unchanged-path measurement |
| Decode | 23.621560 token/s | 27.623484 token/s | +16.943925% |
| Decode host wall | 42.3342 ms/token | 36.2011 ms/token | -14.486% |

The candidate won all ten formal pairs.  All 1,930 paired generation steps had
identical complete hidden-state hashes and selected tokens.  Cache mismatch,
cache-prefix mismatch and cache-structure mismatch counters were zero.  M64
prefill executed zero direct-n projections and was pairwise byte exact.

Every run retained exactly 8 MiB VTCM, one FastRPC execution unit, one HMX
owner, zero timed intermediate DDR, zero spill/fill, no QNN and a closed DSP
ledger.  Each decode token reads 672 MiB of direct packed-W4 transformer
carrier and avoids 1,344 MiB of Expanded-S8 carrier production.  The most
visible wall reductions are O projection (4.832 to 1.644 ms/token) and Down
projection (6.593 to 4.159 ms/token); Gate/Up plus SwiGLU remains the largest
candidate stage at about 17.357 ms/token.
