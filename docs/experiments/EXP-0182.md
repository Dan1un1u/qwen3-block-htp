# EXP-0182 — Prepared-Session VTCM-resident mutable V tail

## Decision and purpose

EXP-0180 and EXP-0181 both prove that quartet-native V carriers reduce the
Attention consumer cost, but neither provides a stable complete-decode win.
The remaining physical tax is structural: every token still updates the DDR
tail, and every fourth token publishes a converted carrier back to DDR.  The
prepared FastRPC session retains the exact same 8 MiB VTCM allocation across
all generation steps.  Its current W4U8 plan peaks at about 6.62 MiB, while a
complete mutable V-tail atlas for 28 layers, eight KV heads and 32x128 U8
values requires 917,504 bytes.

EXP-0182 tests whether that unused persistent VTCM can own the hot V-tail.  The
external segmented-v4 cache remains the recoverable row-major journal and
canonical audit state.  Attention consumes a separately versioned V7 format
whose mutable HMX carrier mirror lives only in the prepared session.  No K
cache, Attention arithmetic, qparam, projection, MLP or LM-head change is
allowed.

## Physical design

M64 prefill initializes the VTCM atlas.  Each decode append continues to write
one logical V row to the existing DDR journal, while also updating the current
layer/head raw quartet fragment in VTCM.  Attention copies complete carrier
groups directly from the atlas, converts only the active partial group in its
working slot and, on every fourth row, converts once and publishes back to the
atlas with HVX stores rather than DDR DMA.  At row 32 the completed atlas is
used to seal the immutable DDR segment.  A session restart can reconstruct the
atlas from the external logical journal, but no timed decode Attention may
read the mutable V tail from DDR.

The atlas must fit above the ordinary buffer-plan peak without overlap.  It is
not a graph output or spill workspace and may not increase the requested VTCM
beyond exactly 8 MiB.

## Gates

A 34-step boundary replay must cross quartet and segment boundaries and remain
byte-exact against the EXP-0179 segmented-v4 control for external cache,
consumed AV carrier, hidden hashes, selected logit codes and tokens.  Telemetry
must prove VTCM atlas initialization, one VTCM row update per layer/head/token,
no mutable-tail DDR read in Attention, no VTCM/ordinary-plan overlap and zero
full-tile RMW.

Five rotated short pairs must improve both QK-Softmax-AV and complete decode
Host wall.  Only then may ten rotated 193-step pairs run.  The formal ranking
metric is direct full-stack decode token/s.  All exact 8 MiB VTCM, one FastRPC
per pass, no QNN, zero timed intermediate/full-logit DDR, zero spill/fill and
zero unattributed-tick contracts remain mandatory.  Any local pass remains
pending explicit user promotion.

## Decision state

Approved and completed on 2026-09-04 under the user's standing authorization

All correctness and physical gates passed.  The 193-step independent integer
reference matched 193/193 selected tokens and logit codes, the 34-step replay
crossed both quartet and 32-row segment boundaries exactly, padding poison was
invariant, and the EXP-0163 transformer/cache regression passed.  Every timed

measured 1,272.951 token/s for the candidate.  The experiment is locally
eligible but remains `adoption_status: pending`; only the user may promote it
to a Selected Baseline.
