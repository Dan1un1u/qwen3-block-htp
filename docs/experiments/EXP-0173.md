# EXP-0173 — Decode W4U8 LM-head batch-sixteen pipeline

## Decision and purpose

The continuous decode loop returns to selected EXP-0170 after EXP-0172 showed
that replacing integer HMX with HVX GEMV is structurally slower. The selected
W4U8 LM head still consumes about 5.20 ms/token, reads about 156 MB of W4
weights per token, and uses 594 eight-output-tile HMX commands plus 593 weight
prefetches. Its DMA, HVX expansion and HMX lifetimes remain largely overlapped,
but command, descriptor and per-group argmax granularity can still be reduced
without changing arithmetic.

## Direct control and candidate

One binary exposes the selected eight-output-tile control and a decode-M1-only
sixteen-output-tile candidate. The candidate doubles the coarse group size,
using the already available expanded-carrier capacity, a declared larger
compressed staging capacity, and transformer-dead VTCM for the larger HMX
output/argmax carrier. It must retain the same W4 codes, per-channel scales,
U8 input/output qparams and bias/requant words, four-context W4-to-S8 expansion,
two-slot DMA/HVX/HMX ordering, greedy argmax mathematics and selected-token
boundary. Prefill remains on batch eight.

No Transformer block, cache, Softmax, projection, RMSNorm, embedding, token
feedback, F16F16/W4F16 path or QNN dependency may change.

## Gates and evidence

The bounded gate first proves identical token/logit code and output hashes,
correct batch telemetry, exact 8 MiB VTCM, zero timed intermediate/full-logit
DDR, zero spill/fill and zero ledger residual. It then requires lower LM-head
wall and lower complete decode Host wall in rotated short pairs. Failure rejects
batch sixteen without a formal long run.

If the bounded gate passes, formal evidence uses ten rotated sessions of one
M64 prefill followed by 192 continuous L64-L255 decode tokens. Adoption
requires higher directly measured decode tokens/s, all byte-exact/reference
checks and the unchanged physical contract. Prefill is a preservation
diagnostic and must continue to report batch eight.
