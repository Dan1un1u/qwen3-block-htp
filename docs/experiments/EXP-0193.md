# EXP-0193 — Direct-n decode Down DMA-four / HMX-two

## Decision and purpose

EXP-0192 proved that placing four Down outputs in one direct-n HMX worker
command resets the cDSP domain.  EXP-0193 keeps the validated two-output HMX
command intact and tests only a larger weight-transfer group: four packed-W4
tiles and biases are prefetched into one existing compressed-weight slot, then
consumed by two consecutive two-output HMX commands.

This separates two effects previously coupled by one `batch_tiles` parameter.
The candidate should retain 896 Down HMX commands per token while reducing
Down DMA groups by half and total weight DMA descriptors from 6,122 to 5,226.
No new VTCM allocation is required.

## Gates

One binary compares Down DMA2/HMX2 with DMA4/HMX2.  Gate/Up remains batch
sixteen and all other EXP-0191 modules remain unchanged.  Correctness requires
byte-exact hidden hashes, selected tokens and cache state.  Physical gates
remain exactly 8 MiB VTCM, zero timed intermediate DDR, zero spill/fill, one
FastRPC, one HMX owner, no QNN, unchanged weight bytes, unchanged HMX tile
pairs and commands, and zero Transformer W4-to-S8 expansion.  Five rotated
short pairs must improve direct complete decode token/s and Down wall before
ten formal pairs are allowed.
