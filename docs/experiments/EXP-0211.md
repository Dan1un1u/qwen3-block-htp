# EXP-0211 — Direct-W4 Down batch8 single-descriptor DMA

## Decision and purpose

EXP-0211 inherits the evidence-valid EXP-0210 structure. Down currently uses
batch4, so its 64 N tiles require 16 HMX groups per layer. Each batch4 group is
393216 packed-W4 bytes and already uses one complete weight descriptor plus one
bias descriptor. The candidate uses batch8: its 786432-byte weight group fits
the existing 1 MiB direct-N ping-pong slot and therefore requires no VTCM-plan
change.

Across 28 layers, the expected result is 448 to 224 Down groups, 1213 to 989
direct-N HMX commands, and 2278 to 1830 DMA descriptors. Arithmetic, W4 bytes,
HMX tile pairs, qparams, activation layout, all other projections, and prefill
remain unchanged.

## Gates and decision state

Correctness requires byte-exact Down output, hidden state, cache, selected
codes and tokens. Physical gates remain exact 8 MiB VTCM, zero timed
intermediate DDR, zero spill/fill, one FastRPC, one HMX owner, no QNN, zero
explicit W4 expansion, identical weight bytes/HMX tile pairs, Down commands
448 to 224, direct-N commands reduced by 224, and exactly 448 fewer DMA
descriptors. Five rotated pairs must improve Down wall and full decode token/s
before ten formal pairs. The user's consecutive local-win/E2E-regression
