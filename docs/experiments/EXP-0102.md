# EXP-0102 — Head-pair-aligned W4U8 QKV batch eight

## Decision and motivation

The accepted EXP-0084 W4U8 Q, K and V projections use four adjacent output
tiles per DMA-expand-HMX batch. Four tiles equal one 128-channel Attention
head, so QKV submits 32 HMX commands in total. The downstream Q/K Norm and
RoPE path, however, already consumes two adjacent heads per task. Batch eight
therefore matches the established consumer granularity: once one command
completes, both heads of a pair can be published together without delaying a
useful single-head consumer.

EXP-0102 compares QKV batch four with QKV batch eight. O remains batch four.
Both cells use the same binary and the same enlarged buffer plan. The
candidate should reduce QKV commands 32→16, complete-block HMX commands
176→160, weight DMA descriptors 512→480 and QKVO overlap/prefetch events
44→28 while preserving weight bytes and tile arithmetic.

## Fixed contract and gates

This is a clean sibling from accepted EXP-0084. Packed W4 values, expanded S8
values, asymmetric-U8 qparams, output bytes, Q/K/V tensor order, per-head
RMSNorm/RoPE math, Attention, O batch four, residuals, MLP, worker counts and
all HMX tile pairs remain fixed. The only functional scheduling change is
that QKV expands and submits eight adjacent output tiles per command and
publishes both completed head dependencies at the command boundary.

Both cells must request/acquire exactly 8 MiB VTCM, use the same enlarged peak
plan, one FastRPC and one HMX owner, and perform zero intermediate DDR and
spill/fill. Weight bytes and 49,408 U8-by-S8 tile pairs remain unchanged.
Control must report QKV batch four, 32 QKV commands, 176 total HMX commands and
512 DMA descriptors. Candidate must report QKV batch eight, 16 QKV commands,
160 total HMX commands and 480 descriptors. All 16 Q and eight K head-ready
dependencies must be published exactly once, with no Q/K Norm early read.

Audit-on control and candidate must be byte-exact at final output and the
established Input-RMSNorm, QK, probability and AV boundaries with zero
mismatches and zero maximum LSB. Five order-rotated rounds at repeat one and
repeat ten then compare QKV wall and complete Host wall; both must strictly
improve by ordinary and paired medians at both repeat counts. PC-027 and
PC-028 close the experiment. A local pass remains pending explicit adoption.
