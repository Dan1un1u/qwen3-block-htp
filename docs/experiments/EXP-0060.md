# EXP-0060 — Replace scalar U8 RMSNorm lane reduction with an HVX tree

## Parent and scope

EXP-0059 failed and is not inherited. EXP-0058 remains the direct source
control. The experiment changes only how the exact centered-square sum inside
U8 RMSNorm is reduced; qparams, square arithmetic, `sqrtf`, gamma, output
requantization, layouts, Attention, projections, residual equations, and MLP
scheduling remain unchanged.

## Hypothesis

The current U8 RMSNorm accumulates squares in four HVX vectors, spills each
vector to a 32-word stack array, and performs 128 scalar lane additions per
row. The complete centered-square sum is bounded below `2^32` for U8 values
and width 2048. Adding the four accumulator vectors lane-wise and applying one
HVX word-reduction tree is therefore integer-exact and removes the scalar
spill/reduction loop. The same helper is used by Input RMSNorm, post-attention
RMSNorm, and Q/K Norm, so one isolated change can reduce all A8 normalization
costs.

## Candidate and gates

Control and candidate must be selectable in one binary through an explicit
U8 norm-reduction mode. The candidate performs only the HVX tree reduction.
Final output and QK/probability/AV boundaries must be byte-exact to EXP-0058
and the independent reference. Formal runs require exactly 8 MiB VTCM, zero
intermediate DDR, zero spill/fill, one FastRPC execution unit, one HMX owner,
and no QNN.

At repeat one and repeat ten, Input RMSNorm, aggregate Q/K Norm plus RoPE,
post-attention residual plus RMSNorm, and complete Host wall must strictly
improve in both ordinary and paired medians. Seven interleaved paired rounds
and a PC-027/PC-028 complete profiling closure are required.

## Result

Implementation commit `dfb78797a9589232d79733a709a1d3176d37eb37`
made scalar and HVX-tree reduction selectable in one binary. Final output and
QK/probability/AV hashes remained byte-exact with zero mismatch and zero max
LSB. VTCM remained exactly 8 MiB and intermediate DDR/spill/fill remained
zero.

At repeat one, Input RMSNorm improved 13.518%, aggregate Q/K Norm plus RoPE
work improved 18.910%, post-attention residual plus RMSNorm improved 7.014%,
and complete Host wall improved 4.644% (paired 5.006%). At repeat ten the same
metrics improved 13.973%, 17.854%, 7.978%, and 5.194% (paired 5.131%).

## Final decision

`local_gate=pass`, `adoption_status=pending`. EXP-0060 is the latest eligible
W4U8 candidate. Baseline promotion remains a user decision.
