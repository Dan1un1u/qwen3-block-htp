# EXP-0117 — W4U8 packed-pair SwiGLU lookup table

## Decision and scope

The user authorized a continuing W4F16/W4U8 recipe-specialization loop.
EXP-0117 derives from EXP-0112 and uses its `single_fence` W4U8 Gate/Up path as
both cells' scheduling parent. It changes only the byte-exact Gate/Up SwiGLU
lookup representation and HVX lookup kernel; projections, qparams, W4 weights,
HMX, DMA, task cadence, Attention, residuals, Down and the frozen public layer
remain unchanged.

## Hypothesis

The current formal 256-by-256 U16 table occupies 128 KiB. For each 128 output
codes, the HVX hot loop unpacks two 64-lane halves and performs two predicated
halfword gathers per half because one 16-bit gate row spans 512 bytes and the
full table crosses the 64-KiB gather region boundary. That is four gathers per
128 outputs.

Every table entry is an U8 output stored in U16. Pack adjacent even/odd Up-code
outputs into the low/high bytes of one halfword. The resulting 256-by-128
halfword table is exactly 64 KiB, so each half can issue one unpredicated
halfword gather at offset `gate*256 + (up&~1)`, then select the low or high byte
from the gathered halfword using the Up-code parity. This preserves all 65,536
formal mappings while reducing four gathers to two and adds only mask, shift,
predicate and mux operations—no multiply or dual rounding shifts. It is a new
representation distinct from the rejected EXP-0096 arithmetic approximation
and EXP-0097 affine carrier.

## Fixed boundary and gates

Control uses the original U16 table and `qbh_mlp_gate_up_lut_hvx`; candidate
packs the same file in Host shared memory before execution and selects a new
HVX packed-pair kernel. To isolate the kernel, both cells retain the original
128-KiB shared-memory and VTCM reservation and copy traffic. The candidate may
read only the first 64 KiB but may not claim a boundary-memory saving.

An offline exhaustive gate must pack and decode all 65,536 entries with zero
mismatch. Static disassembly must show two unpredicated halfword gathers per
128-output loop and no predicated split-region gather in the candidate. Final
output and all existing independent W4U8 audits must remain byte-exact with
zero mismatch and zero maximum LSB. Exact 8 MiB VTCM, zero intermediate DDR
and spill/fill, one FastRPC execution unit, one HMX owner, unchanged weights,
DMA descriptors, HMX commands, tile work, pair publication and peak VTCM are
hard gates. Activation work, Gate/Up and complete Host wall must all strictly
improve in ordinary and paired repeat-one and repeat-ten medians over five
rotated rounds. PC-027 and PC-028 are mandatory; no local pass automatically
promotes a baseline.
