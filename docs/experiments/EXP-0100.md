# EXP-0100 — W4U8 O-projection batch-eight pipeline

## Decision and motivation

The accepted EXP-0084 W4U8 O projection uses the common QKVO pipeline with
four adjacent output tiles per DMA-expand-HMX batch. O has 64 output tiles, so
it submits sixteen HMX commands. Unlike QKV, it has no per-head readiness
consumer, and unlike Gate/Up, it has no per-batch SwiGLU publication. The
post-Attention residual begins only after the complete O projection. This
makes O the cleanest remaining projection on which to reduce command and DMA
batch cadence without delaying a fine-grained downstream dependency.

EXP-0100 compares the existing O batch four with O batch eight. Q, K and V
remain batch four. Both cells use the same binary and the same batch-eight-
capable VTCM buffer plan, so address placement is controlled. The candidate
should reduce O HMX commands from sixteen to eight and its two-descriptor
weight/bias prefetch batches from sixteen to eight.

## Fixed contract and gates

The experiment is a clean sibling from accepted EXP-0084. Only the O batch
cardinality, its declared double-buffer capacity and telemetry may change.
Packed W4 values, expanded S8 values, asymmetric-U8 qparams, activation and
output bytes, HMX tile arithmetic and order, QKV batch four, Attention,
residuals, MLP and all worker counts remain fixed.

Both cells must request and acquire exactly 8 MiB VTCM, use one FastRPC and
one HMX owner, perform zero intermediate DDR and spill/fill, and have no QNN.
Weight bytes and 49,408 U8-by-S8 tile pairs remain unchanged. The control must
report O batch four, sixteen O commands, 176 total HMX commands and 512 weight
DMA descriptors. The candidate must report O batch eight, eight O commands,
168 total HMX commands and 496 descriptors. The enlarged buffer plan must be
identical in both cells and remain below 8 MiB.

Audit-on control and candidate must be byte-exact at final output and the
established Input-RMSNorm, QK, probability and AV boundaries, with zero
mismatches and zero maximum LSB. Five order-rotated rounds at repeat one and
repeat ten follow. O wall and complete Host wall must strictly improve by
ordinary and paired medians at both repeat counts. PC-027 and PC-028 close the
experiment. A local pass remains pending explicit user adoption.
