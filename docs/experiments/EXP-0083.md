# EXP-0083 — Wider W4U8 Gate/Up HMX command batches

## Parent and scope

EXP-0079 is the direct source parent and strict batch-eight control. Rejected
EXP-0080 through EXP-0082 are siblings and are not inherited. Preserve the
EXP-0079 persistent MLP workers, dependency-driven integer Attention, W4 and
U8 arithmetic, qparams, layouts outside the Gate/Up bounded ring, exact 8 MiB
VTCM request, zero intermediate DDR, one FastRPC Execution Unit, one HMX owner
and no QNN path.

## Evidence-driven hypothesis

EXP-0049 proved that coarsening Gate/Up HMX consumption from batch four to
batch eight reduced the Gate/Up pipeline by a further 3.1 percent after the
larger command-cadence defect had already been fixed. The current layer still
submits 48 Gate/Up HMX commands for 384 output tiles. Each command handoff
crosses two project-owned QuRT semaphores and delays release of expanded slots
and publication of completed Gate/Up pairs.

The current 8 MiB physical budget has enough unused phase-local capacity to
test batch sixteen and batch thirty-two without changing stored weights or
creating an intermediate DDR boundary. The experiment asks whether reducing
Gate/Up commands from 48 to 24 or 12 shortens the complete critical path, or
whether the longer delay before SwiGLU pair publication offsets the saved
command cadence.

## Bounded search and gates

The search contains exactly the EXP-0079 batch-eight control, batch sixteen,
and batch thirty-two. Each candidate gives the expanded-weight ring one slot
per output in the HMX batch and the Gate/Up pair ring one slot per output pair;
this prevents in-batch slot reuse. No deeper producer lookahead claim is made.
The packed-W4 DMA order, 32-K-tile generation handoff, three persistent Gate/Up
HVX contexts, integer-HMX tile order, activation LUT, Down path, Attention and
all other block stages remain unchanged.

Final output and all audited boundaries must be byte-exact to EXP-0079 and the
independent reference. Every candidate must retain 512 weight-DMA descriptors,
25,444,352 weight bytes, 49,408 U8xS8 tile pairs, exact 8 MiB acquired VTCM,
zero intermediate DDR, zero spill/fill, one FastRPC invocation, one HMX owner
and no QNN dependency. Gate/Up HMX commands must be 48, 24 and 12 for batch
eight, sixteen and thirty-two respectively; measured peak plan bytes must fit
inside the fixed request.

Smoke timing selects at most one wider candidate. A wider candidate advances
to formal measurement only if it is byte-exact and lowers the Gate/Up ledger
without an obvious complete-wall regression. The formal local gate requires
both Gate/Up ledger time and complete Host wall to improve over batch eight in
ordinary and seven-round paired medians at repeat one and repeat ten. PC-027
and PC-028 closure are mandatory. Failure rejects the wider command cadence
and returns the source parent to EXP-0079.
