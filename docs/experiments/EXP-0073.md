# EXP-0073 — Share one prebuilt SOLE Softmax LUT-template bank

## Parent and scope

EXP-0072 is the direct source control. Preserve its six-context residual,
parallel Input RMSNorm, per-GQA-group QK/AV HMX commands, paired-head integer
Softmax, projections, MLP, qparams, layouts, VTCM plan, and every numerical
byte. Change only where the constant SOLE probability LUT-template bank is
built and read.

## Hypothesis

The current paired-head Softmax builds the same fourteen 32-byte SOLE LUT
templates independently inside each of eight GQA-group tasks. The templates
depend only on the fixed SOLE division approximation, not on the group, head,
row, score, or qparam. Building one 448-byte bank before worker dispatch and
letting every group read it from an already-reserved Softmax scratch region
should remove seven redundant builds without changing any row computation.

## Gates

The control retains eight per-group template builds. The candidate builds one
shared read-only bank in group-zero's existing VTCM Softmax scratch and passes
that pointer to all group tasks. No allocation, VTCM-plan, scratch-size,
Softmax approximation, task scheduling, HMX, projection, residual, MLP, DMA,
or qparam change is allowed.

Final output and audited Input-RMSNorm/QK/probability/AV boundaries must remain
byte-exact to EXP-0072 and the independent implementation reference. Exactly
8 MiB VTCM, zero intermediate DDR, zero spill/fill, one FastRPC Execution
Unit, one HMX owner, and no QNN are mandatory. At repeat one and repeat ten,
the Attention ledger and complete Host wall must strictly improve in ordinary
and paired medians. Seven interleaved paired rounds and PC-027/PC-028 closure
are required.
