# EXP-0008 — Apply W4 per-channel scale in HMX accumulator conversion

## Approval

Approved by the user on 2026-08-27 as the next optimization of the standalone
Packed-W4 path. The requested outcome remains an effective self-speedup rather
than parity with Qualcomm QNN.

## Objective

Remove per-weight scale multiplication from the HVX W4 expansion kernel. The
EXP-0007 path expands each signed nibble `q4[k,n]` and immediately computes
`q4[k,n] * scale[n]`, which performs scale work over K-by-N elements. Because
the scale is constant for each output channel, the equivalent formulation is:

`sum_k (u8[k] - zp) * (q4[k,n] * scale[n])`

`= scale[n] * (sum_k (u8[k] - zp) * q4[k,n])`.

The candidate therefore expands W4 only to its signed S8 q4 carrier, accumulates
U8-by-S8 on integer HMX, applies the activation-zero-point correction in the
unscaled accumulator domain, and encodes the per-output scale in the HMX bias /
convert state. This changes scale work from the K-by-N expansion domain to the
M-by-N output-conversion domain and leaves stored packed-W4 bytes unchanged.

## Fixed contract

Gate/up remains `M=64, K=2048, N=6144`; down remains
`M=64, K=6144, N=2048`. Activations are asymmetric U8 with zero point 128,
weights are signed symmetric W4 in `[-7, 7]`, and the synthetic exact scales
remain positive integers in `[1, 18]`. The selected EXP-0007 physical plan is
fixed at four compressed slots, 32 K tiles per chunk, eight expanded chunk
slots, and six HVX workers. DDR boundaries, FastRPC scope, User DMA, VTCM
layout, HMX instruction family, output U8 saturation, clocks, and performance
vote are unchanged.

The Expanded-S8 observation control and the EXP-0007 HVX-prescaled Packed-W4
path are retained. The only candidate change is whether q4 scale is applied in
HVX before HMX or once per output channel by the HMX conversion state after
accumulation.
