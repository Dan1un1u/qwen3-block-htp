# EXP-0150 — Real 28-layer Qwen3 transformer stack

## Decision and purpose

The user approved continuation to the next stage on 2026-09-01 after
EXP-0149 passed. EXP-0150 is the PC-005 and PC-034 full-transformer-stack
integration gate. It expands the accepted three-layer runtime to all 28 Qwen3
transformer layers while preserving the numerical recipes, kernels, cache ABI,
VTCM plan and layer-handoff contract. It is not a cache-native Attention
optimization and has no speed gate or baseline-promotion authority.

## Fixed scope

The source parent is EXP-0149 commit
`f75c5e0e0b6ec09ac4422496a9254d82092e9e40`. A declared full-model teacher
supplies only the real embedding hidden state entering layer 0 and the position
metadata for prompt positions 0-63 and decode positions 64-71. The runtime
executes layers 0 through 27 inside one DSP Execution Unit. Every layer output
feeds the next layer through the existing phase-overlaid VTCM buffers; Host
hidden-state handoff, intermediate DDR and per-layer FastRPC calls are forbidden.
The output boundary is layer 27 before the model's final RMSNorm or LM head.

The versioned Prepared Decode Session activates all 28 layer descriptors.
Every layer computes and appends its own K/V. All cache lengths start at zero,
reach 64 after prefill and advance in lockstep to 72 after eight decode steps.
Persistent per-layer K/V and immutable weights are legal DDR state and their
traffic is reported separately. The runtime requests exactly 8 MiB VTCM once,
retains one HMX owner and reuses one block Physical Plan across layers.

## Staged gates

Stage A generates immutable F16F16, W4F16 and W4U8 packages plus independent
full-stack references. Static audit must prove all layer offsets and the total
shared-memory size fit the declared ABI. A device mapping smoke then proves the
complete package can be represented by rpcmem and FastRPC without a Host refill.
If that gate fails, work stops to redesign the package ABI; it must not fall
back to 28 Host calls.

Stage B runs a real 64-token prefill. Stage C runs eight continuous decode steps
for positions 64-71. The FP16 variants retain the approved composition-aware
elementwise gate `abs(actual-reference) <= 0.0625 +
0.002*abs(reference)`, require no non-finite values and cosine at least
`0.99999`. W4U8 requires zero LSB against its independent integer-path
reference. Final layer-27 output and all 28 layer caches are validated after
prefill and every decode step. Physical execution requires one FastRPC call per
full-stack step, exact 8 MiB VTCM, zero intermediate DDR, zero spill/fill, one
HMX owner and no QNN.

Only after correctness and physical gates pass is formal repeat-one and rotated
repeat-ten profiling collected. The report must close the complete stack ledger
and retain per-layer ledgers and cache traffic. Latency is characterization
evidence only. Passing EXP-0150 permits a separate cache-native W4U8 decode
Attention experiment; it does not silently introduce that specialization or
extend scope to tokenizer, sampler, final model norm or LM head.

## Stage A result — stopped at the package-capacity gate

The static audit completed on 2026-09-01 and failed before package generation
or device execution. Each Qwen3 layer contains 50,331,648 projection weight
elements, so the required F16F16 carrier is 100,663,296 bytes per layer and
2,818,572,288 bytes for 28 layers. The current Host path deliberately rejects
any package larger than `INT_MAX` before calling the signed-int
`rpcmem_alloc` API. The F16F16 immutable projection weights alone exceed that
2,147,483,647-byte limit by 671,088,641 bytes, before the request header,
alignment, references, norms, qparams, caches or runtime carriers are added.

Accordingly, the package-mapping gate is a deterministic failure under the
single-rpcmem/single-shared-fd ABI. EXP-0150 is aborted at Stage A as required;
it did not generate a partial package, contact the device, refill weights
between layers or fall back to 28 Host calls. The valid evidence is
`D:/llm_exp/results/qwen3-block-htp/exp0150/20260901T150000Z_f75c5e0e0b6e_static_gate/package_capacity.json`
with SHA-256
`656a64118c69895db8ab41aa9229fc243afae1a6a2a75dbeb3638c2f65d9d039`.
Source commit `8f46fb8` contains the reproducible lower-bound audit.

Resuming the full-stack work requires a separately approved ABI experiment.
The recommended design is persistent segmented mapping: keep one small control,
state and cache arena plus two immutable weight arenas split at the layer-14
boundary. Each allocation remains below `INT_MAX`; all arenas are mapped before
execution and remain resident; projection descriptors gain an arena identifier
and a 32-bit offset within that arena; one full-stack FastRPC call and one HMX
owner remain mandatory. Host refill, per-layer RPC and recipe changes remain
forbidden.
