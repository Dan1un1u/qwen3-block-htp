# EXP-0165 — W4F16 prefill generation-boundary pipeline

## Decision and purpose

The user approved a stepwise optimization of the input/output work newly added
by EXP-0164. The accepted transformer and cache implementation is held fixed.
EXP-0164 measures 82.912 ms for the complete M64 token-to-token prefill while
its earlier transformer-only control measures 54.443 ms on a smaller boundary.
Within the new boundary, embedding and final model RMSNorm together cost about
0.11 ms, while the correctness-first streamed W4 LM head and greedy argmax cost
26.443 ms. EXP-0165 therefore targets the LM-head pipeline first without
assuming that local work reduction equals end-to-end speedup.

## Allowed implementation scope

The source parent is EXP-0164 at
`6a6801193f16fff3ef5e88a25a87f0600b40c18f`. Changes may affect token
embedding, final model RMSNorm, streamed per-output-channel W4 LM-head
execution, online greedy argmax, their VTCM buffer lifetime, and DMA/HVX/HMX
scheduling across those stages. Layers 0-27, projection schedules, Attention,
MLP, persistent KV-cache representation, W4 values, per-output scales,
tokenizer, prompt and expected token sequence are immutable.

The direct control is the complete EXP-0164 token-to-token implementation, not
the smaller EXP-0158 transformer-only replay. Control and candidate must be
measured in rotated pairs. The optimization must not materialize full logits in
the timed path or move DSP work into an unattributed/Host bucket.

## Gates

The selected token, continuous 16-token sequence and decoded text must remain
identical to EXP-0164 and its independent W4F16 reference. The existing
EXP-0158 hidden/cache regression remains mandatory. Physical execution must
retain exactly 8 MiB VTCM, one FastRPC call per pass, no QNN, zero inter-layer
hidden or timed full-logit DDR traffic, zero spill/fill and a closed additive
ledger.

The adoption metric is the median paired improvement of repeat-ten complete
M64 Prefill Host wall. The candidate must be strictly faster than the EXP-0164
control. The aggregate embedding/final-norm/LM-head ledger must also decrease as
a diagnostic. Decode latency is reported because the same output head is used,
but it is not the promotion metric for this prefill-scoped experiment.
