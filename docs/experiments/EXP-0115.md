# EXP-0115 — W4F16 direct low-nibble vlut16 decode

## Decision and scope

The user authorized a continuing W4F16/W4U8 recipe-specialization loop. After
EXP-0114 showed that the remaining join barrier is below critical-path
significance, EXP-0115 returns to the actual W4-to-FP16 decode work. It derives
from EXP-0112 and uses EXP-0111 `join_only` as its W4F16 control. No public,
F16F16, W4U8, Attention, Down or QKV behavior changes.

## Hypothesis

The current packed-W4 FP16 expansion loop loads one 128-byte packed vector,
computes low nibble indices with `vand 0x0f`, shifts high nibble indices, then
performs the existing deal, `vlut16`, shuffle and four vector stores required
by the FP16 HMX Crouton carrier. Its disassembly executes one vector `vand` for
every packed vector.

The retained htp-ops-lib Q4-to-FP16 path feeds the packed low-nibble bytes
directly to Hexagon `vlut16`, explicitly noting that masking is unnecessary.
EXP-0115 tests whether the same property applies to our signed-nibble FP16
table and physical layout. Removing one HVX instruction per packed vector
targets the real expansion work rather than another synchronization term.

## Fixed boundary and gates

Control is EXP-0111 `join_only` with the masked relaxed unpack helper. The sole
candidate uses a separate relaxed helper for both main and pool-worker parts of
W4F16 Gate/Up groups. That helper replaces only `low = packed & 0x0f` with the
packed byte vector itself; high-nibble shift, deal, `vlut16`, output shuffle,
stores and all publication ordering remain identical. Other projections keep
the established helper.

The candidate must be byte-exact at final output and pass the independent
W4F16 expansion audit with zero mismatch and zero maximum LSB. Static
disassembly must show the candidate lacks `vand` while retaining the same
decode and store structure. Exact 8 MiB VTCM, zero intermediate DDR and
spill/fill, one FastRPC execution unit, one HMX owner, unchanged physical work
and no QNN remain hard gates. Gate/Up plus SwiGLU and complete Host wall must
both strictly improve in ordinary and paired repeat-one and repeat-ten medians
over five rounds. PC-027 and PC-028 are mandatory; no local pass automatically
promotes a baseline.
