# EXP-0075 — Dependency-driven row-sliced W4U8 Attention stream

## Parent and scope

EXP-0072 is the direct source control. EXP-0074 is evidence that sixteen
32-row Softmax tasks reduce the Attention tail, but its three full-pool stage
barriers are rejected and must not be inherited. Preserve EXP-0072 arithmetic,
six-context pool, Q/K preparation, paired-head QK/AV HMX commands, projections,
MLP, qparams, layouts, exact 8 MiB VTCM and zero-intermediate-DDR contract.

## Hypothesis

The EXP-0074 Attention ledger improves about 4.6%, while repeat-one complete
Host wall fails only at the global QK-to-Softmax and Softmax-to-AV stage
boundaries. A single dependency-driven scheduler can publish each GQA group
independently: QK completion exposes two 32-row Softmax tasks, and completion
of both slices exposes that group's AV task. Existing contexts may steal ready
Softmax or AV work without waiting for unrelated groups. This should retain
row-level load balancing while eliminating whole-Attention barriers.

## Gates

The candidate may change only Attention dependency state, task claiming and
context-local Softmax scratch. It must contain no full-pool QK/Softmax/AV stage
barrier. The row algorithm, SOLE LUT values, mask, qparams, tensor bytes, QK and
AV HMX tile math, 176 total HMX commands, 49,408 tile pairs, one HMX owner and
all weight traffic remain unchanged.

Final output and audited QK/probability/AV boundaries must remain byte-exact to
EXP-0072 and the independent implementation reference. Exactly 8 MiB VTCM,
zero intermediate DDR, zero spill/fill, one FastRPC Execution Unit and no QNN
are mandatory. At repeat one and repeat ten, both the Attention ledger and
complete Host wall must strictly improve in ordinary and seven-round paired
medians. PC-027 and PC-028 closure are required.

## Result

Implementation commit `8e3fe8561e5b1bf994d20f8e93c96dd6087c0af2`
completed the dependency stream. Formal evidence is retained at
`D:/llm_exp/results/qwen3-block-htp/exp0075/20260830T112231Z_8e3fe8561e5b_formal`.
The final block output and audited Input RMSNorm, QK, probability and AV
boundaries are byte-exact to EXP-0072 and the independent reference, with zero
mismatches and zero maximum LSB error. The candidate executes sixteen Softmax
row tasks with no global Attention stage barrier while preserving 176 HMX
commands, 49,408 HMX tile pairs, all weight traffic, exact 8 MiB VTCM, zero
intermediate DDR, zero spill/fill, one FastRPC Execution Unit, one HMX owner,
and no QNN dependency.

At repeat one, Attention falls from 4,698 to 3,780 ticks (-19.54%, paired
-19.75%) and Host wall falls from 2,494,375 to 2,443,542 ns per block (-2.04%,
paired -2.10%). At repeat ten, Attention falls from 4,706.0 to 3,781.6 ticks
(-19.64%, paired -19.41%) and Host wall falls from 2,067,552.1 to 2,027,734.4
ns per block (-1.93%, paired -1.99%). Aggregate Softmax work increases only
0.89% at repeat ten, versus 7.84% in rejected EXP-0074, and pipeline wait
increases 4.12% rather than 133.82%.

## Decision

All repeat-one and repeat-ten correctness, physical, ordinary-median and
paired-median gates pass. EXP-0075 becomes the latest locally eligible W4U8
candidate and the provisional source parent for the next profiling-guided
experiment. It is not promoted to Selected Baseline without explicit user
approval.
