# EXP-0091 — Interleaved W4U8 nibble decoder

## Decision and motivation

The user authorized continuing the autonomous profiling-guided loop on
2026-08-31. The direct source parent is the accepted EXP-0084 fair W4U8
baseline. EXP-0089 and EXP-0090 remain rejected and are not inherited.

Gate/Up plus SwiGLU remains the largest W4U8 module. EXP-0090 proved that ready
SwiGLU tasks do not wait behind a material FIFO backlog, while accepted-path
profiling still shows Gate/Up HMX ready-wait comparable to HMX compute. A V79
disassembly of `qbh_unpack_w4_to_s8_hvx` at the accepted implementation shows a
single-vector loop: one packed load, low/high nibble extraction, two consecutive
`vlut32` operations, one shuffle and two stores. The compiler did not unroll or
interleave an independent second vector. This experiment tests whether explicit
software pipelining can hide LUT and memory latency without changing the proven
lookup arithmetic.

## Fixed contract

The Execution Unit is the real Qwen3-1.7B layer-14 complete block at M=64. The
Project Variant is W4U8 and the direct control is
`W4U8-EXP0084-FAIR-CANONICAL`. Preserve byte-identical packed W4 values, expanded
S8 values, asymmetric-U8 qparams, projection arithmetic, layouts, task counts,
tensor traffic, output codes, DMA descriptors, HMX commands and tile pairs.
Preserve all Attention, residual, SwiGLU and Down behavior during the Gate/Up
isolation gate.

The candidate may only interleave independent packed-vector iterations inside
the existing `vlut32` W4-to-S8 decoder. It may not replace lookup decoding with
the rejected EXP-0082 arithmetic decoder, add HVX workers, change queueing,
change tile or command granularity, create a second HMX owner, or move an
intermediate to DDR. Formal runs require one FastRPC per block, exactly
8,388,608 acquired VTCM bytes, zero intermediate DDR and spill/fill, no QNN,
512 weight-DMA descriptors, 176 HMX commands and 49,408 U8-by-S8 tile pairs per
block.

## Serial milestones

### Stage A — static schedule gate

Disassemble the accepted decoder and preserve the output as evidence. The gate
passes only if its hot loop lacks compiler-generated unrolling or independent
vector interleaving. Inspect the candidate disassembly and require at least two
independent packed vectors to have their loads, nibble extraction, LUTs and
stores interleaved in the hot loop. Stop before hardware timing if the compiler
collapses the candidate back to the same single-vector dependency chain.

### Stage B — Gate/Up isolation gate

Select the interleaved decoder only for the Gate/Up projection; QKV, O and Down
retain the accepted decoder. Start with two-way interleaving and test four-way
only if two-way improves decoder work without creating register spill or code
path regression. Run five interleaved control/candidate rounds at repeat one and
repeat ten. Gate/Up and complete Host wall must strictly improve in ordinary and
paired medians at both repeats, with no material regression in other modules.

### Stage C — optional common-decoder confirmation

Only if Stage B passes, extend the selected decoder to QKV, O and Down and run
seven interleaved paired confirmation rounds. Correctness requires byte-exact
final output, middle activation, Down output, QK, probability and AV boundaries
with zero mismatch and zero maximum LSB. Complete PC-027 and PC-028. A local
pass remains a candidate until the user explicitly promotes it.

## Result

Completed with valid evidence and rejected. The accepted decoder had one packed
vector, two `vlut32` operations and no independent interleaving in its hot loop.
The candidate compiled to two independent packed vectors and four interleaved
`vlut32` operations without stack spill, so the static gate passed.

Five interleaved control/candidate rounds preserved the final output and audited
Attention boundaries byte-for-byte with zero mismatch and zero maximum LSB.
The physical contract also remained exact: 8 MiB requested/acquired VTCM, zero
intermediate DDR and spill/fill, 25,444,352 weight bytes, 512 DMA descriptors,
176 HMX commands and 49,408 U8-by-S8 tile pairs per block.

The instruction schedule did reduce aggregate MLP W4 expansion by 5.29% at
repeat one and 5.32% at repeat ten. Expanded-slot wait fell by about 11%–12%
and HMX ready-wait fell by about 3%. This did not shorten the Gate/Up critical
path: Gate/Up regressed by 1.24% at repeat one and 0.95% at repeat ten, while
MLP HMX compute increased by about 5.1% and 4.1%. The evidence indicates that
denser HVX decoding increased simultaneous contention with HMX even though the
decoder itself became faster. Stage C and four-way widening were therefore not
run. EXP-0084 remains the accepted baseline.
