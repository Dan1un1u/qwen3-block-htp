# EXP-0205 — Direct-W4 decode Down-projection batch4 command granularity

## Decision and purpose

EXP-0205 inherits the evidence-valid EXP-0204 candidate. Direct-W4 Down still
uses two output tiles per HMX command. The candidate raises only Down from
batch2 to batch4. It should halve Down HMX commands and reduce weight-DMA
descriptor groups without increasing bytes or HMX tile work.

## Gates

One binary compares Down batch2 and batch4. Correctness requires byte-exact
hidden, cache, selected-code and token outputs. The exact 8 MiB VTCM,
zero-intermediate-DDR, zero-spill/fill, one-FastRPC, one-HMX-owner, no-QNN and
zero-explicit-W4-expansion contracts remain mandatory. Packed-W4 bytes and HMX
tile pairs must remain identical; Down commands and DMA descriptors must fall.

Five rotated pairs must improve both Down wall and directly measured full
decode token/s before ten formal pairs may run. The user's consecutive
local-win/E2E-regression stop gate remains active.

## Decision state

Approved and registered on 2026-09-05 under the continuous decode-loop
authorization and completed on the same day. During bounded bring-up, the
first batch4 implementation reset cDSP because its upper packed-W4 half reused
a VTCM range occupied by persistent decode-cache state. Moving the two batch4
carriers to the phase-dead Expanded-S8 weight slots fixed the lifetime alias;
the retained implementation then restored DMA--HMX overlap. This is part of
the accepted implementation, not a performance result from a serialized debug
path.

The five-pair short gate and ten-pair formal gate both pass on source commit
`fb2d4c0fb34aaee771f496dc1d9ea600a496a8fc`. Formal decode improves from
43.957344 to 44.261504 token/s (+0.691943%), with all ten pairs faster. Down
wall falls from 4179.5 to 4016.2 us/token. Down HMX commands halve from 896 to
448; total direct-N HMX commands fall from 1829 to 1381 and weight-DMA
descriptors from 3510 to 3062. Packed-W4 bytes and 1,699,840 HMX tile pairs are
identical. Outputs are byte exact and the exact-8-MiB, zero-intermediate-DDR,
zero-spill/fill, one-FastRPC, one-HMX-owner, no-QNN and zero-expansion gates all
pass. M64 prefill is unchanged at 1292.170 versus 1292.542 token/s measurement
noise.
