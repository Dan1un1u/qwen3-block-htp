# EXP-0205 — Direct-W4 decode Down-projection batch4 command granularity

## Decision and purpose

EXP-0205 inherits the evidence-valid EXP-0204 candidate. Direct-W4 Down still
uses two output tiles per HMX command even though the existing compressed
double buffers are explicitly sized for the safe four-tile geometry. The
candidate raises only Down from batch2 to batch4. It should halve Down HMX
commands and weight-DMA descriptor groups without increasing bytes or HMX tile
work and without using the phase overlay needed by larger batches.

## Gates

One binary compares Down batch2 and batch4. Correctness requires byte-exact
hidden, cache, selected-code and token outputs. The exact 8 MiB VTCM,
zero-intermediate-DDR, zero-spill/fill, one-FastRPC, one-HMX-owner, no-QNN and
zero-explicit-W4-expansion contracts remain mandatory. Packed-W4 bytes and HMX
tile pairs must remain identical; Down commands and DMA descriptors must fall.

Five rotated pairs must improve both Down wall and directly measured full
decode token/s before ten formal pairs may run. The user's consecutive
local-win/E2E-regression stop gate remains active.
