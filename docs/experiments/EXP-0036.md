# EXP-0036 — Crouton-native Gate/Up-to-SwiGLU handoff

## Approval and status

Approved by the user on 2026-08-29 after reviewing the formal EXP-0032
complete-block profile. The experiment starts from the fastest valid EXP-0032
source commit `91ba193660513bd0675c0a091db199aa09df1773`. This source choice does
not promote EXP-0032 or EXP-0036 to Selected Baseline.

## Motivation

At repeat ten, the fastest W4F16 control spends 21,786.2 qtimer ticks, or 48.7
percent of the complete DSP ledger, in Gate/Up plus streaming SwiGLU. Gate and
Up contain twice the Down projection MACs and packed-weight bytes, but their
exclusive interval is 3.47 times Down and improves only 0.68 percent over the
fair F16F16 Gate/Up control. Down improves 29.9 percent.

The retained streaming path still unpacks each Gate and Up HMX Crouton result
to full row-major tensors, computes SiLU-by-Up into a full row-major Middle
tensor, and repacks each 64-channel group to the Down Crouton activation.
Because elementwise SwiGLU preserves element correspondence regardless of
layout, these row-major round trips are not mathematically required.

## Fixed contract

- The Execution Unit is the real Qwen3-1.7B layer-14 complete block at `M=64`,
  measured with repeat one and repeat ten in one FastRPC invocation.
- The Stage A control is EXP-0032 W4F16 batch-four + DMA-eight + pre-encoded
  scale cache at source commit `91ba193660513bd0675c0a091db199aa09df1773`.
  Attention, QKV overlap, residuals, norms, Down projection, W4 values, scales,
  FP16 activation arithmetic, HMX arithmetic, and standard Softmax are fixed.
- Stage A may change only the Gate/Up output lifetime and the SwiGLU-to-Down
  physical handoff. Matching Gate and Up HMX output tiles use bounded VTCM ring
  slots. HVX applies the existing FP16 SiLU-by-Up instruction sequence directly
  in Crouton order and writes each result to its final Down activation tile.
- Full row-major Gate, Up, and Middle tensors may be omitted from the timed
  path only if audit-mode evidence proves byte-identical Down input and final
  block output. They may not be replaced by DDR workspaces.
- Every mode requests and receives exactly 8,388,608 VTCM bytes. Intermediate
  DDR, spill/fill, a second FastRPC execution unit, QNN, and QAIRT are failures.
  One serialized HMX owner is retained.
- Equivalent-scope Host wall is primary. The exclusive Block Timing Ledger and
  overlapping DMA/HVX/HMX work counters remain separate.

## Ordered milestones

### A1 — Crouton element-correspondence proof

Audit the existing HMX output and Down activation tile address maps. Prove that
Gate and Up tiles share identical logical-to-physical element order and that a
tile-local elementwise result can be written directly at the corresponding
Down K-tile offset without transpose or row-major staging.

### A2 — Batch-four ring implementation

Introduce bounded Gate/Up Crouton output slots with generation-tagged producer
and consumer handoff. While HMX advances to a later Gate/Up group, HVX consumes
a completed pair, executes unchanged SiLU-by-Up SIMD, and writes the final Down
Crouton carrier. Remove timed row-major Gate/Up/Middle materialization and the
associated unpack/repack work.

### A3 — Stage A formal gate

Collect audit-on correctness and five alternating audit-off repeat-one and
repeat-ten runs for the immutable control and candidate in one stable boot.
The candidate must be byte-identical, strictly reduce the Gate/Up exclusive
interval, and strictly reduce complete-block Host wall at both repeat counts.
It must keep zero intermediate DDR, zero spill/fill, one HMX owner, and the
fixed 8 MiB VTCM grant. If any condition fails, stop before Stage B.

### B — Batch-eight follow-up, conditional on Stage A

Only after Stage A passes, use the released VTCM to test eight output tiles per
Gate or Up HMX command, reducing Gate/Up command count from 96 toward 48. Give
F16F16 the same batch-eight search opportunity and use its fastest valid plan
as the fair comparator. Stage B must retain Stage A mathematics and physical
contracts and improve both Gate/Up and complete-block Host wall at repeat one
and repeat ten.
