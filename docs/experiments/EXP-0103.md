# EXP-0103 — Interleaved two-head U8 Q/K Norm-RoPE kernel

## Decision and motivation

The accepted EXP-0084 already assigns two adjacent Q or K heads to one HVX
task, batches 16 rows through one vector reciprocal-square-root call, and
shares preconverted RoPE coefficients. Inside that paired task, however, the
two heads still execute the complete SF32 gamma, normalization, RoPE and
requant chain serially. Formal repeat-ten evidence attributes about 28.5k
overlapping work ticks to the W4U8 Q/K Norm-RoPE path versus about 6.3k for the
W4F16 FP16 worker path, while W4U8 retains roughly 1.2k pool-join ticks.

EXP-0103 tests a genuinely paired HVX microkernel. It loads and converts both
heads together, shares splatted norm/output constants, interleaves independent
QH-float operations to expose instruction-level parallelism, and packs both
heads before moving to the next row. It preserves the existing batched rsqrt,
shared RoPE cache, Q/K task pairing and projection/Attention schedule.

## Fixed contract and gates

This is a clean sibling from accepted EXP-0084. Packed W4 weights, U8 qparams,
row/head order, gamma, RoPE coefficients, reciprocal-square-root values,
per-head floating operation order, rounding, output packing, projection
commands, Attention, residuals and MLP remain fixed. Control uses the existing
serial-inner-pair helper; candidate uses the interleaved two-head helper in the
same binary. No arithmetic reassociation, approximate fixed point or qparam
change is allowed in this experiment.

Audit-on control and candidate must be byte-exact at Q/K Norm-RoPE outputs,
score, probability, AV and final block output with zero mismatches and zero
maximum LSB. Compiler/static evidence must show the candidate paired helper,
shared norm/output vector constants and no vector stack spill in the hot loop.

Both cells request/acquire exactly 8 MiB VTCM, keep the same peak plan, one
FastRPC and one HMX owner, and perform zero intermediate DDR and spill/fill.
Weight bytes, DMA descriptors, HMX commands and 49,408 U8-by-S8 tile pairs are
unchanged. Five order-rotated rounds at repeat one and repeat ten require
Q/K Norm-RoPE work, QKV wall and complete Host wall to strictly improve by
ordinary and paired medians at both repeat counts. PC-027 and PC-028 close the
experiment. A local pass remains pending explicit user adoption.
