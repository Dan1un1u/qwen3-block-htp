# EXP-0066 — Elide probability row-sum reductions outside numerical audit

## Parent and scope

EXP-0065 is the direct source control. Preserve its SOLE LUT templates,
paired-head QK requantization, QK2/AV4 HMX command batching, qparams, mask,
probability encoding, V packing, projection schedules, residuals, and MLP.
Change only whether diagnostic probability row sums are evaluated when the
numerical-audit telemetry pointer is absent.

## Hypothesis

The performance path currently reduces both 64-lane probability halves and
updates row-sum minima and maxima for every paired row even though those values
are discarded when telemetry is null. Restricting those two reductions and the
min/max bookkeeping to numerical-audit mode removes 1,024 unnecessary half-row
reductions per block. Audit mode must retain the original calculations and
reported values exactly; probability bytes are never changed.

## Gates

Control and candidate must be selectable in one binary. In audit mode, row-sum
telemetry and final output, QK, probability, and AV boundaries must remain
byte-exact to EXP-0065 and the independent implementation reference. Exactly
8 MiB VTCM, zero intermediate DDR, zero spill/fill, one FastRPC Execution Unit,
one HMX owner, and no QNN are mandatory. HMX commands, tile pairs, traffic,
qparams, mask semantics, and group scheduling remain unchanged.

At repeat one and repeat ten, Softmax work, the Attention ledger, and complete
Host wall must strictly improve in ordinary and paired medians. Seven
interleaved paired rounds and PC-027/PC-028 closure are required.
