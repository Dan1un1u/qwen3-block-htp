# EXP-0295 — Qwen3-0.6B long-prefill migration

Full-model hardware arithmetic and physical checks pass. Throughput parity is reported independently below; implementation completion is not automatic baseline promotion.

## Contract

Frozen W4A8-SP2 mode8, FP32 residual2, no rotation, 28 layers. Preserve Q/K RMSNorm and Qwen wide4 raw-difference/NR64 attention arithmetic; do not substitute Llama wide8/scaled-score arithmetic. No prefix seed.

Fullmodel M64 chunks, absolute RoPE, persistent row-major KV capacity832, correct tail rows, final-prompt-chunk head. Prompt<=768, decode<=63. All timed calls retain exact8MiB VTCM and no intermediate-DDR/spill. All weights/calibration unchanged.

Five short rotated rounds are auxiliary; ten formal rotated six-arm rounds × repeat10, every sample retained. Fixed project-owned prompt and teacher-forced token trajectory, not a named-dataset/quality benchmark. D counts decode RPC steps; prefill already selects the first output token. Full warm Host wall includes embedding, all layers, final norm/head/greedy and FastRPC; long paths include host input/RoPE staging. Cold loading, tokenizer, audit and log output are excluded. Native short control uses its pre-existing timing boundary with no added host-staging charge, conservatively favoring that control.

Qwen had no prior supported long runtime. opt11 is a basic vectorized sequential-GQA long control; opt31 adds bounded concurrent GQA clients. Both retain native K/V packing and native4 softmax. Freshly ported scalar opt0 diagnostics are retained but excluded from formal speedup claims. Native segmented-cache M64 and long-row-major M64 are both measured, and parity uses the faster one.

## Remaining limits

Long prefill method is implemented and verified. One-row long-cache decode still uses sequential dynamic attention/full-prefix preparation; the four-client path is admitted only for rows>1. Projection/Down/head reuse remains intact. Native short-cache efficiency must not be inferred for long decode; a long-cache decode specialization remains future work.

No new PPL/text-quality assessment, no rotation, no A16/ordinary-A8 long migration, no paper-baseline promotion. Named datasets remain unmeasured.
