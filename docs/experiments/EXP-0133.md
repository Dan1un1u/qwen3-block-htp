# EXP-0133 — W4F16 Gate/Up balanced static HVX partition

## Decision and hypothesis

EXP-0132 proved that fixed two-region claims remove almost all stream-join tail
but split ten pool regions unevenly and regress Gate/Up. EXP-0133 keeps the
same three HVX contexts, region-32 group, main-context share, DMA8, scale cache,
batch-eight HMX commands, arithmetic, carriers, and output. The candidate
instead assigns the ten pool regions once as two contiguous five-region spans,
one per worker. It therefore removes atomic claims and repeated decode calls
without changing the balanced 6/5/5 main/worker work budget.

## Gates

Static partitioning is legal only for W4F16 Gate/Up join-only expansion. Both
cells must remain byte exact at `f18b9abbe1487231`, pass expansion audits,
request exactly 8 MiB VTCM, retain zero intermediate DDR/spill, one FastRPC
unit, one HMX owner, no QNN, and identical physical work. The candidate passes
only if Gate/Up plus SwiGLU and complete Host wall strictly improve in ordinary
and paired repeat-one and repeat-ten medians. Formal closure requires PC-027
and PC-028; only the user may promote a Selected Baseline.

## Result

Formal evidence is archived at
`D:/llm_exp/results/qwen3-block-htp/exp0133/20260901T014439Z_646ded5a54bf_formal`.
Both cells preserve output `f18b9abbe1487231`, zero expansion mismatch, exact
8 MiB VTCM, zero intermediate DDR/spill, one FastRPC unit, one HMX owner, and
identical physical work.

The balanced partition lowers repeat-ten expansion elapsed 0.288%, pool wait
26.976%, HMX wait 0.373%, and Gate/Up 0.160%. Those local gains are real but
too small and do not close at the block boundary: ordinary repeat-ten Host wall
regresses 0.149%. Repeat-one Host improves 0.242%, while Gate/Up regresses
0.250%. The strict gate therefore fails.

Dynamic claim overhead is not a meaningful critical-path term. Static 6/5/5
partitioning is retained as evidence but rejected for adoption. Reopen only if
an additional worker changes the main-context share or if expansion scheduling
can be fused with the downstream streaming join.
