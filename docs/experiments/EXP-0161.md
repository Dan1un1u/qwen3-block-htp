# EXP-0161 — Long-KV scaling and segmented HMX-native W4U8 cache

## Decision and purpose

EXP-0160 is the user-promoted Selected Full-Stack W4U8 Cache-Native Baseline.
It overlaps compact-base DMA and HVX tail reconstruction across GQA groups and
reduces positions 64-71 decode to 49.042 ms/token. That evidence is bounded to
an eight-token delta journal and cannot establish long-context behavior.

EXP-0161 first measures the selected monolithic reconstruction design at
logical KV lengths 64, 256, 1024 and 4096. If full-length reconstruction or
the two-slot overlay becomes material, the experiment implements an immutable
32-token HMX-native segment format plus one compact mutable tail. QK and AV
then consume segments without constructing a total-length carrier in VTCM.

## Execution and attribution boundary

The immutable source parent is EXP-0160 commit
`b33e88e3971c35851450d0737a0689bd0bd077aa`. The scan reuses EXP-0147's
independent CPU integer-Attention and complete-block references. Each point is
a synthetic single real layer-14 decode snapshot, not continuous decode and
not a full-stack throughput claim.

Phase A converts the existing row-major fixtures into the accepted compact
M64 base plus delta-journal representation and characterizes serial and
two-slot reconstruction. Phase B is activated only if the evidence shows a
material scaling or VTCM-capacity limitation. Its sealed segments are
immutable; only the current sub-32-token tail is appended or sealed.

W4 values, asymmetric U8 qparams, QK/log2-Softmax/AV mathematics, projection
kernels, output contracts and the single HMX owner remain fixed. A16 recipes
are outside this experiment.

## Gates

Every measured length must match the independent block output and current
token cache append with zero U8 LSB error. Formal runs require exactly 8 MiB
VTCM, zero intermediate DDR, zero spill/fill, one FastRPC invocation per block,
one HMX owner and no QNN.

The segmented candidate may not construct or clear a total-length K/V carrier
or perform a full-prefix pack. Its Attention scratch must be bounded by segment
size rather than total KV length; sealed segments remain immutable and only the
active tail may change. It must not slow L64 and must beat the fastest valid
monolithic control at L256, L1024 and L4096 to pass the speed gate.

Any correctness or physical-contract failure stops candidate integration
before it reaches the full-stack runtime. Passing this micrograph does not
change a Selected Baseline without another explicit user decision.
