# EXP-0063 — Fuse QK requantization into Softmax row loading

## Parent and scope

EXP-0062 is the direct source control. Preserve its QKV path, shared RoPE
cache, HMX QK and AV arithmetic, log2 Softmax approximation, qparams, mask,
probability encoding, residual equations, and MLP. Change only the physical
boundary between QK output requantization and the existing Softmax.

## Hypothesis

Each GQA group currently performs a complete in-place U8 requantization pass
over the 8 KiB QK score carrier, executes a barrier, and then reads the same
carrier row by row in Softmax. Applying the exact same HVX requantization to
the row immediately after Softmax loads it can remove the separate carrier
read and barrier. In performance mode the transient requanted score need not
be written back; numerical-audit mode must write every row back so the QK
boundary hash remains authoritative.

## Candidate and gates

Control and candidate must be selectable in one binary. Saturation telemetry,
causal masking, log2 codes, LUT division, probability bytes, AV input, and
final output must remain identical. Final output and QK/probability/AV audit
boundaries must be byte-exact to EXP-0062 and the independent reference.
Exactly 8 MiB VTCM, zero intermediate DDR, zero spill/fill, one FastRPC
execution unit, one HMX owner, and no QNN are mandatory.

At repeat one and repeat ten, the combined QK-requant plus Softmax work,
Attention ledger, and complete Host wall must strictly improve in both
ordinary and paired medians. Seven interleaved paired rounds and PC-027/PC-028
complete profiling closure are required.
