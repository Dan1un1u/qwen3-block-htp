# EXP-0145 — W4U8 Down projection HMX batch-eight

## Decision and hypothesis

The user's continuing autonomous specialization loop authorizes this bounded
W4U8 experiment on 2026-09-01. It uses the evidence-valid EXP-0144 candidate
commit `919aaa74870661d78b92e64976e695a4fa87f955` as an explicit fastest
experimental parent. EXP-0144 remains rejected under its strict preservation
gate and is not a Selected Baseline.

Down is now the second-largest projection after Gate/Up. Its current integer
HMX path already combines both K chunks of four output tiles into one command,
releases the four-slot expanded ring from inside that command, and records
producer progress. The shared runner and request ABI support up to eight batch
outputs, but runtime validation has so far limited Down to one or four.

The hypothesis is that batch-eight can halve Down commands from sixteen to
eight while retaining in-command slot release, allowing DMA and HVX expansion
to refill the four-slot ring during a command. This is different from the
rejected Gate/Up eight-bundle DMA chain: only HMX issue grouping changes, not
the point at which a ready weight bundle is published.

## Gates

Control is the full EXP-0144 SIMD-I/O candidate with Down batch-four.
Candidate changes only Down's nonstreaming HMX batch width to eight. Q/K SIMD
I/O, QKV ring3, Attention, O, residuals, Gate/Up ring16, weights, qparams,
Down math and the Public Common Layer remain fixed.

Both cells must produce byte-exact output `69f22eeb035e5ec5`, zero maximum LSB
and identical existing audits. Exact 8 MiB VTCM, zero intermediate DDR and
spill/fill, one FastRPC Execution Unit, one HMX owner, no QNN, identical
weight/DMA/tile/carrier work and peak plan are mandatory. Only the declared
Down command count and command-grouping telemetry may differ.

The candidate passes only if Down and complete Host wall strictly improve in
ordinary and paired repeat-one and repeat-ten medians over five rotated
rounds, while QKV, Attention and Gate/Up each regress by no more than 0.5% in
any ordinary or paired median. PC-027 and PC-028 are mandatory. A local pass
remains pending user decision and cannot promote a Selected Baseline.

## Formal result and rejection

Formal evidence was collected from source commit
`895febfa3543844ffc376be1d86f19c9e16d114a` on stable boot
`77ccafe0-8817-4976-bdae-15af5608d4ff`. Both cells produced byte-exact output
`69f22eeb035e5ec5`, zero maximum LSB and identical stage audits. Both acquired
exact 8 MiB VTCM with the same 5,306,080-byte peak, zero intermediate DDR and
spill/fill, one FastRPC Execution Unit and one HMX owner.

Batch-eight reduced Down HMX commands from sixteen to eight and total block HMX
commands from 128 to 120. At repeat ten, Down improved 1.486% ordinary / 1.491%
paired and complete Host wall improved from 1,367.734 to 1,356.677
microseconds, 0.808% ordinary / 0.727% paired. The mechanism did not create a
cleaner pipeline: aggregate MLP HMX compute fell 13.279%, while HMX-ready wait
rose 13.267% ordinary / 12.047% paired. At repeat one the paired Host result
regressed 0.141%, and QKV, Attention and Gate/Up exceeded the original
preservation limit.

The original gate therefore fails and the experiment is rejected. Under the
new PC-029 noise rule the sub-one-percent repeat-ten result is not selected
without additional paired confirmation; the user instead explicitly promoted
EXP-0144. This batch-width axis may reopen only with a new producer-progress
mechanism, not another fixed batch-width sweep.
