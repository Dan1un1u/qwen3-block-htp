# EXP-0071 — Parallel W4U8 Input RMSNorm across the persistent HVX pool

## Parent and scope

EXP-0070 is the direct source control. Preserve its per-GQA-group QK/AV HMX
command batching, six-context Attention pool, integer Attention arithmetic,
all projections, residuals, MLP, qparams, layouts, VTCM plan, and every output
byte. Change only execution of the first W4U8 Input RMSNorm.

## Hypothesis

The current Input RMSNorm processes all 64 rows serially on the main HVX
context even though five persistent HVX workers are already created before the
block begins. Splitting disjoint row ranges across the main context and the
existing workers should shorten the centered-square reduction and quantized
native-activation store critical path without changing arithmetic, rounding,
or the QKV handoff.

## Gates

The control retains EXP-0070's serial Input RMSNorm. The candidate dispatches
bounded row tasks to the existing main-plus-five HVX context domain and calls
the same per-row implementation for each task. No batched reciprocal-square-
root approximation, qparam, gamma, layout, projection, Attention, residual,
MLP, DMA, VTCM, or HMX change is allowed.

The final output and Input-RMSNorm native activation boundary must remain
byte-exact to EXP-0070 and the independent implementation reference. Exactly
8 MiB VTCM, zero intermediate DDR, zero spill/fill, one FastRPC Execution
Unit, one HMX owner, six persistent HVX contexts, and no QNN are mandatory.
At repeat one and repeat ten, both the Input RMSNorm ledger interval and the
complete Host wall must strictly improve in ordinary and paired medians. Seven
interleaved paired rounds and PC-027/PC-028 closure are required.
