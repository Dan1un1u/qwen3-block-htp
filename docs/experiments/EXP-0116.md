# EXP-0116 — W4F16 Down publication-fence elimination

## Decision and scope

The user authorized a continuing W4F16/W4U8 recipe-specialization loop. This
experiment derives from EXP-0112 and uses the accepted EXP-0111 `join_only`
Gate/Up behavior in both cells. It changes only the nonstreamed W4F16 Down
weight-expansion handoff; QKV, Attention, O, Gate/Up, W4U8 and the frozen public
layer remain unchanged.

## Hypothesis

EXP-0111 proved that a nonstreamed W4F16 group does not need one full barrier
and generation publication per expansion region when no HMX consumer starts
until all expansion workers have joined. The generic W4F16 Down path still
uses the older ordered helper even though it follows the same dependency:
the full expanded group is produced into one slot, all worker semaphores are
joined with a final visibility barrier, and only then is the HMX command
submitted. Down therefore still pays synchronization that Gate/Up has already
shown to be redundant.

## Fixed boundary and gates

Control uses `join_only`: relaxed Gate/Up plus ordered Down. Candidate uses a
new `join_only_down` mode: Gate/Up remains identical and only Down passes the
existing relaxed W4-to-FP16 helper to main and pool workers. The pool join
barrier is retained; no decode arithmetic, weight layout, scale, DMA, HMX,
buffer, command, Attention, QKV, O or W4U8 behavior changes.

Control and candidate must be byte-exact to the independent block reference
with zero mismatch and zero maximum LSB. Static evidence must prove the new
mode is applied only when the projection descriptor is Down and that the final
pool join barrier remains. Exact 8 MiB VTCM, zero intermediate DDR and
spill/fill, one FastRPC execution unit, one HMX owner, unchanged weight bytes,
DMA descriptors, HMX commands and tile work remain hard gates. Down projection
and complete Host wall must both strictly improve in ordinary and paired
repeat-one and repeat-ten medians over five rotated rounds. PC-027 and PC-028
are mandatory; no local pass automatically promotes a baseline.
