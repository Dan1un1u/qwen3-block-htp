# EXP-0024 — HVX FP16 common-operator suite

## Approval and status

Approved by the user on 2026-08-28 as one sustained implementation loop. The
experiment starts from the temporarily accepted EXP-0023 source result and
implements RMSNorm, RoPE, standard causal Softmax, and SiLU-by-Up for the FP16
activation path. The final project needs matching A8 and A16 implementations,
but A8 is explicitly deferred to a later experiment because the current fair
comparison is F16F16 versus W4F16.

EXP-0023 is the Provisional Source Parent, not a Selected Baseline. No result of
this experiment may be promoted automatically.

## Objective and hypothesis

The EXP-0023 DMA-HVX-HMX W4F16 projection pipeline is 15.41% faster than the
F16F16 projection subsystem, but shared scalar block work accounts for about
96.41% of steady-state DSP ticks. Replace the four dominant shared scalar
operator families with mathematically equivalent HVX FP16 implementations so
the compressed-weight projection advantage becomes visible at the complete
Qwen3 block boundary.

The hypothesis is that SIMD work over 128-byte HVX vectors, bounded horizontal
reductions, and in-place VTCM operation can remove most scalar instruction and
loop overhead without changing the projection physical plans or adding DDR
boundaries.

## Ordered implementation loop

The default order is RMSNorm, SiLU-by-Up, RoPE, then stable causal Softmax.
RMSNorm covers input RMSNorm, post-attention RMSNorm, and the per-head Q/K norm
used before RoPE. This order attacks the broad reduction kernels and the
largest elementwise tensor first, then the paired rotary transform, and leaves
the dependency-heavy exponential reduction for last. The order may change only
when measurement demonstrates a shared-worker or VTCM scheduling dependency;
the fixed numerical and physical contracts may not change.

For each operator family, preserve a scalar reference switch, implement an HVX
candidate, run representative edge and real-tensor comparisons, integrate it
into the complete block, and compare the affected qtimer stage against the
fresh scalar control. Search vector unrolling, row partitioning, reduction
shape, direct-exp polynomial degree, and bounded worker use as needed. Retain
only a finite, reference-valid implementation whose median affected-stage
ticks do not regress. Static disassembly must show HVX instructions in every
retained hot loop and must not show a scalar per-element exp, trig, reciprocal,
or normalization loop masquerading as a SIMD implementation.

RoPE must preserve the exact existing position/frequency convention and rotate
each FP16 complex pair without changing head layout. Standard Softmax must
preserve causal masking and fully masked behavior, keep score/probability
storage in VTCM, and use stable max subtraction. SiLU-by-Up must compute the
same gate activation and multiplication without materializing a new DDR tensor.

## Numerical and physical gates

Each operator microgate compares device/HVX output with an independent FP32
formulation using the real Block Package values. Report maximum absolute error,
cosine where meaningful, non-finite count, and mask violations. The integrated
complete-block gates remain finite output, cosine at least 0.99999, and maximum
absolute error at most 0.0625 against each variant's implementation reference.
Teacher error remains diagnostic.

The final source must retain zero intermediate DDR read/write, zero intermediate
DMA descriptor, zero spill/fill, one whole-block FastRPC invocation, exact 8
MiB VTCM request/grant, stable boot identity, and no QNN dependency. VTCM peak
may not exceed the grant. The EXP-0023 projection counters and weight-storage
contracts must remain attributable and unchanged except for timing interference
caused by the shared common-operator schedule.

## Retained implementation

The retained source head is
`b9d14c59937967d41fa75e74745b9d7fc6ebda61`. It provides one shared FP16 HVX
operator suite used without variant-specific changes by F16F16 and W4F16:

- RMSNorm vectorizes square accumulation and FP16 output scaling while keeping
  only the bounded row reduction and one square root per row outside the hot
  per-element path.
- Q/K Norm and RoPE are fused into one VTCM-resident operator. The RMS scale
  and complex-pair rotation preserve the Block Package head and frequency
  convention.
- causal Softmax is the standard stable natural-exponential algorithm. It
  performs scale, mask, row maximum, exponential, row sum, and normalization
  without introducing the historical log2-quantized approximation.
- SiLU-by-Up evaluates the stable sigmoid form and multiplies the Up value in
  the same VTCM-resident HVX pass.

Every retained hot path is present in static Hexagon disassembly. Scalar
implementations remain selectable as independent controls. Per-operator modes
generate independent FP32 references on the DSP from the real Block Package
inputs; the reference instrumentation is disabled in formal scalar and
all-HVX timing modes.

One explored Softmax widening attempted to treat two FP16 vectors as a flat
FP32 lane sequence. Its assumed lane mapping was false and produced a maximum
absolute error of 43.25. It was forward-corrected rather than accepted. The
retained Softmax preserves the verified FP16 lane mapping and uses FP32 for the
normalization reciprocal.

Formal evidence is retained at

The matrix contains 52 accepted device records: correctness records,

| Common operators | Variant | repeat-one Host wall | repeat-ten Host wall per block | repeat-ten projection ticks |
| --- | --- | ---: | ---: | ---: |
| scalar control | F16F16 | 259.970 ms | 195.409 ms | 134,856.6 |

At steady-state repeat-ten scope, the FP16 HVX suite reduces complete-block
wall latency by 69.16% for F16F16 and 69.57% for W4F16. The retained W4F16
block is 1.00% faster than F16F16 for repeat one and 1.81% faster for repeat
ten, so both strict final speed gates pass. Its projection subsystem remains
15.16% faster at repeat-ten scope.

The corresponding shared-stage tick reductions versus the fresh scalar
controls are about 97.77% for the two block RMSNorm calls, 97.60% for Q/K
Norm plus RoPE, 32.94% for Attention including standard Softmax, and 95.25%
for SiLU-by-Up. Attention is now the dominant shared stage and the least
vectorizable improvement of the four, but it still passes the declared
non-regression gate.

## Physical evidence and interpretation

The device boot ID remained stable. Every record requested and received
exactly 8,388,608 VTCM bytes. Peak planned use is 6,286,080 bytes for F16F16
and 7,744,512 bytes for W4F16. Both variants report zero intermediate DDR read,
zero intermediate DDR write, zero intermediate DMA descriptor, and zero
spill/fill. The Block Package hash audit and no-QNN dependency scan pass.

This result confirms the EXP-0023 diagnosis: shared scalar operators, rather
than the compressed W4 projection pipeline, hid nearly all complete-block
benefit. After vectorizing those shared operators, complete-block latency falls
by roughly 69%, while W4F16's fourfold smaller stored-weight stream becomes a
repeatable 1.81% steady-state block advantage. The gain is still far below the
15% projection-only advantage because standard Attention now dominates the
remaining block time.
