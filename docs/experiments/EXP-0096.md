# EXP-0096 — Byte-exact arithmetic Gate/Up activation

## Decision and motivation

The autonomous profiling-guided loop continues from the accepted EXP-0084
control. EXP-0095 is a locally eligible sibling and is not inherited without
user promotion. In the current W4U8 complete block, Gate/Up plus SwiGLU remains
the largest additive module at about 683 microseconds in the latest contextual
profile.

After the existing per-output-channel requantization, every 128-byte Gate/Up
activation vector currently performs four predicated HVX `vgather` operations
against a 131,072-byte two-dimensional U8-by-U8 SwiGLU lookup table, then
reloads two 128-byte scratch vectors. The table was generated from the same
clipped-Q7 SiLU and Q5 product formula already implemented with HVX integer
multiply, add, shift, pack and saturation. EXP-0096 tests whether applying that
fixed-point formula directly after the unchanged requantization removes LUT
gather serialization and shortens the Gate/Up critical path.

## Fixed contract

The Execution Unit remains the real Qwen3-1.7B layer-14 complete block at
M=64. Source parent, W4 values and scales, asymmetric-U8 qparams, Gate/Up HMX
commands and tile order, per-channel requantization, middle and Down bytes,
worker count, task cadence, projections, Attention, residuals, DMA graph and
HMX ownership are fixed to EXP-0084. The 128 KiB LUT and existing gather
scratch remain allocated and staged in this first experiment so the only
performance variable is the activation hot kernel.

Formal runs require one FastRPC, exactly 8,388,608 acquired VTCM bytes, zero
intermediate DDR and spill/fill, one HMX owner, no QNN, 25,444,352 weight
bytes, 512 weight DMA descriptors, 176 HMX commands and 49,408 U8-by-S8 tile
pairs per block.

## Serial gates

Static disassembly must show that the candidate activation loop contains no
`vgather` and uses the declared HVX fixed-point multiply/shift/pack path. Final
output plus audited Input-RMSNorm, QK, probability and AV boundaries must be
byte-exact to EXP-0084 and the independent reference, with zero mismatches and
zero maximum LSB. If the arithmetic implementation is not byte-exact, the
experiment stops before performance testing.

Only after static, correctness and physical gates pass will five order-rotated
control/candidate rounds run at repeat one and repeat ten. Aggregate Gate/Up
activation work, additive Gate/Up wall and complete Host wall must all strictly
improve in ordinary and paired medians at both repeat counts. PC-027 and
PC-028 close the experiment; baseline promotion remains a user decision.
