# EXP-0143 — W4U8 Q/K Norm-RoPE SIMD row-cache transpose

## Decision and hypothesis

The user's continuing autonomous W4F16/W4U8 specialization loop authorizes
this bounded W4U8 experiment on 2026-09-01. It branches from EXP-0124 source
commit `95fadff5930d9081678ad99bb62ef84849ee1897`, preserving the accepted
Gate/Up ring16 lifecycle, Down batch four, quarter-tiled Q/K pair arithmetic
and the QKV ring3 producer/consumer schedule.

The current paired Q/K Norm-RoPE kernel computes sixteen rows per batched HVX
rsqrt. Before the arithmetic, each logical 128-channel row is assembled from
four 32-byte Crouton tile quarters with small `memcpy` calls. For a pair of
heads this performs eight small copies per row, even though four adjacent rows
from one tile form one aligned 128-byte HVX vector.

The residual carrier path already contains a verified four-row transpose: it
loads four full tile vectors and uses `vshuff` at 32-byte and 64-byte
granularity to produce four contiguous logical rows. The hypothesis is that
reusing this exact transpose for the Q/K row cache removes the small-copy
overhead and shortens the preparation pool tail while preserving every byte
fed to the existing rsqrt, gamma, RoPE and requant arithmetic.

## Gates

Control is complete EXP-0124 ring3 with the existing quarter-tiled pair kernel
and memcpy row packing. Candidate adds one runtime-selectable pair-kernel mode
whose only difference is the four-row HVX row-cache pack. QKV projection and
ring scheduling, weights, W4 expansion, qparams, rsqrt, gamma, RoPE,
requantization, Attention, O, residuals, Gate/Up, Down and the frozen Public
Common Layer remain fixed.

Both cells must produce byte-exact output `69f22eeb035e5ec5`, zero maximum LSB
error, and byte-identical existing Input-RMSNorm, score, probability, AV, QKV
operand and W4 expansion audits. They must request exact 8 MiB VTCM, retain
zero intermediate DDR and spill/fill, one FastRPC Execution Unit, one HMX
owner, no QNN, and identical weight bytes, DMA descriptors, HMX commands, tile
work, qparams, carriers and peak plan. Static evidence must show full-vector
loads plus the 32/64-byte HVX transpose in the candidate helper and no memcpy
inside that helper.

The candidate passes only if QKV-plus-Q/K-Norm-RoPE, complete Host wall and
Q/K preparation work strictly improve in ordinary and paired repeat-one and
repeat-ten medians over five rotated rounds, while Attention, Gate/Up and Down
each regress by no more than 0.5% in any ordinary or paired median. PC-027 and
PC-028 are mandatory. A local pass remains pending user decision and cannot
promote a Selected Baseline.

## Formal result and rejection

Formal evidence was collected on stable boot
`77ccafe0-8817-4976-bdae-15af5608d4ff` from source commit
`cd82ee4d0e6f9fc9eddb435f5b133997d411d2b3`. Both modes produced byte-exact
output `69f22eeb035e5ec5`, zero maximum LSB error and identical Input RMSNorm,
score, probability and AV audit hashes. Both acquired exact 8 MiB VTCM with
an identical 5,306,080-byte peak plan, zero intermediate DDR and spill/fill,
one FastRPC execution unit, one HMX owner, and identical physical work.

The carrier hypothesis was strongly confirmed. At repeat ten, SIMD row
packing reduced Q/K Norm-RoPE work by 43.233% ordinary / 43.011% paired, QKV
wall by 30.237% / 30.105%, and complete Host wall by 7.429% / 7.429%. The
complete-block median fell from 1,580.313 to 1,462.917 microseconds. Repeat one
showed the same direction: QKV fell about 30% and Host wall about 13% ordinary
/ 16% paired.

The strict local gate nevertheless failed because the separately attributed
Attention wall increased 3.746% ordinary / 3.230% paired at repeat one and
2.324% / 2.605% at repeat ten, above the 0.5% preservation bound. Work and
HMX counts remained unchanged; the correlated counter was a larger Attention
pipeline wait after Q/K rows became ready much earlier. The candidate is
therefore evidence-valid but rejected under the declared gate. It remains a
useful explicit parent for a different carrier hypothesis, not a Selected
Baseline and not authorization to relax the gate.
