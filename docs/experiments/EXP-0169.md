# EXP-0169 — W4U8 real continuous-decode KV-length scaling attribution

## Decision and purpose

The user approved a diagnosis-first decode and KV-cache experiment after
promoting EXP-0168. The selected EXP-0168 W4U8 token-generation baseline is the
immutable implementation under test. Its published result covers only cache
lengths 64 through 78, so it cannot determine whether longer decode is limited
by the fixed projection/LM-head floor or by historical-cache consumption in
QK, Softmax and AV.

## Immutable implementation and allowed instrumentation

The source parent is EXP-0168 commit
`bcf327142e451ed25c84f32d13e802230397d65a`. Transformer, Attention, MLP,
embedding, final RMSNorm, LM head, argmax and KV-cache kernel mathematics,
physical layouts and schedules are immutable. Model weights, W4 codes, scales,
activation qparams, prompt and token-feedback semantics are also immutable.

Only the Host generation loop's runtime step count, a capacity-257 archive,
RoPE/expected-token publication needed for positions 64 through 255, untimed
audit capture, and offline length-bucket summarization may change. These changes
must not alter any timed DSP kernel or add a timed DDR boundary.

## Execution and evidence

Every Prepared Session performs one real M64 prefill followed by 192 continuous
greedy decode calls, ending with cache valid length 256. Ten formal sessions are
required. Decode results are summarized for cache-length buckets 64-95, 96-127,
128-159, 160-191, 192-223 and 224-255, with exact Host wall and direct tokens/s.
Per-module and per-layer ledgers must remain closed so fixed projection cost can
be separated from QK-Softmax-AV, cache carrier, append DMA, mutable-tail and
32-token segment-seal costs.

Correctness requires the first 16 token IDs and U8 maximum codes to remain exact
to EXP-0168, all 193 captured final-hidden states to produce the same integer
LM-head result in an independent reference, and the existing EXP-0163 193-step
transformer/cache regression to remain exact. Semantic quality is not gated.
The physical gate remains exact 8 MiB VTCM, one FastRPC invocation per pass,
standalone cDSP with no QNN, zero timed inter-layer or full-logit DDR, zero
spill/fill, synchronized monotonic cache lengths and zero unattributed ticks.

This is characterization, not an optimization candidate: there is no speed or
baseline-adoption gate. The experiment completes only when it identifies the
cache-length slope and any segment-boundary discontinuities strongly enough to
choose the next implementation hypothesis.
