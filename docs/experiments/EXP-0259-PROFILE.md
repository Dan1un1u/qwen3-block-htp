# EXP-0259 optimized dense R3 full-model E2E

本轮优化当前R3的数据搬运与流水，保持原有denseHMX矩阵乘和所有数值运算。固定C64 per-output-channelW4、R3_ALL Q/K参数、wideNR64、正确旋转的固定EOS U8前缀，其他recipe冻结。既有idealFloat64整层gate仍失败，本轮不作PPL或模型质量验收。

实现：32KiB显式FP16符号矩阵预打包，逐层HVX复制并计入constant_read_bytes；四行向量转置替代小块标量搬运；R3量化同时形成Koperand；五个worker随Q/K就绪准备FP16输入，QKV结束后join再使用共享HMX。QKV偏置双缓冲移至当时空闲的attention_concat，使gate仅由R3准备worker写入。没有蝶形、重新校准或近似rsqrt替换。

单层先完成四臂5short10formal；初始repeat1decode置信区间上沿10.96%尚不能确认10%门槛，随后固定补充10轮双组配对，未调参、未删样本，合并20轮满足扩展门槛。原始10轮与补充轮次分别保留；不是事先计划的20轮。单层原始统计见LAYER_REPORT.md，补充见confirmation_gate.json。

单层108份完整捕获/输出逐字节比较通过，并复现EXP0252参考；独立denseFloat64组件和矩阵布局检查通过。正确前缀的连续三层九步，优化R3及重复输出与EXP0258相应完整捕获逐字节一致；全模型反馈token复现EXP0258。

以下为新运行时、无R3对照与OPT2 R3候选的真实28层M64+15连续decode、5short10formal配对测量。5280完整模型RPC和147840逐层账本闭合；每次28次R3HMX/672个并行准备heads，8MiB VTCM、零计时中间DDR/spill/audit导出，每token一个RPC。原生W4线性路径和EXP0258 LMhead同步修复保留。
