# EXP-0099 — Four-output generation-safe Down batching

## Decision and motivation

EXP-0098 proved that Down command cadence is still material. Batching two
adjacent outputs per HMX worker command halved Down command submissions,
reduced Down expanded-slot wait by about 35%, reduced Down wall by about 25%,
and improved complete repeat-ten Host wall by about 4%, without changing
traffic, tile arithmetic or the zero-intermediate-DDR contract.

EXP-0099 asks whether the same lifetime-safe mechanism still scales to four
outputs per command. This is a clean experiment from the accepted EXP-0084
source parent, not an adoption of EXP-0098. The candidate carries four
adjacent outputs in each request, but each output must independently wait for
its original two chunks, begin from its own bias, accumulate and store the
same U8 tile, and release both expanded slots before the worker waits for the
following output. The purpose is to remove another 16 Down command
submissions without turning the longer command into producer serialization.

## Fixed contract and gates

Only Down request cardinality and the metadata/lifetime support required for
four outputs may change. Weights, qparams, two 96-tile chunks per output,
output order, HMX tile operations, Gate/Up, Attention, residuals, worker
counts, DMA graph and the single HMX owner remain fixed.

The control has one output per command, 64 Down commands and 176 total HMX
commands per block. The candidate has four outputs per command, 16 Down
commands and 128 total commands. Both retain 49,408 U8-by-S8 tile pairs,
25,444,352 weight bytes, 512 weight DMA descriptors, exactly 8 MiB acquired
VTCM, zero intermediate DDR and spill/fill, one FastRPC, one HMX owner and no
QNN.

Audit-on execution must be byte-exact at final output and the established
Input-RMSNorm, QK, probability and AV boundaries. It must report 128
in-command slot releases per block, observe producer progress during the
longer commands, and contain no complete-batch pre-ready barrier. Five
order-rotated rounds at repeat one and repeat ten follow. Down wall and
complete Host wall must strictly improve by ordinary and paired medians at
both repeat counts. PC-027 and PC-028 close the experiment. Baseline promotion
remains an explicit user decision.

## Result

Running.
