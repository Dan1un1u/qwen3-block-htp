# EXP-0094 — Prepared-session V-recenter LUT and AV-bias cache

## Decision and motivation

The autonomous profiling-guided loop continues from the accepted EXP-0084
control rather than stacking the locally eligible but unapproved EXP-0093
candidate. Current W4U8 Attention still spends about 3.19k aggregate worker
ticks per block in V packing. The accepted vector path has already removed the
scalar recenter lookup and transpose, but it still reconstructs one 256-entry
int16 recenter LUT and one 1,024-byte AV bias block for every GQA group in every
block.

Both objects depend only on the eight static Attention configuration records.
They are invariant across warmup and measured calls in one Prepared Runtime
Session. EXP-0094 tests whether keeping all eight group-specific LUTs and bias
blocks in 12,288 bytes of declared VTCM removes enough scalar setup work to
shorten V packing, the additive Attention interval and complete Host wall.

## Fixed contract

The Execution Unit remains the Qwen3-1.7B layer-14 complete block at M=64.
EXP-0084 W4 bytes, asymmetric-U8 qparams, recenter formula, saturation,
rounding, V-carrier transpose, AV HMX arithmetic, Softmax, projections,
residuals, MLP, task graph, DMA and HMX ownership remain fixed. Each group has
its own immutable LUT and bias block; mutable vgather scratch remains
context-local and is never shared.

Formal performance runs require one FastRPC, exactly 8,388,608 acquired VTCM
bytes, zero intermediate DDR and spill/fill, one HMX owner, no QNN, 25,444,352
weight bytes, 512 weight DMA descriptors, 176 HMX commands and 49,408 U8-by-S8
tile pairs per block. The candidate may increase reported peak VTCM use only by
the declared 12,288-byte cache.

## Serial gates

Correctness first requires byte-exact final output plus Input-RMSNorm, QK,
probability and AV audit boundaries. The persistence gate then requires the
warmup call to build exactly eight group LUTs and eight bias blocks, while the
measured repeat-one and repeat-ten calls build zero and reuse every group.

Only after both gates pass will five order-rotated control/candidate rounds run
at repeat one and repeat ten. Aggregate V-pack work, additive Attention wall
and complete Host wall must all strictly improve in ordinary and paired
medians at both repeat counts. PC-027 and PC-028 close the experiment; baseline
promotion remains a user decision.
