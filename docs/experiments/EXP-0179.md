# EXP-0179 — Decode W4U8 row-four Q/K normalization and RoPE

## Decision and purpose

EXP-0178 proves that logical-M=1 decode benefits when common nonlinear
operators stop scanning the 60 dead rows of the physical M64 carrier.  Source
and profile inspection show the same mismatch in Q/K preparation: all Q and K
heads still execute normalization and RoPE across 64 physical rows.  The K
pair helper also constructs a complete 64-token temporary QK weight/bias
carrier.  During cache-native decode this temporary carrier is not consumed:
the append path takes normalized K row zero into the persistent segmented
cache, and dynamic Attention reconstructs QK operands from that cache.

This experiment tests a decode-only row-four Q/K preparation path while
preserving the existing QKV ring, head-readiness order and HMX projection
work.  It is a new row-extent hypothesis, not a retry of rejected QKV batch or
worker-count scheduling experiments.

## Direct control and candidate

The control is byte-identical EXP-0178: row-four common nonlinear operators
and AV requantization, but full-64-row Q/K pair preparation and the temporary K
carrier pack.  The candidate changes only continuous W4U8 decode with logical
M equal to one.  Each Q and K head pair normalizes and rotates physical rows
zero through three using the established exact arithmetic.  It writes those
rows back to the existing native HMX carrier; row zero remains the only valid
row.  The K pair omits the unused prefill-style full-carrier scatter and bias
construction.  M64 prefill retains the existing full-64-row pair kernels and
carrier construction.

QKV projection weights, qparams, HMX commands, ring slots, DMA order, head
publication, cache formats and append, QK/Softmax/AV, O projection, residuals,
MLP, embedding, feedback and LM-head are immutable.  Telemetry must distinguish
requested and observed row extent, Q-pair and K-pair calls, processed rows and
skipped temporary K carrier builds.

## Gates

The short gate uses five rotated 17-step pairs.  Both cells must be byte-exact
on valid Q/K rows, persistent cache state, hidden hashes, token IDs and logit
codes.  Padding poison must prove that rows four through 63 cannot influence a
valid output.  QKV HMX commands, tiles, weight bytes and all downstream math
must remain unchanged.  The candidate advances only if QKV plus Q/K
preparation wall and complete decode Host wall both improve.

A passing candidate completes ten rotated 193-step pairs, the independent
integer head audit and EXP-0163 transformer/cache regression.  It must retain
exact 8 MiB VTCM, one FastRPC per pass, zero timed intermediate or full-logit
DDR, zero spill/fill, no QNN and zero ledger residual.  Direct complete decode
tokens/s is the formal ranking metric.  A local pass remains pending explicit
user promotion.
