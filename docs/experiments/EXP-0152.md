# EXP-0152 — Real 28-layer full-stack resume on one rpcmem_alloc2 arena

## Decision and purpose

The user approved continuation on 2026-09-01 after EXP-0151 proved that the
connected PJZ110 can allocate, map and address one 2,900,000,000-byte shared
arena through `rpcmem_alloc2`, `fastrpc_mmap` and `HAP_mmap_get`. EXP-0152 is a
new experiment rather than a rewrite of aborted EXP-0150. It resumes the real
28-layer integration gate on that proven allocation substrate.

## Fixed implementation boundary

The source parent is EXP-0151 commit
`bb9531f457dce01e97a1770020bd1a1890c8114b`. The model execution contract is
inherited from EXP-0150 and the accepted EXP-0149 three-layer substrate. The
only infrastructure change authorized before full-stack expansion is replacing
the legacy signed-int package allocation and capacity guard with exact-size
`rpcmem_alloc2(size_t)` allocation. Each recipe uses one arena, one fd and one
persistent cDSP mapping for its Prepared Runtime Session. All layer descriptors
use 32-bit offsets into that arena.

Segmented or delayed mapping, Host weight refill, per-layer RPC, Host hidden
handoff, imported runtime K/V, new kernels, new schedules, changed recipe math,
QNN and intermediate DDR are forbidden. The runtime still requests exactly
8 MiB VTCM and retains one HMX owner.

## Staged gates

Stage A computes the complete byte-exact package layout for F16F16, W4F16 and
W4U8 before allocating or writing multi-gigabyte output. Every section,
alignment, layer offset and total byte count must fit the uint32 descriptor
contract. The three immutable packages and independent references are then
written under the D-drive storage contract.

Stage B allocates each real package at its exact size with `rpcmem_alloc2`, maps
the single fd to cDSP, and validates the first, middle and last regions plus all
28 layer descriptor boundaries. Any capacity or real-package mapping failure
stops the experiment; there is no segmented fallback.

Stage C runs the real 64-token prefill through layers 0-27 in one FastRPC call.
Stage D runs positions 64-71 as eight continuous decode steps with 28 persistent
layer caches. The teacher supplies only the embedding hidden state entering
layer 0 and position metadata. The output boundary remains layer 27 before the
final model RMSNorm or LM head.

The user amended the FP16 composition gate on 2026-09-02 after the isolated
F16F16 hidden-trajectory diagnostic proved that the old elementwise bound can
be exceeded by a small and smoothly growing subset without a layer-index,
weight-layout or capture failure. F16F16 and W4F16 now require no non-finite
values; cosine at least 0.99999 for every conditional single-layer output and
conditional FP16 cache comparison; at most one percent of elements outside the legacy
mixed bound `abs(actual-reference) <= 0.0625 + 0.002*abs(reference)`; and final
composed output cosine at least 0.99999 with NRMSE at most 0.003. The legacy
per-element violation count remains mandatory diagnostic evidence and is not
deleted or relabelled as exact agreement. W4U8 still requires zero LSB against
its independent integer reference. Final layer output and every layer cache are
checked after prefill and every decode step.

`Conditional cache` means that the independent layer reference consumes the
actual incoming hidden state captured at that layer. A formal cache compared
against the independent full-stack reference also contains upstream composed
drift, so that comparison requires valid cache structure, byte-stable old
prefixes and no non-finite values; its cosine, NRMSE and legacy mixed-bound
fraction remain diagnostic and cannot be
mislabelled as local kernel error. This distinction was verified on F16F16:
56/56 conditional prefill K/V caches passed with zero legacy-bound violations,
while seven late-layer composed V caches exceeded one percent solely from
upstream accumulation and retained cosine above 0.99999.

W4F16 confirmed why no extra composed-cache cosine gate may be invented:
28/28 conditional layers and 56/56 conditional K/V caches passed the approved
local gate, and all nine composed outputs passed, while late composed caches
reached a minimum cosine of about 0.99996 from upstream drift. This value is
reported but does not override the user-approved scheme 1.

The gate amendment is authorized by the user message `确认方案1`. The diagnostic
capture is not formal physical or performance evidence: it explicitly writes
all 28 layer outputs to 7,340,032 bytes of DDR. The ordinary RUN path remains
unchanged and must independently pass zero intermediate DDR.

Only after correctness and the physical contract pass is formal repeat-one and
rotated repeat-ten profiling collected. The report must close the complete
stack and per-layer ledgers and separate legal persistent cache traffic. There
is no speed gate and no baseline-promotion authority.
