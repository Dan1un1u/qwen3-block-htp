# EXP-0061 — Batch paired Q/K Norm reciprocal square roots on HVX

## Parent and scope

EXP-0060 is the direct source control. Keep its exact HVX centered-square
tree reduction. Change only reciprocal-square-root evaluation inside the
already paired Q/K Norm plus RoPE tasks. Input RMSNorm, post-attention
RMSNorm, projections, Attention math, residual equations, MLP, qparams, and
layouts remain unchanged.

## Hypothesis

Each paired task currently evaluates 128 independent scalar `1/sqrtf` calls:
two Q/K heads across 64 rows. Across twelve physical paired tasks this leaves
1536 serial scalar roots on the QKV critical path. A two-phase task can first
collect the exact mean-square values, evaluate them in four 32-lane vectors
with Qualcomm's three-Newton-step `qhmath_hvx_rsqrt_vf`, then perform the
existing gamma, RoPE, and U8 requantization. This adds only VTCM rereads and no
DDR traffic while replacing the serial root chain with SIMD math.

## Candidate and gates

Control and candidate must remain selectable in one binary. The initial
correctness gate is strict: final output and QK/probability/AV boundaries must
remain byte-exact to EXP-0060 and the independent reference. Exactly 8 MiB
VTCM, zero intermediate DDR, zero spill/fill, one FastRPC execution unit, one
HMX owner, and no QNN are mandatory.

At repeat one and repeat ten, aggregate Q/K Norm plus RoPE work, the QKV
critical-path ledger, and complete Host wall must strictly improve in both
ordinary and paired medians. Seven interleaved paired rounds and PC-027/PC-028
complete profiling closure are required.
