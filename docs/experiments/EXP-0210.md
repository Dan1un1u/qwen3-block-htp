# EXP-0210 — Direct-W4 O batch16 single-descriptor DMA

## Decision and purpose

EXP-0210 retains the evidence-valid EXP-0209 structure and tests the next
projection whose consumer waits for the complete result. O currently uses
batch8, giving 224 command groups per generated token. The candidate uses
batch16 and transfers each 524288-byte packed-W4 group as one weight descriptor
ordered into one bias descriptor, avoiding the conservative mid-group wait.

The expected result is 112 O groups and 224 fewer total DMA descriptors per
token, with unchanged arithmetic, weight bytes and HMX tile pairs. Unlike Q/K
head publication, O has no useful partial consumer in the current runtime, so
coarser batching should not delay a downstream streaming boundary.
