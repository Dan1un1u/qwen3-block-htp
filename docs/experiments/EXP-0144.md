# EXP-0144 — W4U8 Q/K Norm-RoPE SIMD output transpose

## Decision and hypothesis

The user's continuing autonomous W4F16/W4U8 specialization loop authorizes
this bounded W4U8 experiment on 2026-09-01. It uses the evidence-valid
EXP-0143 candidate source commit
`cd82ee4d0e6f9fc9eddb435f5b133997d411d2b3` as an explicit experimental
parent. EXP-0143 is not a Selected Baseline: it remains rejected because its
large net gain coincided with an Attention-attribution preservation failure.

EXP-0143 removed the input-side small-copy carrier cost, but after rsqrt,
gamma, RoPE and requant every completed logical row is still written to four
32-byte Crouton tile quarters with small `memcpy` operations. Four adjacent
logical rows and four output tiles form the inverse of the same symmetric
4-by-4 quarter transpose already validated on the input side.

The hypothesis is that deferring four completed rows and applying the same
32-byte and 64-byte `vshuff` transpose will replace the output small copies
with four aligned HVX stores. K's signed-sum and weight scatter remain in the
existing per-row order; only the copy back to the K activation carrier is
deferred to each four-row boundary.

## Gates

Control is EXP-0143 candidate mode: SIMD input row packing and existing
per-row output memcpy. Candidate adds a new runtime-selectable pair-kernel
mode with SIMD input packing plus the four-row output transpose. QKV ring3,
weights, qparams, rsqrt, gamma, RoPE, requantization, K weight scatter,
Attention, O, residuals, Gate/Up, Down and the frozen Public Common Layer stay
fixed.

Both cells must produce byte-exact output `69f22eeb035e5ec5`, zero maximum LSB
error and identical existing audits. They must request exact 8 MiB VTCM,
retain zero intermediate DDR and spill/fill, one FastRPC Execution Unit, one
HMX owner, no QNN, and identical physical work and peak plan. Static evidence
must show the output helper contains the HVX transpose and no memcpy call.

The candidate passes only if QKV-plus-Q/K-Norm-RoPE, complete Host wall and
Q/K preparation work strictly improve in ordinary and paired repeat-one and
repeat-ten medians over five rotated rounds, while Attention, Gate/Up and Down
each regress by no more than 0.5% in any ordinary or paired median. PC-027 and
PC-028 are mandatory. A local pass remains pending user decision and cannot
promote a Selected Baseline.

## Formal result and rejection

Formal evidence was collected from source commit
`919aaa74870661d78b92e64976e695a4fa87f955` on stable boot
`77ccafe0-8817-4976-bdae-15af5608d4ff`. Both cells produced byte-exact output
`69f22eeb035e5ec5`, zero maximum LSB and identical stage-audit hashes. Both
acquired exact 8 MiB VTCM with the same 5,306,080-byte peak, zero intermediate
DDR and spill/fill, one FastRPC execution unit, one HMX owner and identical
physical work.

The inverse-transpose hypothesis was confirmed. At repeat ten it reduced Q/K
Norm-RoPE work by 67.587% ordinary / 67.536% paired and QKV wall by 41.779% /
41.263%. Complete Host wall fell from 1,463.188 to 1,364.625 microseconds,
6.736% ordinary / 6.712% paired. Attention was effectively unchanged at
-0.056% ordinary / +0.013% paired.

The strict preservation gate failed elsewhere: Gate/Up increased 0.986%
ordinary / 0.904% paired at repeat ten, Down increased 0.884% / 0.986%, and
repeat-one Gate/Up increased 1.508%. These downstream changes are small
relative to the roughly 99-microsecond net Host gain but exceed the declared
0.5% bound. The candidate is therefore evidence-valid and rejected, while
remaining an explicit fastest-candidate parent for a different module
hypothesis. It is not a Selected Baseline.
