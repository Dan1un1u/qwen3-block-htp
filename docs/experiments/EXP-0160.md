# EXP-0160 — Pipeline compact W4U8 delta-tail reconstruction with HMX Attention

## Decision and purpose

EXP-0159 is the user-promoted Selected Full-Stack W4U8 Cache-Native Baseline.
It removes persistent HMX tile read-modify-write and reduces cache update plus
append time by about 4.41 ms/token, but serial compact-base placement and tail
reconstruction raise decode QK-Softmax-AV from 7.223 to 10.082 ms. On
2026-09-02 the user approved continuing with the proposed read-side pipeline.

## Fixed boundary

The immutable source parent is EXP-0159 commit
`4c27bea705c21835b7f444841096a9d6828048cd`. The same-binary control is the
accepted compact M64 HMX base plus contiguous U8 K/V journal with serial
reconstruction. Only the W4U8 decode Attention cache consumer, physical base
placement, tail clearing, scratch buffering and schedule may change.

The candidate places compact K/V base fragments directly into their final HMX
locations, clears only the unpopulated tail, removes the intermediate V-base
staging copy, and uses two VTCM slots to prepare group `g+1` with DMA/HVX while
the single HMX owner consumes group `g`. The persistent cache ABI, retained
package and current-token journal append remain byte-identical to EXP-0159.

QK, Softmax and AV mathematics; all qparams and W4 values; HMX command and tile
counts; projection kernels and schedules; A16 paths; legal DDR boundaries; and
the M64 prefill path remain unchanged. The execution unit is real Qwen3 layers
0-27, one M64 prefill followed by continuous decode positions 64-71, with one
FastRPC invocation per full-stack step.

## Gates

The candidate must be zero-LSB exact for all nine outputs and all cache
references. It must perform no full carrier clear, no intermediate V-base HVX
staging copy, no persistent native-tile DDR read-modify-write, no full-prefix
pack and exactly one current-token K/V append per layer and decode step.

The physical contract remains exact 8 MiB VTCM, zero intermediate DDR, zero
spill/fill, one FastRPC invocation, one HMX owner and no QNN. Decode
QK-Softmax-AV and complete Host wall must both be strictly below the
same-binary serial control; complete Host wall must also beat the selected
EXP-0159 value of 50,249.834 us/token. Prefill may regress by at most 1%.

Instrumentation first closes base DMA, zeroing, K patch, V placement, V patch,
HMX and wait intervals. Implementation then proceeds through a bounded smoke,
complete 28-layer correctness and physical gates, and ten rotated same-binary
control/candidate replays. Passing does not promote another baseline without
explicit user approval.

## Decision state

Execution completed at source commit
`b33e88e3971c35851450d0737a0689bd0bd077aa`. Ten rotated same-binary
replays of the real 28-layer stack passed exact output/cache correctness,
8 MiB VTCM, zero intermediate DDR/spill, unchanged HMX work and both speed
gates. The formal evidence is
`D:/llm_exp/results/qwen3-block-htp/exp0160/20260902T141223Z_b33e88e3971c_formal`.

Serial reconstruction measured 43.993 ms for M64 prefill and 50.293 ms per
decode token. The two-slot pipeline measured 43.936 ms and 49.042 ms,
respectively. Thus prefill improved 0.128%, full decode improved 2.551%, and
decode QK-Softmax-AV improved from 10.129 to 8.962 ms, or 13.013%. The
candidate uses 77,824 bytes of Attention overlay versus 38,656 bytes for the
serial control, while leaving HMX command/tile counts and cache traffic
unchanged.

All local gates pass and evidence is valid. On 2026-09-02 the user explicitly
promoted EXP-0160 as the Selected Full-Stack W4U8 Cache-Native Baseline.
EXP-0159 is retained as valid evidence but is superseded for that role.
