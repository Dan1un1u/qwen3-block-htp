# EXP-0194 — Direct-n decode QKV head-pair batch-eight

## Decision and purpose

EXP-0191 leaves QKV plus Q/K Norm and RoPE at about 3.54 ms/token.  Direct-n
QKV currently publishes one 128-channel head per four-tile HMX/DMA group.
Eight tiles match the established two-head Q/K preparation task and should
halve command and descriptor granularity.

EXP-0102 rejected QKV batch eight under the old Expanded-S8 producer pipeline
because larger groups reduced DMA-expand-HMX schedulability.  EXP-0188 satisfies
that reopen condition: decode QKV now feeds packed W4 directly to HMX and has no
expansion producer.  This experiment therefore retests the head-pair grouping
under a materially different physical pipeline.

## Gates

One binary compares decode-only QKV batch four with batch eight.  Four
phase-dead VTCM slots carry the larger direct-n W4 groups; bias storage may
reuse only memory whose lifetime ended after Input RMSNorm.  M64 prefill and
O, Attention, cache, Gate/Up batch sixteen, row-four SwiGLU, Down DMA2/HMX2 and
LM head remain unchanged.

Correctness requires byte-exact QK, probability, AV, hidden hashes, tokens and
cache state.  Physical gates remain exactly 8 MiB VTCM, zero timed intermediate
DDR, zero spill/fill, one FastRPC, one HMX owner, no QNN, unchanged weight bytes
and HMX tile pairs, QKV commands 896 to 448 per token and total weight DMA
descriptors 6,122 to 5,226.  Five rotated short pairs must improve complete
decode token/s and QKV plus Q/K Norm/RoPE wall before ten formal pairs.

## Decision state

Completed on 2026-09-05 from source commit
`8b62c9cd30f8a8fc70a7074b515c855b66a16d3e`.  The five-pair short gate and
ten-pair formal gate both pass.  Formal decode improves from 37.759952 to
38.651475 token/s (+2.361027%), and all ten candidate runs are faster.

QKV plus Q/K Norm/RoPE falls from 3.5295 to 2.9055 ms/token.  QKV commands
fall 896 to 448 and total weight DMA descriptors fall 6,122 to 5,226, while
1,699,840 HMX tile pairs, 866,032,640 weight bytes, 672 Q/K head publications,
all hidden hashes, tokens and cache state remain identical.  The 8 MiB VTCM,
zero timed intermediate DDR, zero spill/fill, one FastRPC, one HMX owner and
no-QNN gates pass.  Adoption remains pending; no baseline changes automatically.
