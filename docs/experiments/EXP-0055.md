# EXP-0055 — Native U8 Q/K Norm-RoPE head pairs

## Decision

The user approved continuing to the next optimization on 2026-08-30. This experiment starts cleanly from EXP-0053 and does not inherit rejected EXP-0054 code.

## Hypothesis

The EXP-0053 Q/K preparation pool executes sixteen independent Q-head tasks followed by eight independent K-head tasks. Their aggregate native U8 Norm-RoPE work is about 44.8k ticks per block, while the join remains about 9.1k ticks on the additive QKV path. Adjacent heads use the same tensor shape, RoPE table, loop structure, and per-kind gamma/qparams. A two-head HVX kernel may reuse invariant loads and loop state and halve task-claim cadence without changing any output code.

## Candidate

Pair the two Q heads belonging to each GQA group and pair adjacent K heads across groups. The candidate exposes eight Q-pair tasks followed by four K-pair tasks. Each task waits for both complete generation-tagged heads, applies exactly the existing per-head RMSNorm, RoPE, requantization, and K carrier preparation, and writes the same disjoint native locations. Q/K projection commands, head publication, Attention HMX/Softmax/AV, qparams, weights, MLP, residuals, traffic, and VTCM allocation remain fixed.

## Gates

The device result and QK/probability/AV audit boundaries must remain byte-exact to EXP-0053 and the independent reference. Formal runs require exactly 8 MiB VTCM, zero intermediate DDR, zero spill/fill, one FastRPC execution unit, one HMX owner, and no QNN. At repeat one and repeat ten, aggregate Q/K Norm-RoPE work, Q/K preparation join, the complete QKV ledger interval, and complete Host wall must all strictly improve. Closure requires seven interleaved paired rounds and the complete PC-027/PC-028 report.

## Result

The candidate passed every local gate in seven interleaved paired rounds. It preserved the final output and the QK, probability, and AV audit boundaries byte-for-byte with zero mismatches and zero maximum LSB error. It requested and acquired exactly 8 MiB VTCM, reported zero intermediate DDR and zero spill/fill, retained one FastRPC execution unit and one HMX owner, and introduced no QNN dependency.

At repeat one, paired-head execution reduced aggregate Q/K Norm-RoPE work from 45,377 to 34,172 ticks (-24.693%), preparation-pool wait from 9,246 to 6,299 ticks (-31.873%), the QKV ledger interval from 16,131 to 13,093 ticks (-18.833%), and complete Host wall from 3,177.760 to 2,983.333 microseconds (-6.118%). At repeat ten, the same metrics changed from 45,393.9 to 33,724.1 ticks (-25.708%), 9,289.5 to 6,169.9 ticks (-33.582%), 16,166.5 to 12,969.7 ticks (-19.774%), and 2,747.849 to 2,552.526 microseconds (-7.108%).

The gain comes from eliminating repeated FP16-to-SF32 conversion of the invariant gamma and the shared per-row RoPE table, while halving task-claim cadence. Each head still performs its own RMS reduction, reciprocal square root, rotation, requantization, and K-carrier construction. EXP-0055 is locally adoption-eligible, but baseline promotion remains a user decision.
