# EXP-0045 — W4U8 Q/K/V/O projection pipeline

## Approval and parent

Approved by the user on 2026-08-29 after EXP-0044 showed that integer
Attention operand preparation can overlap QKV projection but also exposed a
5% to 7% QKV slowdown from HVX contention. The implementation parent is the
completed EXP-0044 Stage-B source head
`98126b62b9300d77b39eff1388f01233d832dad8`. The source branch is
`codex/exp-0045-w4u8-qkvo-pipeline`.

## Evidence-driven hypothesis

At repeat ten, EXP-0044 Stage B spends 35646.5 qtimer ticks in QKV projection
and 13297.2 ticks in O projection. The corresponding selected W4F16 baseline
intervals are 8432.8 and 3344.2 ticks. The W4U8 general projection path still
processes each 32-channel output tile as a serial sequence: copy one packed-W4
bundle, copy its bias, expand W4 to S8 on HVX, synchronously submit one integer
HMX command, and then advance to the next tile. In contrast, the established
W4U8 MLP and W4F16 paths already use bounded DMA-HVX-HMX producer/consumer
pipelines.

The primary hypothesis is that Q/K/V can batch the four output tiles that form
one 128-channel head, overlap packed-weight DMA with HVX expansion and HMX
consumption, and publish readiness at the same head boundary already consumed
by EXP-0044. This can reduce weight-flow and HMX-submission overhead without
coarsening the current dependency contract. If that gate passes, the same
pipeline may be applied to O projection while preserving its existing native
U8 activation boundary.

## Fixed contract and gates

- The Execution Unit remains the real Qwen3 layer-14 complete block at M=64.
- W4 values, asymmetric-U8 qparams, integer Attention arithmetic, output
  codes, EXP-0044 Q/K head-ready overlap, and the W4U8 streaming MLP remain
  unchanged.
- One FastRPC invocation, one HMX owner, exactly 8 MiB VTCM, zero intermediate
  DDR, zero spill/fill, and no QNN path are mandatory.
- Rejected EXP-0033-style dynamic main-thread work stealing and EXP-0018-style
  phase serialization are not candidate schedules. HVX expansion must remain
  capable of overlapping DMA and HMX consumption.
- Stage A changes only Q/K/V projection. It may search batch sizes one, two,
  and four and one to three HVX expansion workers under a common selection
  rule. The selected candidate must be byte-exact and strictly reduce both QKV
  projection wall and complete Host wall at repeat one and repeat ten.
- Stage B is admitted only after Stage A passes. It changes only O projection
  and must strictly reduce O projection, combined QKVO projection wall, and
  complete Host wall at both repeat scopes while preserving Stage A.
- Performance conclusions use seven interleaved paired rounds. Engine-work
  counters explain the result, but equivalent-scope Host wall remains primary.
