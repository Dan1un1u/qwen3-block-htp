# EXP-0203 — Down-tail prefetch of the next layer's first Q direct-W4 weight

## Decision and purpose

EXP-0202 proved that prefetching Down during Gate/Up is locally useful but
competes with the active Gate/Up-to-SwiGLU pipeline and harms end-to-end
decode. EXP-0203 returns to the evidence-valid EXP-0201 source and uses a
different physical window: the final HMX command of each layer's Down
projection, after the last same-projection DMA has already completed.

For layers 0 through 26, the candidate transfers only the next layer's first
16-output-tile Q packed-W4 carrier into the otherwise phase-dead expanded
weight slot while the current layer's final Down HMX command runs. It waits for
both engines before leaving the layer. The following QKV ring consumes that
resident weight and transfers only its unchanged bias. Layer 27 starts no
cross-layer prefetch.

## Controlled implementation

One runtime-selectable binary compares EXP-0201 with and without this
cross-layer carrier lifetime. The candidate may change only the decode-only
first-Q weight-transfer lifetime, first-batch QKV producer consumption,
telemetry, protocol fields and experiment tools. It must not change QKV order,
batch16 HMX commands, Down batch2 commands, carrier contents, quantization,
arithmetic, or any prefill path.

The early weight descriptor replaces, rather than duplicates, the first Q
weight descriptor. The corresponding Q bias remains a separate normal DMA at
QKV-ring entry. Consequently packed-W4 bytes, total weight DDR reads and total
DMA descriptor count must remain identical to control.

## Gates

Correctness requires byte-exact hidden, cache, selected-code and token outputs
to EXP-0201. Physical evidence requires exactly 8 MiB VTCM, zero timed
intermediate DDR, zero spill/fill, one FastRPC per pass, one HMX owner, no QNN,
zero decode W4-to-S8 expansion, identical packed-W4 bytes, DMA descriptors,
HMX commands and tile pairs, plus exactly 27 started and consumed cross-layer
Q-weight carriers per decoded token.

A five-pair rotated short gate must improve QKV wall and complete directly
measured decode token/s. A passing candidate completes ten rotated 193-step
pairs. M64 prefill is preservation-only. If this experiment again reduces its
targeted local path while worsening end-to-end decode, it forms the second
consecutive local-optimum/E2E-regression result; the decode loop then stops at
the fastest eligible pending candidate under the user-defined gate.
