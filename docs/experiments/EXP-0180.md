# EXP-0180 — Quartet-native mutable V-cache tail for W4U8 decode

## Decision and purpose

EXP-0179 leaves QK-Softmax-AV as the largest non-MLP decode opportunity at
about 5.415 ms/token.  Its internal ledger shows about 1.448 ms/token in V
operand packing, while QK and AV HMX together use only about 0.443 ms/token.
The segmented-v4 cache already stores every sealed 32-token V segment in exact
HMX weight layout, but keeps the current mutable segment as row-major U8.  Each
decode step therefore reads and repacks all one through 31 rows of that tail.

EXP-0159 rejected persistent full-tile read-modify-write, not incremental
native publication.  This experiment tests a different physical contract:
publish only complete four-row HMX carrier groups and retain at most three
unpublished logical rows.  It should bound recurring V packing by three rows
without a full-tile read-modify-write.

## Direct control and candidate

The immutable source parent is the locally eligible EXP-0179 commit
`828e4d7f5caf8001f135e225704ed6f83b52dc53`.  The same-binary control is its
segmented-v4 cache: sealed V segments are HMX-native and the 32-row mutable tail
is row-major.

The candidate introduces a versioned V-cache tail containing a 32-row
HMX-native carrier plus one four-row row-major microjournal.  K remains on the
unchanged segmented-v4 format.  Every decode append writes one logical V row to
the microjournal.  When four rows are complete, one HVX conversion publishes
exactly one 128-byte input group in each of the four AV output tiles; no prior
native tile is read.  At Attention consumption, completed groups are DMA-loaded
directly and only the zero-to-three unpublished rows are packed in VTCM.  When
the 32-row tail seals, its already-native carrier is copied to the existing
immutable segment slot.

QK, Softmax, AV and all qparams remain byte-identical.  QKV, O, MLP, embedding,
LM head, HMX command/tile counts, weights, prefill math and the K-cache ABI are
immutable.  No persistent logical V duplicate may be introduced.

## Gates

Static and boundary audits must prove versioned format selection, no native
tail read-modify-write, no complete-prefix pack, at most three rows repacked per
head in the Attention hot path, exactly one logical append per token, correct
four-row publication and exact 32-row sealing.  A boundary sequence crosses
both four-row and 32-row transitions.

Control and candidate must match every logical cache row, consumed AV weight
carrier, hidden hash, selected logit code and token ID.  The independent integer
generation-head audit and EXP-0163 regression remain mandatory.  Physical gates
remain exact 8 MiB VTCM, one FastRPC per pass, no QNN, zero timed intermediate
or full-logit DDR, zero spill/fill and zero unattributed ticks.

The bounded gate uses five rotated continuous-decode pairs.  Candidate
QK-Softmax-AV and complete Host wall must both improve.  Only then may it run
ten rotated 193-step pairs.  Direct full-stack decode token/s is the formal
ranking metric.  A local pass remains pending explicit user promotion.

## Decision state

Approved and executed on 2026-09-04 under the user's standing authorization to
continue the decode optimization loop.  Source commit
`073cbd6da8a9f70f75a193298def5484787a6f83` implements the versioned V5 cache
and all experiment tooling.

The 34-step boundary run passed the four-row publication and 32-row seal
transitions.  Across five rotated 17-step pairs, all cache, hidden-state, logit,
token, 8 MiB VTCM, zero-intermediate-DDR, zero-spill and zero-unattributed-tick
checks passed.  QK-Softmax-AV improved by 19.602%, from 4482.171 to 3747.585
us/token.  However, quartet publication increased cache conversion/update from
159.883 to 604.180 us/token and append DMA from 175.856 to 198.672 us/token.
Complete decode therefore regressed from 22.839162 to 22.715331 token/s
(-0.542%) and won only three of five pairs.

The short performance gate failed, so the required ten-pair 193-step formal run
was not executed.  Evidence is valid, the local gate failed, adoption is
rejected, and no baseline changed.  The retained evidence is
`D:/llm_exp/results/qwen3-block-htp/exp0180/20260904T_exp0180_073cbd6_short`.
The result closes append-side read/convert/write publication as a useful
end-to-end path, but its exact HMX-native carrier remains an explicit enabling
parent for a distinct consumer-side publication experiment.
