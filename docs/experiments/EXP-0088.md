# EXP-0088 — Private persistent SOLE Softmax LUT banks

## Decision and motivation

The user authorized resuming the profiling-guided optimization loop on
2026-08-31. The direct source parent is the accepted EXP-0084 fair-comparison
state, not rejected EXP-0085 through EXP-0087. The current dependency-driven
W4U8 Attention path rebuilds one identical fourteen-template SOLE LUT bank in
each of its six private HVX-context scratch regions on every complete block.

EXP-0065 established that template banks preserve the exact algorithm and are
slightly faster than rebuilding two scalar LUTs per row. EXP-0073 established
that one bank shared by all contexts is slower because cross-context reads lose
locality or contend in VTCM. No prior experiment retained one independent bank
per context across Prepared Runtime Session invocations.

## Fixed contract

The Execution Unit is the real Qwen3-1.7B layer-14 complete block at M=64. The
direct control is `W4U8-EXP0084-FAIR-CANONICAL`; F16F16 and W4F16 remain
contextual PC-028 comparators. Preserve the EXP-0075 dependency stream, two
32-row Softmax slices per GQA group, six HVX contexts, paired Q heads, SOLE
template bytes and lookup rule, qparams, mask, probability bytes, QK/AV HMX
math, V packing, all projections, MLP and residuals.

The candidate reserves one aligned private 512-byte VTCM slot for each of the
six Attention HVX contexts. Each context constructs its own unchanged 448-byte
template bank during the first warmup invocation of a Prepared Runtime Session
and reuses that same private bank during subsequent measured invocations. No
bank is shared across contexts. The old per-block scratch remains private for
row and selected-LUT work. The first-use construction cost and measured reuse
counts must be reported explicitly; it may not be hidden as DDR state.

Every formal run uses one FastRPC per complete block invocation, exactly
8,388,608 acquired VTCM bytes, one serialized HMX owner, zero intermediate DDR,
zero spill/fill and no QNN. The 176 HMX commands, 49,408 U8xS8 tile pairs,
logical tensor traffic and all numerical outputs remain fixed. The additional
3,072-byte private VTCM reservation is declared in peak-plan evidence.

Attention ledger and complete Host wall at both repeat counts. Report session
