# EXP-0088 — Private persistent SOLE Softmax LUT banks

## Decision and motivation

The user authorized resuming the profiling-guided optimization loop on
2026-08-31. The direct source parent is the accepted EXP-0084 fair-comparison
state, not rejected EXP-0085 through EXP-0087. The current dependency-driven
W4U8 Attention path rebuilds one identical fourteen-template SOLE LUT bank in
each of its six private HVX-context scratch regions on every complete block.

EXP-0065 established that template banks preserve the exact algorithm and are
slightly faster than rebuilding two scalar LUTs per row. EXP-0073 established
that one bank shared by all contexts is slower because cross-context reads lose
locality or contend in VTCM. No prior experiment retained one independent bank
per context across Prepared Runtime Session invocations.

## Fixed contract

The Execution Unit is the real Qwen3-1.7B layer-14 complete block at M=64. The
direct control is `W4U8-EXP0084-FAIR-CANONICAL`; F16F16 and W4F16 remain
contextual PC-028 comparators. Preserve the EXP-0075 dependency stream, two
32-row Softmax slices per GQA group, six HVX contexts, paired Q heads, SOLE
template bytes and lookup rule, qparams, mask, probability bytes, QK/AV HMX
math, V packing, all projections, MLP and residuals.

The candidate reserves one aligned private 512-byte VTCM slot for each of the
six Attention HVX contexts. Each context constructs its own unchanged 448-byte
template bank during the first warmup invocation of a Prepared Runtime Session
and reuses that same private bank during subsequent measured invocations. No
bank is shared across contexts. The old per-block scratch remains private for
row and selected-LUT work. The first-use construction cost and measured reuse
counts must be reported explicitly; it may not be hidden as DDR state.

Every formal run uses one FastRPC per complete block invocation, exactly
8,388,608 acquired VTCM bytes, one serialized HMX owner, zero intermediate DDR,
zero spill/fill and no QNN. The 176 HMX commands, 49,408 U8xS8 tile pairs,
logical tensor traffic and all numerical outputs remain fixed. The additional
3,072-byte private VTCM reservation is declared in peak-plan evidence.

## Serial milestones

### Stage A — persistence and numerical gate

Add disabled-by-default or compact ordinary telemetry for private-bank build
and reuse counts. Prove that the control rebuilds one private bank per active
context per block, while the candidate builds six banks in the warmup call and
performs zero builds in the measured repeat-one and repeat-ten calls. Verify
that the VTCM contents survive the Prepared Runtime Session boundary and that
final output plus audited QK, probability and AV boundaries remain byte-exact
to EXP-0084 and the independent implementation reference. Stop if persistence,
correctness or the physical contract fails.

### Stage B — bounded speed gate

Run five interleaved control/candidate rounds at repeat one and repeat ten.
Advance only if ordinary and paired medians strictly improve Softmax work, the
Attention ledger and complete Host wall at both repeat counts. Report session
prepare, warmup/first-use and measured invocation costs separately.

### Stage C — formal comparison

If Stage B passes, run seven interleaved paired rounds at repeat one and repeat
ten, retain the candidate artifacts, and complete PC-027 timing-ledger closure
and the PC-028 F16F16/W4F16/W4U8 module table. A local pass remains a candidate
until the user explicitly promotes it.

## Result

Completed and rejected. The implementation is mathematically and physically
valid: ordinary warmup creates six context-local banks, repeat-one and
repeat-ten measured calls perform zero builds and respectively six and sixty
private-bank reuses, final output and audited QK/probability/AV boundaries are
byte-exact, and the run retains exact 8 MiB VTCM, zero intermediate DDR, zero
spill/fill, one HMX owner, 176 HMX commands and 49,408 U8xS8 tile pairs per
block. The candidate declares 3,072 private VTCM bytes and raises the measured
peak plan from 5,306,080 to 5,309,440 bytes.

The five-round Stage-B gate fails. At repeat one, candidate deltas are
-0.8375% Host wall, +0.5338% Attention ledger and +0.1073% Softmax work. At
repeat ten, all three ordinary medians regress: +0.0203% Host wall, +0.3634%
Attention and +0.3464% Softmax. Paired repeat-ten Attention and Softmax also
regress by +0.4940% and +0.1163%. Removing the approximately 190-tick private
bank construction therefore does not shorten the critical path; the extra
VTCM placement and ordinary scheduling variance absorb the saved local work.

Numerical audit changes the active worker identity set: four contexts build in
warmup, then the measured diagnostic uses one previously inactive context and
records one lazy build plus three reuses. This does not affect the ordinary
performance persistence contract, where all six contexts build during warmup
and no measured rebuild occurs.

Stage C was not entered. PC-027 and PC-028 are complete in

artifacts are retained under
