# EXP-0072 — Expand native W4U8 residual flow to six HVX contexts

## Parent and scope

EXP-0071 is the direct source control. Preserve its parallel Input RMSNorm,
per-GQA-group QK/AV HMX commands, integer Attention, projections, MLP, qparams,
layouts, VTCM plan, and every numerical byte. Change only how many already-
persistent HVX contexts may claim native residual row tasks.

## Hypothesis

EXP-0053 introduced sixteen four-row tasks for both the fused post-Attention
residual-RMSNorm and final residual, using the then-available main plus three
HVX contexts. EXP-0068 later expanded the persistent domain to main plus five,
but the residual helper retained its three-worker limit. Allowing all five
existing workers to claim the same tasks should shorten the two residual
critical intervals without changing task granularity or arithmetic.

## Gates

The control retains four active residual contexts. The candidate uses six.
Both execute the same sixteen tasks per residual boundary and the same Q14
residual, RMSNorm, quantization, gather, and native-layout store functions.
No worker creation, qparam, layout, projection, Attention, MLP, DMA, VTCM, or
HMX change is allowed.

Final output and audited Attention/Input-RMSNorm boundaries must remain
byte-exact to EXP-0071 and the independent implementation reference. Exactly
8 MiB VTCM, zero intermediate DDR, zero spill/fill, one FastRPC Execution
Unit, one HMX owner, six persistent contexts, and no QNN are mandatory. At
repeat one and repeat ten, the combined post-Attention and final residual
ledger plus complete Host wall must strictly improve in ordinary and paired
medians. Seven interleaved paired rounds and PC-027/PC-028 closure are
required.

## Result

The candidate reuses the five persistent workers already created for the
Attention domain and lets them, together with the main DSP context, claim the
unchanged sixteen four-row tasks at both residual boundaries. No worker,
buffer, task, arithmetic, layout, DMA, HMX, or VTCM-plan change was introduced.

The seven-round formal gate passes. At repeat one, the combined post-Attention
and final residual ledger falls from 1,238 to 970 ticks (-21.648%; paired
-20.723%) and complete Host wall falls from 2,479,948 to 2,471,198 ns
(-0.353%; paired -0.530%). At repeat ten, residual work falls from 1,232.6 to
967.6 ticks per block (-21.499%; paired -21.393%) and Host wall falls from
2,073,885.4 to 2,060,849.0 ns per block (-0.629%; paired -0.344%).

Final output, Input RMSNorm, QK, probability, and AV hashes remain byte-exact
to EXP-0071 with zero reference mismatches and zero maximum LSB error. The run
retains exactly 8 MiB VTCM, a 5,306,080-byte peak plan, zero intermediate DDR,
zero spill/fill, 176 HMX commands, 49,408 tile pairs, one FastRPC Execution
Unit, one HMX owner, and no QNN. EXP-0072 is locally eligible and becomes the
latest W4U8 candidate and provisional source parent; the user-selected W4U8
baseline remains EXP-0055 until explicit promotion.
