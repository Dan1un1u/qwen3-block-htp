# EXP-0155 — Persistent HMX-native W4U8 KV cache

## Decision and purpose

EXP-0153 and the independent EXP-0154 reproduction established that the
existing W4U8 continuous-decode path spends about 317.17 ms per 28-layer
replay repacking the complete row-major K and V prefixes into HMX carriers.
That is about 87.3 percent of W4U8 decode Host wall, while the actual QK and
AV HMX work is small. The user approved a structural cache-ABI experiment on
2026-09-02.

This experiment tests whether K and V can remain in persistent HMX-native
tiled layouts between prefill and decode. It is deliberately a one-real-layer
gate before any 28-layer integration.

## Fixed boundary

The immutable source parent is EXP-0154 commit
`21ea7dac13f6da7da3c22bb262fe5a7044ee96e9`, which is also the corrected
profiling source accepted by EXP-0153. The control is the existing W4U8
row-major-cache path. The candidate may change only the W4U8 persistent cache
ABI, append path and Attention cache consumer. Projection kernels, Softmax
math, MLP, activation or weight qparams, recipe math and the FP16 recipes may
not change.

The test unit is real Qwen3 layer 14 with M64 prefill followed by continuous
decode positions 64 through 71. The candidate cache must be explicitly
versioned. K is persisted in the signed/recentered HMX weight carrier needed
by QK; V is persisted in the signed/recentered HMX weight carrier needed by
AV. Required weight-sum or bias metadata is part of the persistent cache ABI.
The hot path may not retain a row-major duplicate.

Prefill may construct the initial tiled cache once. Each decode append must
modify only the current token lane and its current tile metadata; it may not
repack the existing prefix. Offline or non-profiled unpacking is allowed only
to compare the logical cache with the independent integer reference.

## Gates

The candidate must reproduce the independent W4U8 block output and logical K
and V cache at zero LSB after prefill and after every decode step. Decode
full-prefix K-pack and V-pack counters must be zero, and append work must be
bounded by the current physical tile rather than cache length.

The fixed physical contract remains exact 8 MiB VTCM, zero intermediate DDR,
zero spill/fill, one FastRPC invocation, one HMX owner and no QNN. Immutable
weights and the versioned persistent K/V cache are the only legal DDR
tensors.

The complete single-layer continuous-decode Host wall is the speed gate: the
candidate may not be slower than the row-major control. Any correctness,
structural, physical or speed failure stops the experiment for discussion.
Passing this gate does not authorize silent expansion to 28 layers; full-stack
integration requires a separately registered experiment.

No baseline is promoted by registration or by a local gate result.

## Result

EXP-0155 completed on source commit
`c10256023e7465dd4146d4d991326e75c9c7cb87`.  It introduced cache ABI
version 3 with separate HMX-native K-weight and V-weight carrier formats.  The
prefill call constructs the persistent carrier once; each decode call updates
only the current token's K output lane, V input lane and required bias
metadata.  The Attention consumer DMA-loads these carriers directly and does
not reconstruct either complete prefix.

An independent integer replay recomputed layer 14 from the real M64 input
through positions 64-71.  All nine block outputs and all nine logical K/V
states were exact at zero LSB.  A separately implemented Python carrier pack
then matched every device HMX-native cache byte at every step.  Both the
row-major control and candidate therefore passed output, cache, old-prefix and
carrier correctness with zero mismatch.  This audit also identified and
replaced an obsolete EXP-0148 package cache reference; no stale reference was
accepted as new truth.

The ten-round rotated device profile passed exact 8 MiB VTCM, zero
intermediate DDR, zero spill/fill, one FastRPC call, one HMX owner and no QNN.
The candidate reported zero full-prefix pack operations at every decode step.
Median single-layer decode latency fell from 13,579.710 us to 2,358.307 us,
a 5.758x speedup and 82.63 percent latency reduction.  Prefill increased from
2,450.703 us to 3,876.094 us because the initial 64-token HMX carriers must be
constructed once.  The complete prefill plus eight-decode sequence improved
from 111,134.923 us to 22,860.079 us, or 4.862x.

The local gate is `pass` and the evidence is valid.  Registration did not
authorize baseline promotion, and the candidate remains pending user adoption.
The retained formal evidence is
`D:/llm_exp/results/qwen3-block-htp/exp0155/20260902T050807Z_c10256023e74_formal`.
The independent logical reference and versioned candidate package are retained
under `D:/llm_exp/models/qwen3-block-htp/exp0155`.  Full 28-layer integration
still requires a separately registered experiment.
