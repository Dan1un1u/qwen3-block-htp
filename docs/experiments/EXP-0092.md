# EXP-0092 — Gate/Up decoder × worker interference factorial

## Decision and motivation

The user authorized continuing the autonomous profiling-guided loop on
2026-08-31. The direct source parent is the accepted EXP-0084 fair W4U8
baseline. EXP-0091 remains rejected and is not treated as a baseline.

EXP-0091 proved that two-way `vlut32` interleaving reduces aggregate MLP W4
expansion by about 5.3%, expanded-slot wait by about 11%–12% and HMX ready-wait
by about 3%. Gate/Up nevertheless regressed because HMX compute attribution
increased by about 4%–5%, indicating stronger simultaneous HVX/HMX contention.
Historical EXP-0019 found that two physical expansion workers beat three for a
pure streaming Gate/Up projection, while EXP-0040 later needed three workers
when the shared queue also consumed SwiGLU tasks. The changed decoder rate can
alter that balance, so this experiment measures the interaction rather than
assuming either old worker result transfers unchanged.

## Fixed contract

The Execution Unit is the real Qwen3-1.7B layer-14 complete block at M=64. The
four cells use the same packed W4 bytes, expanded S8 values, asymmetric-U8
qparams, projection/SwiGLU arithmetic, layouts, queue, tasks, DMA descriptors,
HMX commands and tile pairs. Only the Gate/Up decoder schedule and the number
of physical persistent pool workers dispatched to the existing Gate/Up queue
may change. Attention, O, Down, residuals and all numerical operators are
fixed.

All runs require one FastRPC, exactly 8,388,608 acquired VTCM bytes, zero
intermediate DDR and spill/fill, one HMX owner, no QNN, 25,444,352 weight bytes,
512 DMA descriptors, 176 HMX commands and 49,408 U8-by-S8 tile pairs per block.
The two-worker cells must dispatch exactly two already-created persistent pool
workers; no extra worker may spin in logical admission backoff.

## Serial milestones

### Stage A — 2 × 2 factorial gate

In one runtime-selectable binary, run five order-rotated rounds for all four
cells at repeat one and repeat ten:

1. single-vector decoder with three workers, the EXP-0084 control;
2. two-way interleaved decoder with three workers, the EXP-0091 interaction
   reference;
3. single-vector decoder with two workers;
4. two-way interleaved decoder with two workers.

Report Gate/Up, decoder expansion work, activation work, HMX compute, HMX ready
wait, expanded-slot wait and complete Host wall. A cell advances only if its
Gate/Up and Host wall both strictly improve over cell one in ordinary and
paired medians at repeat one and repeat ten. Correctness and physical gates are
mandatory for every cell.

### Stage B — confirmation and closure

Only if a unique cell passes Stage A, run seven fresh order-rotated pairs of
the EXP-0084 control and that cell. Require byte-exact final output and audited
QK, probability and AV boundaries with zero mismatch and zero maximum LSB.
Complete PC-027 and PC-028. A local pass remains a candidate until the user
explicitly promotes it.
