# EXP-0067 — Batch Input RMSNorm reciprocal square roots on HVX

## Parent and scope

EXP-0065 is the direct source control. Preserve its Attention, Q/K Norm-RoPE,
QKV/O projections, residual equations, MLP, qparams, gamma, centered-square
reduction, and native integer-HMX activation layout. Change only evaluation of
the sixty-four Input RMSNorm reciprocal square roots.

## Hypothesis

Input RMSNorm currently issues one scalar `sqrtf` and reciprocal for every
row. The centered-square reduction is already HVX, and the Q/K Norm path has
proved that `qhmath_hvx_rsqrt_vf` with the established refinement is exact at
the final U8 boundary. Staging the sixty-four positive mean-square values in
256 bytes of reusable VTCM scratch and applying two 32-lane HVX reciprocal
square-root vectors should remove the scalar chain without adding tensor
traffic or changing output bytes.

## Gates

Control and candidate must be selectable in one binary. Input RMSNorm output
and final block output must remain byte-exact to EXP-0065 and the independent
implementation reference with zero mismatches and zero maximum LSB error.
Exactly 8 MiB VTCM, zero intermediate DDR, zero spill/fill, one FastRPC
Execution Unit, one HMX owner, and no QNN are mandatory. All downstream
commands, tile pairs, traffic, qparams, layouts, and arithmetic remain
unchanged.

At repeat one and repeat ten, the Input RMSNorm ledger and complete Host wall
must strictly improve in ordinary and paired medians. Seven interleaved paired
rounds and PC-027/PC-028 closure are required.
