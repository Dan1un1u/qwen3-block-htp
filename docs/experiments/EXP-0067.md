# EXP-0067 — Batch Input RMSNorm reciprocal square roots on HVX

## Parent and scope

EXP-0065 is the direct source control. Preserve its W4U8 projections, native
activation layouts, SOLE probability LUT templates, Attention schedule,
qparams, mask, residuals, and MLP. Change only the reciprocal-square-root stage
of Input RMSNorm: replace 64 per-row scalar `sqrtf` reciprocals with two
32-lane `qhmath_hvx_rsqrt_vf` vectors after all row mean squares are available.

## Hypothesis

Input RMSNorm still performs one scalar reciprocal square root for each of the
64 rows. Batching the 64 mean-square values into two HVX vectors should remove
that scalar lane while preserving the existing centered-square reduction,
gamma multiplication, U8 requantization, and native HMX handoff byte for byte.

## Gates

Control and candidate must be selectable in one binary. Input RMSNorm carrier
bytes, final output, QK, probability, and AV boundaries must remain byte-exact
to EXP-0065 and the independent implementation reference. Exactly 8 MiB VTCM,
zero intermediate DDR, zero spill/fill, one FastRPC Execution Unit, one HMX
owner, and no QNN are mandatory. Projection, Attention, residual, and MLP
schedules may not change.

At repeat one and repeat ten, the Input RMSNorm ledger and complete Host wall
must strictly improve in ordinary and paired medians. Seven interleaved paired
rounds and PC-027/PC-028 closure are required.

## Result

The candidate is mathematically and physically valid. It replaces 64 scalar
reciprocal square roots with two HVX vectors while preserving the Input RMSNorm
carrier hash (`7255c2406108617c`), final output, QK, probability, and AV bytes
exactly, with zero reference mismatches and zero maximum LSB error. Both
variants retain exactly 8 MiB VTCM, a 5,306,080-byte peak plan, zero
intermediate DDR, zero spill/fill, one FastRPC Execution Unit, one HMX owner,
192 HMX commands, and 49,408 HMX tile pairs per block.

The local stage improves consistently but is too small to pass the block gate.
At repeat one, Input RMSNorm falls from 1,495 to 1,482 ticks (-0.870%), while
Host wall regresses from 2,675,365 to 2,676,875 ns (+0.056%). At repeat ten,
Input RMSNorm falls from 1,488.2 to 1,474.5 ticks (-0.921%) and Host wall
improves from 2,280,239.6 to 2,274,593.7 ns (-0.248%). The repeat-one complete
Host-wall gate therefore fails.

EXP-0067 is rejected for adoption. The result shows that scalar `sqrtf` is not
the dominant Input RMSNorm cost; the centered-square reduction and surrounding
native-layout work remain. EXP-0065 stays the provisional source parent and
latest W4U8 candidate. Formal evidence is retained at
`D:/llm_exp/results/qwen3-block-htp/exp0067/20260830T084346Z_afcd875adc9a_formal`.
