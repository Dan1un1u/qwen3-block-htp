# EXP-0087 — W4U8 Attention Softmax task-tail granularity

## Decision and motivation

The user approved continuing with the next profiling-guided experiment on
2026-08-31. The direct source parent is the accepted EXP-0084 fair-comparison
state, not rejected EXP-0085 or EXP-0086. Its W4U8 repeat-ten Attention ledger
is about 196 us, versus about 140 us for W4F16, and therefore remains the
largest clearly negative W4U8 module comparison.

The accepted EXP-0075 scheduler already removed global QK-to-Softmax and
Softmax-to-AV barriers. It publishes each GQA group's QK result, exposes two
32-row Softmax tasks, and publishes AV after both tasks finish. EXP-0084 uses
six HVX contexts and sixteen Softmax tasks in total. Existing formal telemetry
contains aggregate work and wait counters but not per-task completion times,
so a residual task tail is a hypothesis rather than an established fact.

## Fixed contract

The Execution Unit is the real Qwen3-1.7B layer-14 complete block at M=64.
The direct control is `W4U8-EXP0084-FAIR-CANONICAL`; F16F16 and W4F16 remain
contextual PC-028 comparators. Preserve the EXP-0075 dependency stream, paired
Q heads, exact integer Softmax algorithm, SOLE LUT contents, mask, qparams,
probability bytes, V packing, QK and AV HMX math, projections, MLP and
residuals.

Every formal run uses one FastRPC, exactly 8,388,608 acquired VTCM bytes, one
serialized HMX owner, zero intermediate DDR, zero spill/fill and no QNN. The
176 HMX commands, 49,408 U8xS8 tile pairs and all tensor traffic remain fixed.
Global Attention stage barriers, a shared LUT bank, context-count search,
QKV group-major ordering, AV affine-requant changes and HMX command-batch
changes are explicitly out of scope because prior experiments already tested
and rejected or settled those hypotheses.

## Serial milestones

### Stage A — audit-only dependency timeline

Add disabled-by-default timestamps for each GQA group's QK publication,
Softmax task claim/start/end and executing context, all-slices-ready event, AV
start/end and final pool join. Ordinary performance mode must not execute or
publish this timeline. If repeated audit runs show no Softmax task tail,
context imbalance or AV-readiness gap that finer row slices can address, stop
before changing the scheduler and discuss the negative result with the user.

### Stage B — 32-row versus 16-row micro gate

Only if Stage A passes, generalize the dependency readiness loop and compare
the existing two 32-row slices per group against four 16-row slices per group.
The candidate must keep the same row order and row implementation; only task
partition and readiness bookkeeping may change. It must remain byte-exact and
preserve every physical gate. Candidate and control run interleaved at repeat
one and repeat ten. Advancement requires strict improvement in both the
Attention ledger and complete Host wall.

### Stage C — formal comparison

If Stage B passes, run seven interleaved paired rounds at repeat one and repeat
ten. Local pass requires strict ordinary and paired median improvements in the
Attention ledger and complete Host wall, with complete PC-027 timing-ledger
closure and the PC-028 F16F16/W4F16/W4U8 module table. A local pass does not
become a Selected Baseline without explicit user promotion.

Running. No evidence or adoption decision exists yet.
