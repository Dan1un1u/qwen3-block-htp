# EXP-0076 — Fuse W4U8 AV output requantization into HMX conversion

## Parent and scope

EXP-0075 is the direct source control. Preserve its dependency-driven,
row-sliced Attention scheduler, six-context pool, paired-head QK/AV HMX
commands, Softmax arithmetic, projections, residuals, MLP, qparams, layouts,
exact 8 MiB VTCM and zero-intermediate-DDR contract.

## Hypothesis

EXP-0075 reduces the Attention critical interval, but profiling shows that the
post-HMX AV requantization sweep regresses by about eleven percent. The current
path asks HMX to write an intermediate U8 code centred at 128, then scans every
AV byte on HVX to apply the fixed AV multiplier and final output zero point. If
the same integer mapping and rounding can be represented by the existing HMX
output conversion and bias fields, HMX can write the final U8 code directly and
the separate full-carrier HVX pass can be removed.

## Gates

The candidate may change only the AV HMX output conversion/bias encoding and
remove the now-redundant post-HMX AV requantization pass. AV qparams, QK,
Softmax, mask, tensor layouts, scheduling dependencies, all projections,
residuals and MLP remain unchanged. The total remains 176 HMX commands and
49,408 tile pairs with one HMX owner and unchanged weight traffic.

The AV boundary and final output must remain byte-exact to EXP-0075 and the
independent implementation reference. If the one-stage HMX conversion cannot
reproduce the current two-stage rounding and saturation exactly, the numerical
gate fails and the experiment closes before performance adoption. Exactly
8 MiB VTCM, zero intermediate DDR, zero spill/fill, one FastRPC Execution Unit
and no QNN are mandatory. At repeat one and repeat ten, both the Attention
ledger and complete Host wall must strictly improve in ordinary and seven-round
paired medians. PC-027 and PC-028 closure are required.

## Result

Source commit `cb74da2b0c929f47f45208b1ca9919842667491b` adds a
reproducible integer analysis of the proposed conversion. The accepted
two-stage formulation reproduces the archived real layer-14 AV boundary with
zero mismatches and zero maximum LSB error. Folding the multiplier into one
affine HMX conversion changes the rounding order and differs in 19,713 of
131,072 AV bytes (15.04%), with 5 LSB maximum and 0.187 LSB mean absolute
error. Seven of eight GQA groups use multiplier nine or eleven and are not
globally representable by the proposed one-rounding conversion; only the
multiplier-one group remains exact.

The mandatory byte-exact gate therefore failed before a candidate runtime was
built or executed. Device profiling and paired speed measurements are
intentionally unavailable. Formal negative evidence is retained at
`D:/llm_exp/results/qwen3-block-htp/exp0076/20260830T113701Z_cb74da2_formal`;
the complete closure is in `EXP-0076-PROFILING.md`.

## Decision

EXP-0076 is rejected. EXP-0075 remains the latest locally eligible W4U8
candidate and provisional source parent. This result does not prohibit a
different AV quantization contract in a separately approved experiment, but
the current exact two-stage mapping cannot be deleted through one affine HMX
output conversion.
