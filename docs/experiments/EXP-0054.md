# EXP-0054 — W4U8 GQA streaming

## Decision

The user approved this experiment on 2026-08-30. It continues from EXP-0053 on `codex/exp-0054-w4u8-gqa-streaming` and targets the abnormal W4U8 Attention-front latency without changing arithmetic, qparams, weights, or the accepted MLP and residual schedules.

## Motivation

The current W4U8 path completes all Q, K, and V projections before starting the integer Attention pool. Q and K head preparation overlaps with projection, but V is repacked into the AV native operand only after the full-QKV join. This preserves correctness but serializes work that can start as soon as each V head is produced. It also prevents a GQA group from entering QK, Softmax, and AV while unrelated groups are still waiting for projection or preparation.

## Stage A — V projection to AV operand

Publish each V head when its projection tiles become ready. Persistent HVX workers recenter and transpose that head directly into the GQA group's native AV RHS carrier and prepare the associated correction bias. The Attention callback consumes this prebuilt operand and must not run a second V-pack pass.

Stage A must remain byte-exact to EXP-0053 and the independent reference, retain the fixed 8 MiB VTCM allocation, perform zero intermediate DDR traffic and zero spill/fill, use one FastRPC call and one HMX ownership domain, and introduce no QNN dependency. Because work moves between modules, the speed gate uses the combined QKV-plus-Attention interval and complete block host wall at both repeat1 and repeat10; both must strictly improve.

## Stage B — GQA-group end-to-end streaming

Stage B may start only if every Stage A gate passes. It reorders and schedules Q/K/V readiness by GQA group so that QK, Softmax, and AV for a ready group can begin without waiting for the complete QKV set. HMX remains under one serialized owner, while HVX preparation is allowed to overlap around that owner. The same correctness and physical gates apply, and both the combined QKV-plus-Attention interval and complete host wall must strictly improve over Stage A at repeat1 and repeat10.

## Closure

The final candidate requires seven interleaved paired rounds and a complete PC-027 profiling report. The closure report must begin with the stable F16F16, W4F16, and W4U8 module wall-clock table required by PC-028.

## Result

Stage A is mathematically and physically valid but fails both speed gates. At repeat 1, complete Host wall regresses by 2.080% and the combined QKV-plus-Attention interval regresses by 5.848%. At repeat 10, the corresponding regressions are 1.810% and 4.115%. The candidate reduces the isolated Attention ledger by 14.343% and 16.121%, but increases the QKV preparation join by 28.997% and 25.502% because V packing was already parallel across four Attention contexts and is now placed on the three-worker projection-preparation join tail. Stage B was therefore not executed. EXP-0054 is rejected and EXP-0053 remains the latest eligible W4U8 result.
