# EXP-0014 — Replace scalar output assembly with linked 2-D User DMA

## Approval

Approved by the user on 2026-08-27 under the continuing request to improve the
standalone Packed-W4 implementation until it provides useful acceleration.

## Objective

Remove the serial output-boundary stage that follows every projection. HMX
stores one `64 x 32` U8 output tile contiguously in VTCM. The existing DSP code
then walks all rows and output tiles with scalar `memcpy` calls to construct the
row-major DDR output. This costs about 19.9K qtimer ticks for gate/up and 6.65K
ticks for down and cannot overlap the completed HMX pipeline.

The candidate describes each tile as a 2-D User-DMA transfer with a contiguous
32-byte source row and a destination stride equal to the logical projection
width. All tile descriptors are hardware linked and launched with one
`dmstart`; the final descriptor completion is bounded by a qtimer timeout. The
candidate writes only the existing graph output and does not introduce an
intermediate DDR tensor.

## Fixed contract

The W4 controls use the best non-regressing per-shape plans established so far:
gate/up uses eight compressed, seven expanded slots and linked chain four;
down uses four compressed, eight expanded slots and contiguous batch two. The
fair Expanded-S8 controls use linked chain two for gate/up and batch one for
down. Each storage/shape pair is tested with the inherited scalar output and
the new linked 2-D DMA output. Weight storage, activation format, HMX and HVX
work, qparams, VTCM layout and 2 MiB request, clocks, power votes, and DDR graph
boundaries remain unchanged.

## Gates

All four input patterns and both shapes must remain byte-exact with the
independent Host reference. Weight DMA counts, HMX execution/stream counts, and
all pre-output pipeline counters must be identical between output modes. The
DMA output must report exactly one chain, one submission, one completion per
tile, zero timeout, and no fallback, QNN dependency, hidden DDR intermediate,
resource, power, DMA, synchronization, or device-boot failure.

Formal timing records both repeat one and repeat ten in rotated order. The
local gate requires linked 2-D output DMA to reduce repeat-one Host wall for
both W4 shapes; repeat ten must not regress either W4 shape. Expanded-S8 is
measured with the same output optimization so the final storage comparison is
fair. Output-stage ticks and descriptor counts explain the mechanism, but Host
wall latency decides the gate.
