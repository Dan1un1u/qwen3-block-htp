# EXP-0201 — Interleaved Gate/Up producer with asynchronous U8 SwiGLU

## Decision and purpose

EXP-0199 remains the strict-gate fastest pending W4U8 decode candidate at
42.314 token/s. EXP-0200 repeatedly improved median end-to-end throughput by
about 0.8–0.9% but missed the all-pairs gate. Gate/Up plus SwiGLU remains the
largest decode interval. The current implementation produces all six Gate
batches, then all six Up batches, and only afterward scans all 192 output tiles
with the U8 LUT SwiGLU kernel. This exposes the complete nonlinear pass after
HMX has gone idle.

EXP-0201 tests a producer-consumer schedule. For each 32-tile channel group it
executes Gate then Up, publishes the completed pair to one already-created HVX
worker, and immediately continues the next direct-W4 HMX group. The worker
computes the exact existing LUT SwiGLU into the final middle carrier while DMA
and HMX process later groups. The final group is joined before Down begins.

## Controlled implementation

One runtime-selectable binary compares the strict EXP-0199 control with a
candidate containing EXP-0200 O-to-Gate prefetch plus the new interleaved
Gate/Up-to-SwiGLU stream. The source may change only logical-M1 scheduling,
one persistent HVX worker job, bounded group-ready state, telemetry and
experiment tools. It must reuse the existing Gate, Up and middle carriers,
the exact LUT and the existing per-worker gather scratch contract. No new VTCM
allocation and no additional HMX owner are permitted.

Weights, scales, qparams, arithmetic, HMX tile operations, QKV, Attention, O,
residual/RMSNorm, Down, cache, LM head, M64 prefill, F16F16, W4F16 and the
no-QNN architecture remain immutable.

## Gates

Correctness requires byte-exact Gate, Up, middle, hidden, cache, selected code
and token outputs against EXP-0199. Physical evidence requires exactly 8 MiB
VTCM, zero timed intermediate DDR, zero spill/fill, one FastRPC per pass, one
HMX owner, no QNN, zero decode expansion, identical packed-W4 bytes, DMA
descriptors, HMX commands and tile pairs, six published and consumed SwiGLU
groups per layer, and observable HVX work overlapping the Gate/Up HMX lifetime.

A five-pair short gate must lower Gate/Up plus SwiGLU wall and increase complete
directly measured decode token/s. A passing candidate completes ten rotated
193-step pairs. M64 prefill is preservation-only. Adoption remains pending
explicit user promotion.
