# EXP-0098 — Generation-safe batched Down outputs

## Decision and motivation

The accepted EXP-0084 W4U8 Down projection still submits one HMX worker
command for each of its 64 output tiles. EXP-0050 already proved that command
cadence is material: combining the two ordered 96-K-tile chunks of one output
inside one generation-safe command reduced Down wall time by about 28%, while
preserving all tile arithmetic and producer overlap. No recorded experiment
has batched multiple Down output tiles inside one command.

EXP-0098 tests whether the same successful mechanism extends across adjacent
outputs. The first candidate processes two outputs per command. Each output
still begins from its own bias, accumulates its original two chunks, stores the
same U8 tile, and releases its two expanded slots immediately from inside the
HMX worker before the command advances. This in-command release is essential:
the candidate must allow HVX to produce later weights while HMX consumes the
current output, rather than pre-readying a complete batch. A four-output form
may be tested only after the two-output candidate is correct and exposes a
further command-cadence opportunity without producer serialization.

## Fixed contract

The experiment is a clean sibling of EXP-0093 and EXP-0095 and starts from the
accepted EXP-0084 source commit. Only Down HMX command cadence, request
metadata, and the expanded-slot lifetime needed by that cadence may change.
W4 values and scales, activation qparams, two 96-tile chunks, output order,
HMX tile operations, weight DMA descriptors and bytes, Gate/Up, Attention,
residuals, worker counts, and the single HMX owner remain fixed.

Every formal cell uses one FastRPC invocation per block, requests and acquires
exactly 8,388,608 VTCM bytes, has zero intermediate DDR and spill/fill, and
uses no QNN. The control has 64 Down commands and 176 total block HMX commands.
Batch two must have 32 Down commands and 144 total commands. Batch four, if
reached, must have 16 Down commands and 128 total commands. All cells retain
49,408 U8-by-S8 tile pairs, 25,444,352 weight bytes and 512 weight DMA
descriptors per block.

## Serial gates

Stage A adds audit-only timestamps and counters for per-output ready wait,
in-command expanded-slot release, producer progress and command duration. It
must prove that batch two releases both slots of each completed output before
waiting on the following output, with no pre-ready batch barrier.

The device final output plus audited middle activation and Down output must be
byte-exact to EXP-0084 and the independent reference. The physical gate must
prove the declared command reduction, unchanged tile/traffic contract, exact
full-VTCM acquisition, zero intermediate DDR, one FastRPC and one HMX owner.

Five order-rotated control/candidate rounds run at repeat one and repeat ten.
Down wall and complete Host wall must strictly improve in ordinary and paired
medians at both repeat counts. Batch four is tested only if batch two passes
correctness and does not introduce producer/expanded-slot serialization; the
best eligible candidate then receives the same formal closure. PC-027 and
PC-028 close the experiment. Baseline promotion remains a user decision.

## Result

Passed every local gate and is eligible for user adoption. The final output
and audited Input-RMSNorm, QK, probability and AV boundaries are byte-exact to
the EXP-0084 control with zero mismatches and zero maximum LSB. Both cells
request and acquire exactly 8 MiB VTCM, perform zero intermediate DDR traffic
and spill/fill, retain one FastRPC and one HMX owner, and execute the same
49,408 U8-by-S8 tile pairs, 25,444,352 weight bytes and 512 DMA descriptors.

The candidate reduces Down HMX commands from 64 to 32 and total block HMX
commands from 176 to 144. It reports 128 in-command expanded-slot releases per
block and observes producer progress inside the batched command, proving that
it did not create a whole-batch pre-ready barrier. At repeat one, Down wall
falls 26.89%; complete Host wall falls 0.40% by ordinary median and 2.71% by
paired median. At repeat ten, Down falls 25.26%; complete Host wall falls
4.08% by ordinary median and 4.14% by paired median. Down expanded-slot wait
falls about 35% and Down pipeline time about 27%, while weight traffic, DMA
descriptors and tile arithmetic remain unchanged.

The optional four-output cell was not run. Batch two already removes half of
the remaining Down command cadence while preserving producer progress; a
four-output extension is a distinct follow-up hypothesis rather than part of
this completed two-output result. EXP-0098 remains pending explicit user
adoption and does not change the selected EXP-0084 baseline by itself.
