# EXP-0213 — Deferred completion of cross-layer Q32 prefetch

## Decision and purpose

EXP-0212 proved that the next layer's first Q32 packed-W4 transfer can be
started under the current layer's final Down8 HMX command and consumed exactly
once, but synchronously completing that DMA at the end of Down merely moved
about 0.48 ms from QKV into Down. EXP-0213 changes only the completion point.

For layer transitions 0 through 26, the candidate starts the same Q32 transfer
under the final Down8 HMX command and returns from Down without waiting for the
DMA. The state remains live while final residual, next-layer metadata and
Input RMSNorm execute. The next QKV entry waits only if the transfer is still
active, validates the carrier identity, consumes it, and fetches the normal
bias. Control disables the selector in the same binary.

## Gates and decision state

Correctness requires byte-exact hidden state, cache, selected codes and tokens.
The physical contract remains exact 8 MiB VTCM, zero timed intermediate DDR,
zero spill/fill, one FastRPC, one HMX owner, no QNN, zero explicit W4
expansion, identical packed-W4 bytes, DMA descriptors, HMX commands and tile
pairs, and exactly 27 start/consume/overlap lifetimes per decode token. The
candidate must improve both QKV wall and full decode token/s in five rotated
pairs before a ten-pair formal run.

The local-win/E2E-regression streak is one at entry. If this second distinct
hypothesis again lowers the local target while reducing median E2E throughput,
the user-defined decode-loop stop gate is reached: preserve the fastest
evidence-valid implementation as the pending promotion candidate and switch to
the direct-W4 prefill loop. Approved and registered on 2026-09-05 under the
continuous loop authorization; evidence is not yet available.
