# EXP-0199 — Direct-n QKV batch-sixteen two-slot ring

## Decision and purpose

EXP-0198 is the fastest evidence-valid pending W4U8 decode candidate at
41.798 token/s. Its full decode profile leaves QKV plus Q/K preparation at
about 2.9 ms/token. The current direct-n QKV ring uses eight output tiles for
all three projections. At the real Qwen3 shapes this means eight Q groups,
four K groups and four V groups per layer. Direct packed W4 has removed
expansion, so command granularity and DMA/HMX handoff are now exposed costs.

EXP-0199 tests a uniform batch-sixteen ring for Q, K and V. This reduces each
layer from sixteen QKV HMX groups to eight without changing a single
weight, scale, qparam, output tile or HMX tile pair.

## Controlled implementation

One runtime-selectable binary compares the EXP-0198 batch-eight control with a
batch-sixteen candidate. The candidate may change only logical-M1 direct-n QKV batch
construction, the number and mapping of valid HMX-accessible ring slots,
telemetry and experiment tools. It must use two capacity-checked ping-pong
packed-W4 slots and phase-dead, aligned bias storage; arbitrary VTCM addresses
are forbidden by the EXP-0197 result.

Weights, scales, qparams, Input RMSNorm, Q/K mathematical preparation,
Attention, O, MLP, residuals, cache, LM head, M64 prefill, F16F16, W4F16 and
the no-QNN architecture remain immutable.

## Gates

Correctness requires byte-exact QKV carriers, prepared Q/K, hidden state,
cache, selected codes and tokens against batch eight. Physical evidence requires
exactly 8 MiB VTCM, zero timed intermediate DDR, zero spill/fill, one FastRPC
per pass, one HMX owner, no QNN, zero decode W4-to-S8 expansion, identical
weight bytes and HMX tile pairs, and the expected sixteen-to-eight QKV command
change per layer.

A five-pair short gate must lower QKV plus Q/K preparation wall and increase
complete directly measured decode token/s. A passing candidate completes ten
rotated 193-step pairs. M64 prefill is preservation-only. Adoption remains
pending explicit user promotion.

## Result and decision state

Completed on 2026-09-05 at source head
`aef3582fd1f4b06bf147b1f28f18ea812e541391`. The short gate passed 5/5 and
the formal gate passed 10/10. Formal decode improved from 41.760 to 42.314
token/s, or 1.33%, while QKV plus Q/K preparation fell from 2913.9 to 2602.4
us/token, or 12.0% faster.

The QKV ring correctly fell from 448 to 224 groups per token; total direct-n
commands fell by 224 and DMA descriptors by 448. HMX tile pairs, weight bytes,
all outputs and audit tensors were unchanged. The run retained exactly 8 MiB
VTCM, zero timed intermediate DDR, zero spill/fill, one FastRPC pass, one HMX
owner and zero decode expansion.

Evidence is archived under
`D:/llm_exp/results/qwen3-block-htp/exp0199/`. Evidence is valid, the local
gate passes, adoption remains pending explicit user promotion, and EXP-0200
may use this fastest pending candidate as an enabling parent.
