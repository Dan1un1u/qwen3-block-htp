# EXP-0199 — Heterogeneous direct-n Q16/KV8 ring

## Decision and purpose

EXP-0198 is the fastest evidence-valid pending W4U8 decode candidate at
41.798 token/s. Its full decode profile leaves QKV plus Q/K preparation at
about 2.9 ms/token. The current direct-n QKV ring uses eight output tiles for
all three projections: Q therefore needs eight HMX groups while K and V each
need one. Direct packed W4 has removed expansion, so command granularity and
DMA/HMX handoff are now exposed costs.

EXP-0199 tests a heterogeneous ring: Q uses sixteen output tiles per group,
while K and V retain their exact eight-tile whole-projection groups. This
reduces each layer from ten QKV HMX groups to six without changing a single
weight, scale, qparam, output tile or HMX tile pair.

## Controlled implementation

One runtime-selectable binary compares the EXP-0198 Q8/KV8 control with a
Q16/KV8 candidate. The candidate may change only logical-M1 direct-n QKV batch
construction, the number and mapping of valid HMX-accessible ring slots,
telemetry and experiment tools. It must use two capacity-checked ping-pong
packed-W4 slots and phase-dead, aligned bias storage; arbitrary VTCM addresses
are forbidden by the EXP-0197 result.

Weights, scales, qparams, Input RMSNorm, Q/K mathematical preparation,
Attention, O, MLP, residuals, cache, LM head, M64 prefill, F16F16, W4F16 and
the no-QNN architecture remain immutable.

## Gates

Correctness requires byte-exact QKV carriers, prepared Q/K, hidden state,
cache, selected codes and tokens against Q8/KV8. Physical evidence requires
exactly 8 MiB VTCM, zero timed intermediate DDR, zero spill/fill, one FastRPC
per pass, one HMX owner, no QNN, zero decode W4-to-S8 expansion, identical
weight bytes and HMX tile pairs, and the expected ten-to-six QKV command
change per layer.

A five-pair short gate must lower QKV plus Q/K preparation wall and increase
complete directly measured decode token/s. A passing candidate completes ten
rotated 193-step pairs. M64 prefill is preservation-only. Adoption remains
pending explicit user promotion.
