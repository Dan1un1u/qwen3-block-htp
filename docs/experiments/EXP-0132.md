# EXP-0132 — W4F16 Gate/Up two-region HVX expansion claims

## Decision and hypothesis

The continuing user-approved W4F16/W4U8 specialization loop authorizes this
bounded W4F16 experiment. The source branches from EXP-0129, whose three-worker
cell preserves the current EXP-0111 join-only Gate/Up behavior. EXP-0129 showed
that a fourth expansion worker lowers neither expansion latency nor HMX
readiness, and permits reopening only with a different work partition or more
expansion work per publication.

EXP-0132 keeps the main context and two pool workers, region-32, DMA8, cached
scales, batch-eight HMX commands, arithmetic, carriers, and output unchanged.
The candidate lets each pool worker atomically claim two adjacent regions and
decode the contiguous pair in one relaxed HVX call. The control claims one
region per atomic operation and call. This tests whether queue and call
granularity, rather than worker supply, is the remaining expansion overhead.

## Gates

The claim-two path is legal only for Gate/Up join-only expansion, where the
complete group is published by the existing worker join. It may not change
region size, main/pool work split, weight bytes, DMA descriptors, HMX commands,
tile work, qparams, VTCM plan, or any other block module.

Both cells must produce byte-exact output `f18b9abbe1487231`, pass expansion
audits, request exactly 8 MiB VTCM, retain zero intermediate DDR/spill, one
FastRPC Execution Unit, one HMX owner, and no QNN. The candidate passes only if
Gate/Up plus SwiGLU and complete Host wall both strictly improve in ordinary
and paired repeat-one and repeat-ten medians. Formal closure requires PC-027
and PC-028; only the user may promote a Selected Baseline.

## Result

Formal evidence is archived at
`D:/llm_exp/results/qwen3-block-htp/exp0132/20260901T013657Z_9936277a2793_formal`.
Both cells preserve output `f18b9abbe1487231`, zero expansion mismatch, exact
8 MiB VTCM, zero intermediate DDR/spill, one FastRPC unit, one HMX owner, and
identical weight, DMA, HMX, tile-work, and peak-plan counters.

The candidate fails the speed gate. At repeat one, Gate/Up regresses 1.961%
and Host wall regresses 0.524%; paired Host regresses 1.045%. At repeat ten,
Gate/Up regresses 2.039% and Host wall regresses 0.765%. Expansion elapsed
increases 9.030%, pool wait increases 676.0%, and HMX wait increases 9.374%,
even though stream-join wait falls 98.994%.

Fixed two-region claims therefore remove synchronization calls but divide ten
pool regions poorly between two workers. One worker retains a longer claim
while HMX waits for the next group, so the saved queue/call overhead is much
smaller than the induced load imbalance. The claim-one control remains
selected. Reopen only with an order-preserving balanced partition, not another
fixed multi-region claim size.
