# EXP-0191 — Direct-n decode Gate/Up batch-sixteen phase overlay

## Decision and purpose

The user authorized a continuous decode optimization loop.  EXP-0190 is the
evidence-valid fastest candidate at commit
`fb6e6617daa42e2942c762968459e1c47e382465`; it improves complete decode to
36.725 token/s by increasing direct-n Gate/Up batch size from four to eight.

EXP-0191 tests whether batch sixteen can halve the remaining Gate/Up HMX
command count from 1,344 to 672 per token.  Packed-W4 continues to use the two
decode-phase-dead Expanded-S8 buffers.  A sixteen-tile bias group fills the
existing scale/bias arena, so the second slot aliases the current layer's
input-norm gamma region only after that gamma's lifetime has ended.  The next
layer reloads its gamma before use.

## Gates

One binary compares batch eight and batch sixteen.  Only decode Gate/Up batch
and the dead bias-slot alias may change.  Weights, scales, qparams, HMX tile
pairs, projection math, row-four SwiGLU, Down, Attention, cache, LM head and
M64 prefill remain unchanged.

Correctness requires byte-exact hidden hashes, selected tokens and cache state.
Physical gates remain exactly 8 MiB VTCM, zero timed intermediate DDR, zero
spill/fill, one FastRPC, one HMX owner, no QNN, unchanged weight bytes and zero
Transformer expansion.  Five rotated short pairs must improve direct complete
decode token/s before ten formal pairs are allowed.
