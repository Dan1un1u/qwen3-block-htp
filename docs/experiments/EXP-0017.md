# EXP-0017 — Re-evaluate W4 scale placement under the latest physical plans

## Approval

Approved on 2026-08-27 by the user's continuing instruction to optimize the
standalone W4 path until it provides effective acceleration over the project's
own Expanded-S8 implementation.

## Objective

Recover more of the expected packed-W4 bandwidth benefit. EXP-0016 shows that
the latest paired W4 gate/up path is 17.85% faster than Expanded-S8 at repeat
one and 20.88% faster at repeat ten. Weight staging is substantially lower for
W4, but HMX compute attribution is about twice the S8 control because the
current candidate applies per-channel scale during HMX accumulator conversion.

EXP-0008 compared scale placement only under the old 32-K-tile publication
plan. Its HVX-prescale variant was already 1.12% faster for gate/up, but all
later coarse publication, batched/linked DMA, VTCM-ring, linked output, prepared
session, and paired-invocation improvements were developed around HMX-postscale.
This experiment repeats the scale-placement comparison using the current best
physical plan instead of assuming the old result transfers unchanged.

## Fixed contract

The primary shape is the paired gate/up projection
`M=64, K=2048, N=12288`, using one prepared-session invocation, 2 MiB VTCM,
linked 2-D output DMA, eight compressed and seven expanded slots, 64 K tiles
per HMX publication, linked-chain-four weight DMA, six HVX workers, asymmetric
U8 activation with zero point 128, signed W4 in `[-7,7]`, and the same exact
integer per-output-channel scales and Host reference as EXP-0016.

The real down projection `M=64, K=6144, N=2048` is also characterized using
its selected four-compressed/eight-expanded, 96-K-tile, contiguous-batch-two
plan. Expanded-S8, HVX-prescale packed W4, and HMX-postscale packed W4 must use
the same logical S8 carrier, stored-byte accounting, output ordering, input,
clock vote, resource lifetime, HMX tile count, and graph boundaries. Only W4
Scale Placement changes.

## Gates

All four inherited patterns and both W4 scale placements must be byte-exact
with the independent Host reference and mutually identical. There may be no
worker fallback, descriptor timeout, resource, power, DMA, synchronization,
cache, backend, or device-reboot failure. Static evidence must distinguish the
HVX multiply/pack prescale kernel from raw-nibble postscale and retain integer
HMX in both.

Formal timing uses rotated repeat-one and repeat-ten records. The local gate
passes if HVX-prescale improves the current HMX-postscale parent for at least
one projection family without changing arithmetic; the fastest valid Scale
Placement may be selected independently for paired gate/up and down. The
Expanded-S8 comparison is reported for each selected shape. HMX compute,
weight expansion, ready wait, pipeline time, and Host wall explain the result,
but Host wall decides the selection. Only the user may adopt the result or
promote a Selected Baseline.
