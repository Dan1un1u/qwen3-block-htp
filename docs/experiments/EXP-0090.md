# EXP-0090 — Gate/Up activation-priority service

## Decision and motivation

The user authorized resuming the profiling-guided loop on 2026-08-31. The
direct source parent is the accepted EXP-0084 fair W4U8 baseline. EXP-0089 is
retained as a rejected cross-phase prestage experiment and is not inherited.

Gate/Up plus SwiGLU remains the largest W4U8 module. The current persistent HVX
pool consumes one bounded FIFO containing both W4-to-S8 expansion tasks and
SwiGLU activation tasks. An activation task is published only after HMX has
completed a Gate/Up pair, then joins the tail behind already-published expansion
work. If that residence time is material, the pair slot remains occupied and
can backpressure the serialized HMX producer even though the arithmetic needed
to release it is already ready.

## Fixed contract

The Execution Unit is the real Qwen3-1.7B layer-14 complete block at M=64. The
Project Variant is W4U8 and the direct control is
`W4U8-EXP0084-FAIR-CANONICAL`. Preserve byte-identical W4 values and scales,
asymmetric-U8 qparams, projection and SwiGLU arithmetic, layouts, logical task
counts, tensor traffic, output codes, DMA descriptors, HMX commands and tile
pairs. Preserve all Attention, residual and Down behavior.

The candidate may change only how the existing Gate/Up persistent HVX pool
selects between already-ready activation and weight-expansion tasks. It may
not add workers, change HVX admission limits, create a second HMX owner, move
an intermediate to DDR, alter queue capacity, or reorder tasks within the same
class. Formal runs require one FastRPC per block, exactly 8,388,608 acquired
VTCM bytes, zero intermediate DDR and spill/fill, no QNN, 512 weight-DMA
descriptors, 176 HMX commands and 49,408 U8-by-S8 tile pairs per block.

## Serial milestones

### Stage A — audit-only queue-residency gate

On the untouched EXP-0084 control, record for every Gate/Up activation task its
enqueue and claim times, the number of older normal tasks at enqueue, aggregate
and maximum residence, activation execution work, pair-slot wait and the final
Gate/Up tail. Audit instrumentation must be disabled in ordinary performance
mode. Stop if seven runs do not show a repeatable, material activation residence
or if that residence is unrelated to pair-slot or Gate/Up tail pressure.

### Stage B — same-pool priority gate

If Stage A passes, retain one combined bounded capacity but represent activation
and normal work as two FIFO classes. A worker awakened for ready work services
the activation class first, while preserving publication order within each
class. Run five interleaved control/candidate rounds at repeat one and repeat
ten. Gate/Up and complete Host wall must strictly improve in ordinary and paired
medians at both repeats, with no material Down or Attention regression.

### Stage C — confirmation and closure

Only if Stage B passes, run seven interleaved paired confirmation rounds and
complete PC-027 and PC-028. Correctness requires byte-exact final output,
middle activation, Down output, QK, probability and AV boundaries with zero
mismatch and zero maximum LSB. A local pass remains a candidate until the user
explicitly promotes it.
