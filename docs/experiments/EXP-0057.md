# EXP-0057 — Full-width HVX vgather for V recentering

## Decision

EXP-0056 reduced Softmax work but failed its strict repeat-one complete-block gate. It is not inherited. The continuous profiling-guided loop proceeds from the accepted EXP-0055 W4U8 baseline.

## Profiling basis

The native U8 Attention path spends about 8.2k aggregate worker ticks per block in V packing. Its current recenter step loads 128 U8 values, performs 128 scalar accesses into the exact 256-entry recenter table, and then constructs the S8 HMX carrier. This is independent of the failed EXP-0054 scheduling experiment: EXP-0057 changes the kernel, not which worker or phase executes V packing.

## Hypothesis

Unpacking one 128-byte source vector into two 64-lane halfword index vectors allows the exact same 256-entry table to be read with two full-width HVX halfword `vgather` operations. This removes the per-byte scalar lookup loop while preserving every recentered S8 byte and the downstream HMX carrier.

## Candidate

Keep the selected EXP-0055 graph, scheduling, qparams, projection kernels, Softmax, AV HMX, residual, and MLP paths unchanged. Replace only the V recenter lookup implementation. The control and candidate remain selectable in the same binary.

## Gates

The final output and QK, probability, and AV audit boundaries must remain byte-exact to EXP-0055. Formal runs require exactly 8 MiB VTCM, zero intermediate DDR, zero spill/fill, one FastRPC execution unit, one HMX owner, and no QNN. Aggregate V-pack work, the additive Attention ledger, and complete Host wall must all strictly improve at repeat one and repeat ten.
