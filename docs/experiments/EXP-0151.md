# EXP-0151 — Single-buffer rpcmem_alloc2 cDSP mapping feasibility

## Decision and purpose

The user approved this bounded experiment on 2026-09-01 after EXP-0150 proved
that the legacy signed-int `rpcmem_alloc` API cannot represent the 28-layer
F16F16 weight lower bound. EXP-0151 tests the narrower factual question exposed
by Hexagon SDK 6.6: can the connected PJZ110 allocate and map one
full-stack-sized buffer through the size_t-based `rpcmem_alloc2` path?

This is a capacity and addressability probe, not a full-stack retry. It does
not generate model packages, execute transformer layers, change numerical
recipes, profile model speed, or promote a baseline.

## Fixed scope

The source parent is EXP-0150 commit
`8f46fb8534ab60ec9719021f06e5307d8c82bf05`. The Host must verify that
`rpcmem_alloc2` exists in the device FastRPC library, allocate one exactly
2,900,000,000-byte uncached buffer, obtain its one shared file descriptor and
map that descriptor into cDSP with `fastrpc_mmap(..., FASTRPC_MAP_FD)`.

One FastRPC call passes the descriptor and 32-bit byte length to a minimal DSP
probe. The DSP obtains the mapping with `HAP_mmap_get` and exchanges exact
sentinel values with the Host at aligned offsets near the beginning, middle and
end. The Host verifies all three locations, then the DSP mapping, FastRPC map
and rpcmem allocation are released in reverse order. Evidence records every
stage result, timing, requested length, offsets, device serial and boot ID.

No segmented allocation, delayed mapping, smaller fallback, Host refill, QNN,
full package generation or model execution is permitted. A missing symbol,
allocation or mapping failure, DSP addressability failure, sentinel mismatch,
disconnect or reboot immediately ends the experiment. The failure evidence is
retained and work stops for discussion with the user.

## Gates

The correctness gate requires exact bidirectional Host/DSP sentinel exchange at
all three declared offsets. The physical gate requires one
2,900,000,000-byte `rpcmem_alloc2` allocation, one fd and one contiguous cDSP
mapping on the same device boot, with no QNN dependency. There is no performance
gate; allocation, mapping, probe and release wall times are diagnostic only.

Passing EXP-0151 permits a separately registered experiment to resume the
full-stack package ABI on this proven single-buffer substrate. It does not by
itself reopen or complete EXP-0150.
