# EXP-0093 — Four-row shuffle for native W4U8 residual inputs

## Decision and motivation

The user authorized resuming the autonomous profiling-guided loop on
2026-08-31. EXP-0084 is the accepted direct source parent. EXP-0091 and
EXP-0092 proved that reducing W4 decoder work while it overlaps HMX can merely
move the bottleneck into shared HVX/HMX contention, so this experiment targets
a non-overlapped residual phase instead.

The accepted W4U8 native-output residual path reconstructs every contiguous
128-channel row vector from four 32-channel integer-HMX output tiles with one
`vgather`. A four-row residual task therefore executes four gathers per channel
group and uses the row-major destination as gather scratch before reloading it.
The physical tile layout contains four consecutive rows in each 128-byte load.
Two levels of 32-byte/64-byte `vshuff` can turn four tile loads into four
contiguous row vectors in registers and remove that gather scratch round trip.

## Fixed contract

The Execution Unit is the real Qwen3-1.7B layer-14 complete block at M=64.
EXP-0084 arithmetic, qparams, W4 bytes, layouts, task count, six-context
residual pool, projections, Attention, MLP, DMA, HMX commands and all tensor
boundaries remain fixed. The candidate may change only how a four-row residual
task loads the native integer-HMX addition tiles before the unchanged Q14
residual arithmetic. It applies to both post-Attention residual/RMSNorm and the
final residual.

Formal runs require one FastRPC, exactly 8,388,608 acquired VTCM bytes, zero
intermediate DDR and spill/fill, one HMX owner, no QNN, 25,444,352 weight bytes,
512 weight DMA descriptors, 176 HMX commands and 49,408 U8-by-S8 tile pairs per
block. Final output and audited Input-RMSNorm, QK, probability and AV boundaries
must be byte-exact to EXP-0084 and the independent reference with zero mismatch
and zero maximum LSB.

## Serial milestones

Stage A statically verifies that the candidate hot loop uses four native tile
loads and two shuffle levels without `vgather`, stack spills or a new scratch
buffer. It also runs correctness and physical-contract checks for control and
candidate.

Stage B runs five order-rotated control/candidate rounds at repeat one and
repeat ten. The combined post-Attention and final residual ledger plus complete
Host wall must strictly improve in ordinary and paired medians at both repeats.
If Stage B passes, seven fresh confirmation rounds close PC-027 and PC-028.
Otherwise the experiment stops and is rejected.
