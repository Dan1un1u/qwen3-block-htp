# EXP-0074 — Stage and row-slice paired-head W4U8 Softmax

## Parent and scope

EXP-0072 is the direct source control. Preserve its six-context residual and
Input RMSNorm schedules, Q/K preparation, per-GQA-group QK/AV HMX commands,
integer Attention arithmetic, projections, MLP, qparams, layouts, and exact
8 MiB VTCM/zero-intermediate-DDR contract.

## Hypothesis

The current Attention scheduler exposes only eight coarse GQA tasks to six
contexts. Each task owns V packing, serialized QK HMX, all 64 paired-head
Softmax rows, serialized AV HMX, and AV requantization. Two groups therefore
form a late second wave, while Softmax remains the largest Attention work item.
If QK completion, sixteen independent 32-row paired-head Softmax slices, and AV
consumption are staged explicitly, all six contexts can share the Softmax rows
more evenly and shorten the Attention tail despite the added stage barriers.

## Gates

The control is byte-identical EXP-0072. The candidate may change only
Attention task dependency granularity and use one context-local Softmax scratch
region for each of the six existing contexts. It must preserve the exact row
algorithm, SOLE LUT values, mask, qparams, QK and AV HMX tile math, 176 total
HMX commands, 49,408 tile pairs, one HMX owner, and all weight traffic.

Final output and audited QK/probability/AV boundaries must remain byte-exact to
EXP-0072 and the independent implementation reference. Exactly 8 MiB VTCM,
zero intermediate DDR, zero spill/fill, one FastRPC Execution Unit, and no QNN
are mandatory. At repeat one and repeat ten, both the Attention ledger and
complete Host wall must strictly improve in ordinary and seven-round paired
medians. PC-027 and PC-028 closure are required.

## Result

Implementation commit `57b098ec5a76e9a9062d0b536b3b81cb24d28729`
completed the staged schedule. Formal evidence is retained at
`D:/llm_exp/results/qwen3-block-htp/exp0074/20260830T111113Z_57b098ec5a76_formal`.
The final block output and audited Input RMSNorm, QK, probability and AV
boundaries are byte-exact to EXP-0072 and the independent reference, with zero
mismatches and zero maximum LSB error. The candidate executes sixteen Softmax
row tasks while preserving 176 HMX commands, 49,408 HMX tile pairs, all weight
traffic, exact 8 MiB VTCM, zero intermediate DDR, zero spill/fill, one FastRPC
Execution Unit, one HMX owner, and no QNN dependency.

The candidate consistently shortens the Attention ledger: repeat one changes
from 4,713 to 4,500 ticks (-4.52%, paired -4.75%), and repeat ten changes from
4,697.8 to 4,479.0 ticks (-4.66%, paired -4.62%). However, row slicing raises
aggregate Softmax work at repeat ten from 14,001.3 to 15,099.2 ticks (+7.84%)
and pool/queue wait from 1,055.4 to 2,467.7 ticks (+133.82%). Repeat-ten Host
wall improves from 2,073,630.2 to 2,059,317.7 ns per block (-0.69%, paired
-0.37%), but repeat-one Host wall changes from 2,488,073 to 2,490,781 ns
(+0.11%, paired +0.006%).

## Decision

The strict repeat-one and repeat-ten two-target gate fails, so EXP-0074 is
rejected and is not an eligible W4U8 source parent. EXP-0072 remains the latest
eligible W4U8 candidate and the Selected Baseline is unchanged. The positive
Attention result supports retaining row-level parallelism in a future
dependency-driven pipeline, but the three global QK/Softmax/AV barriers must
not be reused as if they were free.
