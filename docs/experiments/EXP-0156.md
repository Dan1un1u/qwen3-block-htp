# EXP-0156 — Full-stack scaling of persistent HMX-native W4U8 KV cache

## Decision and purpose

EXP-0155 proved on real Qwen3 layer 14 that a persistent HMX-native W4U8
K/V cache removes complete-prefix carrier reconstruction and reduces continuous
decode latency from 13,579.710 us to 2,358.307 us per token.  The user approved
a separate scaling gate on 2026-09-02 to determine whether that benefit survives
composition across all 28 transformer layers before selecting the next
optimization direction.

## Fixed boundary

The immutable implementation parent is EXP-0155 commit
`c10256023e7465dd4146d4d991326e75c9c7cb87`.  The experiment extends cache ABI
version 3 from one real layer to Qwen3 layers 0 through 27.  It may change only
the W4U8 package construction and the layer-count integration needed to give
every layer its own persistent HMX-native K-weight and V-weight carrier.

Projection kernels, Q/K Norm and RoPE, QK HMX, Softmax mathematics, AV HMX,
the MLP, activation and weight qparams, W4 values, schedules and the FP16
recipes remain unchanged.  The direct control uses the same EXP-0156 binary,
package, inputs, replay sequence and measurement protocol with the existing
row-major W4U8 cache format selected at runtime.

The execution unit is one real layers-0-through-27 M64 prefill followed by
continuous decode positions 64 through 71, with one FastRPC call per full-stack
step.  Per-layer ledgers are retained so cumulative 1, 3, 7, 14 and 28-layer
decode costs can be compared without introducing different binaries or partial
model inputs.

## Gates

The candidate must match the independent exact W4U8 implementation reference
at zero LSB for all nine full-stack outputs and for the logical K/V state of
all 28 layers.  Offline carrier packing must match every retained HMX-native
cache reference byte.

Every candidate decode step must report zero complete-prefix K/V pack
operations for every layer.  Incremental cache work must remain bounded by the
current physical tile rather than cache length.  The fixed physical contract is
exact 8 MiB VTCM, zero intermediate DDR, zero spill/fill, one FastRPC call per
full-stack step, one HMX owner and no QNN.

The primary speed gate is complete 28-layer continuous-decode Host wall: the
HMX-native candidate must be faster than the row-major control.  The scaling
gate additionally requires the candidate median per-token Host wall to remain
within 1.25 times the EXP-0155 single-layer linear projection
`28 * 2,358.307 us`, and the cumulative per-layer ledger at 1, 3, 7, 14 and 28
layers must show no structural reappearance of prefix packing or an unexplained
superlinear discontinuity.

Any correctness, structural, physical, speed or device-reboot failure stops the
experiment for discussion.  Passing does not promote a baseline automatically.

## Result

The experiment completed on source commit
`5cec25408a33ed5a670bc5e97761296bc874bdc3`.  All ten rotated control/candidate
pairs completed without a device reboot.  All nine full-stack outputs, all
logical K/V cache states and all retained HMX-native carrier references matched
exactly.  The physical contract also passed: exact 8 MiB VTCM, zero intermediate
DDR, zero spill/fill, one FastRPC call per stack step, one HMX owner and no QNN.
The row-major control executed 448 full-prefix packs per decode step; the
HMX-native candidate executed zero.

At 28 layers, decode latency fell from `366,219.030 us/token` to
`51,814.720 us/token`, a `7.068x` speedup and an `85.85%` latency reduction.
The candidate reached `19.300 tok/s`, which is `62.64%` faster than the unchanged
EXP-0154 W4F16 result of `84,269.479 us/token`.

The benefit remained stable as layers accumulated.  Cumulative HMX-native
decode costs for 1, 3, 7, 14 and 28 layers were respectively `1,703.968`,
`5,129.036`, `12,180.586`, `24,589.980` and `49,447.347 us`.  The corresponding
speedups over row-major were `7.620x`, `7.596x`, `7.470x`, `7.386x` and
`7.366x`.  Native cost per layer increased only from `1,703.968 us` at one layer
to `1,765.977 us` at 28 layers, with no superlinear cliff or reappearance of
prefix packing.

The current candidate is not a complete prefill improvement.  Prefill latency
rose from `53,750.625 us` to `91,917.735 us` (`+71.01%`) because it reconstructs
a second persistent cache carrier after QK and AV have already consumed
equivalent HMX carriers.  The next hypothesis is to preserve or DMA those
already-built prefill K/V carriers directly into persistent cache storage,
initializing only the unused padded tail tile.

The local gate passed and the evidence is valid.  Adoption remains pending and
no baseline was promoted.  Formal evidence is retained at
`D:/llm_exp/results/qwen3-block-htp/exp0156/20260902T054011Z_5cec25408a33_formal`.
