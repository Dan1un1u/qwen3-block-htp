F16A16 的输出和小样本质量接近 BF16，两个 A16 的重复评分逐项一致。W4A16 为 8/24；独立软件 W4F16 也为 8/24（NLL 4.250193），但 DSP/软件 top-1 仅 445/512 一致，不能宣称数值等价或把所有差异都归为量化。可读文本不能替代精度评测。

W4A8 为 0/24，分数仅为诊断：固定重复样本有 3/32 个位置的 logit 统计不一致；初始 instrumented consistency 的一次调用还出现了一个 selected-token 偏离，随后四次一致。失败原始证据保留，原因未解决，不提升为可信精度基准；未开展 W4A8 质量修复或 specialization。正常速度测试所有固定输出均一致。

完整三 recipe 质量集进程耗时 251.8 秒，快速集合计 51.5 秒，确定性复测 24.9 秒。BF16 teacher 一次缓存 47.2 秒。

三 recipe 使用同一 checkpoint/tokenizer；W4A16/W4A8 的 394 个 packed W4 权重和 FP32 scale 文件逐文件一致。评分使用真实 DSP head 的完整词表 FP16 或按实际 qparam 解码的 U8 值；无 Host 替代 head。

正式速度：一次预热、五轮 short gate 后十轮轮转，同一 M64 prompt + 15 次反馈 decode。480 次完整模型调用、13440 个 layer ledger 全部闭合；8 MiB VTCM、无中间 DDR/溢出；评分关闭。单位 μs，括号为 Host 占比。
