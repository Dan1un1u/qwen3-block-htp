# EXP-0136 — W4F16 Gate/Up four-tile streaming subgroups

## Decision and hypothesis

EXP-0135 proves that the existing four locked HVX workers plus the main DSP
context can drain the Crouton-native SwiGLU queue faster than the prior
three-worker drain. Its remaining streaming tail is scheduled as twenty-four
coarse tasks, each covering all eight output tiles produced by one unchanged
Gate/Up HMX batch-eight command.

EXP-0136 keeps the complete EXP-0135 expansion, DMA, HMX, and worker domain and
changes only the consumer task granularity. The control retains one eight-tile
SwiGLU task per HMX group. The candidate publishes two independent four-tile
SwiGLU subgroups after the same eight-tile HMX result becomes ready. Each
subgroup writes its disjoint final Down-activation Crouton positions. A
generation-safe per-HMX-group completion counter releases the producer ring
slot only after both subgroups finish.

The hypothesis is that forty-eight balanced four-tile tasks reduce the final
queue tail and main-context share enough to outweigh the extra atomic claims,
ready publications, and subgroup-completion operations. This is a consumer
granularity experiment, not an HMX batch-size or projection change.

## Gates

Both cells must produce byte-exact output `f18b9abbe1487231`, pass the existing
W4F16 expansion audit, request exact 8 MiB VTCM, retain zero intermediate DDR
and spill/fill, one FastRPC Execution Unit, one HMX owner, and no QNN. Weight
bytes, DMA descriptors, W4 expansion bytes, HMX commands, HMX tile work,
Crouton layouts, worker creation, and peak VTCM must remain identical.

The candidate may change only the Gate/Up Crouton-native SwiGLU task count from
24 eight-tile tasks to 48 four-tile tasks. Source tiles are read with the
unchanged eight-tile HMX slot stride, output tiles are disjoint, and a slot may
not be recycled before both candidate subgroups publish completion. All four
locked pool workers and the main context retain the EXP-0135 final drain.

The candidate passes only if Gate/Up plus SwiGLU and complete Host wall
strictly improve in ordinary and paired repeat-one and repeat-ten medians.
Formal closure requires the complete PC-027 report and PC-028 three-recipe
overview. A local pass remains pending user decision and cannot promote a
Selected Baseline automatically.
