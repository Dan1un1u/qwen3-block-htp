# EXP-0130 — W4U8 QKV DMA-flight main-context Q/K preparation

## Decision and hypothesis

The continuing user-approved W4F16/W4U8 specialization loop authorizes this
bounded W4U8 experiment. It branches from EXP-0124's three-expansion-worker
QKV producer/consumer ring. EXP-0124 reduced the QKV interval, but failed the
strict complete-host gate; EXP-0125 then showed that handing an expansion
worker to Q/K preparation merely moves the tail to V readiness and ring
backpressure.

The new hypothesis keeps all three expansion workers. The main thread already
owns an HVX context while it submits and waits for QKV weight DMA. During V
projection DMA-flight windows, it may execute at most one Q/K Norm+RoPE task
whose source heads are already published. This uses otherwise idle main-context
cycles without reducing V expansion capacity.

## Gates

The candidate must use a nonblocking ready-only helper: it may never claim a
task whose source generation is not yet published, may never wait inside the
helper, and may run only during V DMA-flight windows. Ring depth, the three
expansion workers, two ordinary preparation workers, HMX owner, weights, DMA
order, projection arithmetic, Q/K Norm+RoPE arithmetic and every later block
stage remain unchanged.

Both cells must be byte-exact to EXP-0124 and the independent audits, request
exactly 8 MiB VTCM, retain zero intermediate DDR/spill, one FastRPC Execution
Unit, one HMX owner, no QNN, and identical weight bytes, DMA descriptors, HMX
commands, tile pairs, qparams and peak plan. The candidate passes only if the
combined QKV plus Q/K Norm+RoPE interval and complete Host wall strictly
improve in ordinary and paired repeat-one and repeat-ten medians. Formal closure
requires PC-027 and PC-028. Only the user may promote a Selected Baseline.
