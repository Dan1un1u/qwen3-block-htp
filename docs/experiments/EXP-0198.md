# EXP-0198 — Continuous direct-n Gate-to-Up projection ring

## Decision and purpose

The user authorized an uninterrupted decode optimization loop. EXP-0196 is the
fastest evidence-valid pending W4U8 candidate at
`c8e8b7d35a1aa93f04d1685ae791853f74d4a927`, measuring 41.403837 token/s.
EXP-0197 closed wider LM-head batching after a physical HMX/VTCM failure.

The largest remaining decode interval is Gate/Up plus SwiGLU at about 7.276
ms/token, followed by Down at 4.182 ms/token and Attention at 3.574 ms/token.
Gate and Up use the same input activation and identical 2048-to-6144 physical
shape. Each currently starts and drains an independent three-group batch-32
direct-n ring. That serializes the first Up weight DMA after the final Gate HMX
tail even though the two projections can share one six-group schedule.

EXP-0198 tests a structural, not parametric, hypothesis: preserve batch 32 and
all HMX work, but carry the ping-pong ring across the Gate-to-Up boundary so the
first Up packed-W4 transfer overlaps the final Gate HMX command.

## Controlled implementation

One runtime-selectable binary compares the exact EXP-0196 independent Gate and
Up calls with a continuous Gate-to-Up ring. Both cells use direct packed W4,
the same two one-MiB HMX-accessible weight slots, the same dead-RoPE bias slots,
the same activation, output carriers and batch-32 HMX commands. The candidate
may alter only Gate/Up direct-n orchestration, boundary telemetry and experiment
tools.

Weights, scales, qparams, valid arithmetic, QKV, Attention, O, SwiGLU, Down,
residuals, cache, LM head, M64 prefill, F16F16, W4F16 and the no-QNN architecture
remain immutable.

## Gates

Correctness requires byte-exact Gate, Up, middle, hidden, cache, selected-code
and token results against the same-binary independent-call control, retaining
the existing independent integer checks. Physical evidence requires exactly 8
MiB VTCM, zero timed intermediate DDR, zero spill/fill, one FastRPC per pass,
one HMX owner, no QNN, zero decode W4-to-S8 expansion, and identical weight
bytes, DMA descriptors, HMX commands and tile pairs. Telemetry must prove one
continuous six-group sequence per layer and exactly one removed serialized
projection-start bubble per layer.

A five-pair short gate must lower Gate/Up wall and increase complete directly
measured decode token/s. A passing candidate completes ten rotated 193-step
pairs. M64 prefill is preservation-only. Adoption remains pending explicit user
promotion.
