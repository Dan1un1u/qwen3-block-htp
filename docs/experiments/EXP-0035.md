# EXP-0035 — Overlap first Q-weight prefetch with input RMSNorm

## Approval and status

Approved by the user on 2026-08-28 after EXP-0034 attributed the W4F16 QKV
regression to the first Q projection plus the Q/K Norm-RoPE join tail. The
experiment starts from EXP-0034 telemetry commit
`c39dfefdb24c1bb9670a263a6605f833653800cc`. EXP-0034 changed no runtime
schedule or mathematics and is retained only to provide the per-projection
ledger.

## Motivation

At repeat ten, W4F16 Q is 4,901.7 ticks versus 3,871.6 for F16F16, while
W4F16 K and V are respectively 277.0 and 246.1 ticks faster. W4 Q expansion
and HMX wait scale approximately linearly at twice the K projection, but Q
wall and weight-DMA lifetime contain an additional roughly 1.6 to 1.8 thousand
ticks. Q is the first projection and has no preceding call from which to
receive the packed-weight cross-prefetch already available to K and V.

EXP-0035 tests one narrow hypothesis: move the exact first packed-Q weight DMA
earlier, after block input DMA has completed but before input RMSNorm begins,
so User DMA can overlap the unchanged HVX RMSNorm. The Q projection must
consume that same prefetched data without issuing a duplicate transfer.

## Fixed contract

- The Execution Unit remains one complete real Qwen3-1.7B layer-14 block at
  `M=64`, measured at repeat one and repeat ten in one FastRPC invocation.
- Controls are the EXP-0034 F16F16 batch-four and W4F16 Gate/Up batch-four,
  DMA-8, scale-cache schedules. Q/K/V order, Q/K head readiness, GQA
  Attention, streaming MLP, all weights and scales, HMX commands, arithmetic,
  output layout, and operator implementations remain unchanged.
- The candidate may move only the first Q packed-weight transfer and its wait.
  It may not transfer additional weight bytes, add a weight-DMA descriptor,
  change bundle size, pre-expand weights in DDR, or alter later Q/K/V
  cross-prefetch behavior.
- The input tensor DMA must complete before candidate Q prefetch is launched.
  The prefetch may overlap input RMSNorm but must complete before its packed
  slot is consumed. Generation/lifetime state must prevent a previous repeat
  from being reused accidentally.
- Every configuration requests and receives exactly 8,388,608 VTCM bytes.
  Existing compressed slots are reused; peak VTCM may not increase.
  Intermediate DDR, spill/fill, extra FastRPC calls, QNN, and QAIRT are hard
  failures.
- Candidate output must remain byte-identical to the W4 control and pass the
  independent Implementation Reference. F16F16 remains an immutable paired
  comparator.

## Required telemetry

Record whether Q inbound prefetch is enabled, start and completion count,
packed bytes, descriptor count, launch-to-consume lifetime, consume-side wait,
and the input-RMSNorm overlap window. Retain the EXP-0034 Q/K/V ledger. The
candidate must report exactly one moved Q transfer per block, and aggregate
weight bytes and descriptor counts must equal the W4 control.

DMA lifetime, HVX work, HMX work, and wall intervals may overlap and may not
be summed as latency. Complete-block Host wall is primary; Q wall and
consume-side wait diagnose the mechanism.

## Selection gate

Collect one audit-on correctness run and five alternating audit-off repeat-one
and repeat-ten runs for immutable F16F16 control, immutable W4F16 control, and
the Q-inbound-prefetch candidate in one stable boot. At both repeat counts a
selected candidate must:

- reduce W4F16 Q projection wall relative to W4F16 control;
- reduce complete-block W4F16 Host wall relative to W4F16 control;
- keep the W4F16 complete block strictly faster than F16F16;
- preserve byte-identical output, exact weight bytes and descriptors, HMX
  commands, 8 MiB VTCM, zero intermediate DDR, and zero spill/fill; and
- demonstrate that the moved Q transfer was consumed once without a duplicate
  or stale-repeat reuse.

No fixed percentage target is imposed. If the candidate reduces Q wall but
does not reduce complete-block Host wall, or if DMA/HVX contention moves the
same cost into input RMSNorm, the gate fails and the schedule is rejected.
