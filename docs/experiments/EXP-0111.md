# EXP-0111 — W4F16 Gate/Up publication-fence elimination

## Decision and scope

The user authorized a continuing W4F16/W4U8 specialization loop after adopting
EXP-0110. EXP-0111 is a W4F16-only experiment derived from the accepted
EXP-0110 carrier baseline. It does not modify the Frozen Public Baseline or any
F16F16 or W4U8 runtime path.

## Hypothesis

The accepted W4F16 Gate/Up path overlaps HMX consumption of the current group
with HVX expansion of the next group. Each next group is nevertheless consumed
only after the complete expansion pool joins. Its small expansion regions do
not require individual generation publication. The current implementation
still ends every region with a full `barrier` and then stores and releases a
ready generation, before `qbh_w4f16_pool_wait` performs the actual group join
and final barrier. Gate/Up invokes this redundant sequence hundreds of times
per block.

The candidate adds a relaxed W4-to-FP16 unpack entry point only for
`publish_ready == 0`. Worker regions on that path omit the per-region full
barrier and generation publication; the existing pool join barrier remains the
single visibility boundary before the expanded group becomes an HMX operand.
All streaming paths that consume region readiness keep their existing
per-region publication contract.

## Fixed boundary and gates

The experiment may not change W4 bytes, scales, arithmetic, tensor shape,
activation or weight layout, HMX commands or tile work, DMA bytes or descriptor
count, ring depth, worker count, Attention, Down, public configurations or any
W4U8 code path. It retains exactly 8 MiB VTCM, zero intermediate DDR and
spill/fill, one FastRPC execution unit, one HMX owner and no QNN.

The candidate must be byte-exact with control at final output and preserve the
independent W4F16 expansion audit with zero mismatch and zero maximum LSB. Its
disassembly must show no per-region full barrier on the nonstreamed Gate/Up
path while the streaming publication path remains unchanged. It passes the
speed gate only if Gate/Up-plus-SwiGLU and complete Host wall both strictly
improve in ordinary and paired repeat-one and repeat-ten medians over five
rounds. Closure requires the complete PC-027 report and PC-028 overview. A
passing result remains a candidate until the user explicitly adopts it.
