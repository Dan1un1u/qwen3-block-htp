# EXP-0056 — Paired two-head U8 log2 Softmax rows

## Decision

The user promoted EXP-0055 as the selected W4U8 baseline and authorized a continuous profiling-guided optimization loop on 2026-08-30. EXP-0056 is the first compatible iteration in that loop.

## Profiling basis

At repeat ten, the selected W4U8 baseline spends about 420.9 microseconds in QK-Softmax-AV versus 140.7 microseconds for the selected W4F16 comparator. Inside the W4U8 Attention pipeline, log2 Softmax reports about 14.0k aggregate worker ticks, larger than QK HMX, AV HMX, requantization, or pipeline-wait work individually. Each causal score row contains only 64 U8 elements while one HVX vector is 128 bytes.

## Hypothesis

The two Q heads in one GQA group share row index, causal mask, probability qparams, lookup tables, and loop structure. Processing the corresponding 64-element row from both heads as one full-width HVX input can improve vector occupancy and share invariant setup. Max reduction, denominator, reciprocal, and output remain independent for each half, so no probability mass crosses heads.

## Candidate

Keep EXP-0055 projection, Q/K Norm-RoPE, QK HMX, V packing, AV HMX, O, residual, and MLP paths unchanged. Replace only the two independent per-head log2 Softmax row calls inside one GQA task with a paired-row HVX kernel. The control remains the exact EXP-0055 implementation in the same binary.

## Gates

The final output and actual QK, probability, and AV audit boundaries must remain byte-exact to EXP-0055 and the independent reference. Formal runs require exactly 8 MiB VTCM, zero intermediate DDR, zero spill/fill, one FastRPC execution unit, one HMX owner, and no QNN. Aggregate U8 Softmax work, the additive Attention ledger, and complete Host wall must all strictly improve at repeat one and repeat ten. Closure requires seven interleaved paired rounds and the complete PC-027/PC-028 reports.
