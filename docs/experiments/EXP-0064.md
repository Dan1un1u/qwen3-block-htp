# EXP-0064 — Batch QK and AV output tiles per HMX command

## Parent and scope

EXP-0063 is the direct source control. Preserve its paired full-width QK
requant-Softmax load, Q/K Norm-RoPE, V packing, qparams, mask, probability
encoding, residual equations, projection schedules, and MLP. Change only the
integer-HMX command cadence inside one GQA task.

## Hypothesis

The integer-HMX worker already accepts multiple output tiles in one command,
but Attention currently submits one command per output tile. Each Q head uses
two QK output tiles and four AV output tiles. Submitting those contiguous
weights, biases, and outputs as `n_tiles=2` and `n_tiles=4` can preserve the
exact per-tile HMX operation while eliminating 64 mutex/semaphore command
round trips per block. Attention HMX commands should fall from 96 to 32 and
total block HMX commands from 256 to 192.

## Gates

Control and candidate must be selectable in one binary. Final output and the
actual QK, probability, and AV audit boundaries must remain byte-exact to
EXP-0063 and the independent implementation reference. Exactly 8 MiB VTCM,
zero intermediate DDR, zero spill/fill, one FastRPC Execution Unit, one HMX
owner, and no QNN are mandatory. QK and AV tile counts, weights, biases,
qparams, arithmetic, and GQA task ownership remain unchanged.

At repeat one and repeat ten, combined QK+AV HMX submission time, the Attention
ledger, and complete Host wall must strictly improve in ordinary and paired
medians. Seven interleaved paired rounds and PC-027/PC-028 closure are required.
