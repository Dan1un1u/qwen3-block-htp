# EXP-0097 — Exact affine Gate/Up activation carrier

## Decision and motivation

EXP-0096 disproved that the repository's old clipped-Q7 direct helper is the
same mathematical mapping as the formal layer-14 Gate/Up LUT. It nevertheless
showed that the activation kernel itself is material: replacing four
predicated gathers with vector arithmetic reduced diagnostic activation work
by about 60%, although the invalid formula was not eligible for performance
testing.

The formal LUT has additional structure that EXP-0096 did not use. For each
fixed gate code, real SiLU(gate) is constant and the LUT varies affinely with
the centred up code before final rounding and saturation. Exhaustive search
over the exact 65,536-entry package LUT found a byte-exact representation with
one unsigned 16-bit magnitude per gate code. Gate codes 0 through 121 use a
Q15 multiplier; codes 122 through 255 use Q14. The coefficient sign follows
whether the gate code is below its exact zero point 125. The common up zero
point is 110 and the middle zero point is 102.

EXP-0097 tests whether this 512-byte coefficient representation can replace
the 128 KiB two-dimensional lookup with two halfword gathers plus HVX signed-
by-unsigned multiply, rounded shift, pack and saturation per 128 output bytes.

## Fixed contract

The experiment is a clean sibling of EXP-0093 and EXP-0095 and starts from the
accepted EXP-0084 source commit. It changes only Gate/Up activation mapping.
Weights, qparams, HMX outputs, middle bytes, Down input and output, worker
count, task cadence, projections, Attention, residuals, DMA graph and HMX
ownership remain fixed. The complete 128 KiB LUT slot remains allocated and
staged for both cells; the candidate writes the compact coefficient table into
the same slot, so no additional VTCM is allowed.

Formal runs require one FastRPC, exactly 8,388,608 acquired VTCM bytes, zero
intermediate DDR and spill/fill, one HMX owner, no QNN, 25,444,352 weight
bytes, 512 weight DMA descriptors, 176 HMX commands and 49,408 U8-by-S8 tile
pairs per block.

## Serial gates

Stage A first regenerates the coefficient table from the formal package LUT
and must prove zero mismatches and zero maximum LSB over all 65,536 Gate/Up
code pairs. Candidate disassembly must use at most two halfword `vgather`
instructions per 128 elements, contain signed-by-unsigned HVX multiply and
both Q14/Q15 rounded shifts, and have no vector stack spill.

The device final output plus audited Input-RMSNorm, QK, probability and AV
boundaries must be byte-exact to EXP-0084 and the independent reference. The
candidate must preserve the full physical contract and report all 192 compact
activation tasks. Any failure stops before formal timing.

After those gates pass, five order-rotated control/candidate rounds run at
repeat one and repeat ten. Activation work, additive Gate/Up wall and complete
Host wall must all strictly improve in ordinary and paired medians at both
repeat counts. PC-027 and PC-028 close the experiment. Baseline promotion
remains a user decision.

## Result

Rejected by the formal speed gate. The compact representation is mathematically
and physically correct: exhaustive offline validation matches all 65,536 LUT
entries exactly; both device cells are byte-exact at final output and audited
Input-RMSNorm, QK, probability and AV boundaries; the candidate preserves the
8 MiB VTCM, zero-intermediate-DDR, one-HMX-owner and unchanged physical-work
contract. Disassembly contains two halfword gathers, two signed-by-unsigned
vector multiplies, four rounded shifts and one saturated pack.

The reduced table and gather count do not reduce total HVX work. At repeat ten,
activation work rises 32.01%, Gate/Up rises 4.05%, and complete Host wall rises
1.44%; paired changes are 31.96%, 4.11% and 1.53%. HMX ready wait rises 7.58%,
expanded-slot wait 18.64%, and producer-slot wait 50.22%. The extra multiply,
dual Q14/Q15 shift and selection lengthen each activation task and hold pair
slots long enough to backpressure the producer/HMX pipeline.

EXP-0084 remains the selected baseline. Merely compressing the formal LUT is
not sufficient; reopening requires a representation that reduces total HVX
instruction and gather latency, not just table bytes.
