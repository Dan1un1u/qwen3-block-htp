## Evidence-driven hypothesis

EXP-0043 proved that two synchronous W4U8 MLP layout boundaries consume
13163.1 qtimer ticks per repeat-ten block: 6574.5 ticks pack the row-major
post-attention RMSNorm output into the integer-HMX activation layout, and
6573.5 ticks unpack Down HMX output into a row-major tensor before the final
residual. These boundaries explain 99.958% of the former gap and perform no
model arithmetic.

Stage A tests whether the unchanged post-attention residual-RMSNorm arithmetic
can store its U8 result directly into the Gate/Up HMX activation layout. Stage
B, admitted only if Stage A passes, tests whether the final residual can read
the Down HMX output layout directly and combine layout decode, residual add,
and the unchanged output requantization in one HVX traversal. The final block
output remains the existing legal row-major boundary.

## Fixed contract and gates

- The Execution Unit remains the real Qwen3 layer-14 complete block at M=64.
- EXP-0045 QKVO projection and Attention scheduling and the EXP-0040 streaming
  W4U8 MLP remain fixed except for the explicitly named MLP boundary.
- W4 values, asymmetric-U8 qparams, integer arithmetic, rounding, saturation,
  output codes, and all model semantics remain unchanged.
- One FastRPC invocation, one HMX owner, exactly 8 MiB VTCM, zero intermediate
  DDR, zero spill/fill, and no QNN path are mandatory.
- Stage A changes only the post-attention residual-RMSNorm-to-Gate/Up handoff.
  It must preserve byte-exact final output and strictly reduce both the complete
  MLP-input boundary interval and complete Host wall at repeat one and repeat
  ten. Stage B is not admitted if either speed comparison fails.
- Stage B changes only the Down-to-final-residual handoff. It must preserve the
  Stage-A result, byte-exact final output, and strictly reduce both the combined
  Down/output-boundary/final-residual interval and complete Host wall at repeat
  one and repeat ten.
- Formal conclusions use seven interleaved paired rounds. The closure report
  must satisfy PC-027 and show the complete additive ledger and overlapping
  HMX, HVX, DMA, wait, traffic, command, VTCM, correctness, and provenance
  tables for repeat one and repeat ten.

## Formal Stage A result

Stage A passed on source commit
`62c7648ee5d69acdafeb3d8577058747bc83a28e`. The post-attention
residual-RMSNorm now uses HVX word scatter to write the unchanged asymmetric-U8
codes directly into four consecutive integer-HMX activation tiles. The old
row-major-to-HMX input pack is skipped exactly once per block, while Down's
row-major output unpack remains present for the conditional Stage B.

Across seven interleaved paired rounds, the candidate preserved byte-exact
final output (`69f22eeb035e5ec5`), zero intermediate DDR read/write, zero
spill/fill, one FastRPC execution unit, one HMX owner, 1040 HMX commands per
block, 512 weight-DMA descriptors per block, and the exact 8 MiB VTCM request.
The unchanged Attention implementation audit also had zero mismatches.

At repeat one, the median MLP-input boundary fell from 53067 to 46559 qtimer
ticks (-12.264%) and complete Host wall fell from 6.955365 ms to 6.416667 ms
per block (-7.745%; paired median -8.017%). At repeat ten, the boundary fell
from 53104.9 to 46590.3 ticks (-12.267%) and Host wall fell from 6.363943 ms to
6.028479 ms per block (-5.271%; paired median -5.421%). Projection HMX, W4
expansion, waits, command counts, and output unpack remain statistically
unchanged, so the result is attributable to the removed input layout boundary.

Stage A therefore passes every correctness, physical, and speed gate. Stage B
is authorized and may change only the Down-HMX-output-to-final-residual handoff.
