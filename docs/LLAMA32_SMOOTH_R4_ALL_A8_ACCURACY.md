# L32-0014：平滑＋完整 R4 的全 A8 精度可行性

状态：完成。Down 输入静态 A8 的额外 PPL 损失已很小；现有统一 U8 残差合同仍导致全链路精度崩坏。此次为全16层软件及 SDK 整数算术模拟，真机调用0次，未新增 DSP R3/R4 内核，未运行性能测试，未更改默认 recipe 或提升任何基线。不能将结果表述为真机验证，也不能由这一失败候选推断所有 A8 方案不可行。

## 实现与数据

- 从已核验六文件哈希的原始 Llama-3.2-1B-Instruct BF16 权重重新构建，不复用旧旋转或量化权重。
- seed42 固定随机符号 Hadamard R1/R2 离线折叠。保留原始 embedding 均值；未照搬参考中并非 RMSNorm 等价变换的 embedding 去均值。FP32、TF32关闭的矩阵乘，变换后权重存储为 BF16。
- 每个 Down 输入通道以校准最大绝对激活与 Down 权重列绝对最大值计算 sqrt(a/w)，除以中位数后截断到[1/32,32]；逆缩放吸收进 Up 行，正缩放吸收进 Down 列。第二层最大缩放触及32。
- SwiGLU 后完整8192维归一化 Hadamard R4；Down 权重离线吸收逆旋转。Q/K在 RoPE 后做64维 R3。所有在线旋转都是显式稠密矩阵乘法，无蝶形/FWHT、无 SP2。
- 原始 train 的8个互不重叠512-token窗口校准，另8个互不重叠 train 窗口只作选择诊断。每窗口取前32和后续480中抽样64个位置；前缀样本相对频率权重64/480。validation不参与校准或训练。
- 8次端到端 CE 反传，收集112个 Linear 输出的梯度平方；归一化后加0.01下限形成重要性。A8范围33个粗网格＋9个细网格，最小化梯度加权的投影输出误差。每个 Linear 输入一个固定尺度，prefix=0。
- 先搜索每输出通道 W4 截断比例[.5,.6,.7,.8,.9,1,1.1]，再用实际量化输入进行 token 加权、通道统计收缩 GPTQ：1%对角阻尼，act-order，求解分块128。**求解分块不是权重分组量化**；部署权重仍每输出通道一个尺度、signed[-7,7]。
- 本次没有 gain/bias 优化更新，用固定最终权重隔离边界损失。因此不是参考软件完整最佳微调模型的复现。参考 local 文件原样只读快照，原 rotation-quant 工作树未改动。

## 数学及算术检查

16层吸收平滑和 R4 的独立向量等价性检查最大相对L2误差8.6675e-7。临时浮点 forward 修正 RoPE 计算后，与同一变换模型的 Transformers 逐层输出和 logits 完全一致。原始模型与变换后 BF16 模型的单窗口 logits 相对L2差0.019998，属于折叠/旋转后的有限精度差异；不宣称 BF16逐位等价。完整 PPL 对照见下表。

112个矩阵、973078528个 W4 编码：全部确认与软件对照权重、导出 packed W4、FP32输出通道尺度一致。SDK整数参考对113个矩阵（含 head）的抽样原始点积，与 CPU int64 计算一致。

首次不固定分块的 FP32 稠密旋转存在 batch-shape 舍入差异，导致 full80 与 cache 路径不一致；失败日志及首样本保留、不计入最终结果。固定64行稠密 GEMM（不足64行补零）后，full80 与实际 M64＋15 decode 在16个位置、全部128256词表量化 logits 上完全一致，原零误差门槛未放宽。该计算方式用于最终 SDK 整数模拟，仍不代表 DSP FP16/HMX 旋转已验证。

中间两项 BF16诊断仍保留浮点 softmax 和 BF16 head，不能称为完整 native A8。最终 SDK 参考额外使用原有整数 RMS/RoPE、log2 softmax/精确整数除法、U8 KV、HMX整数转换、定点残差、U8 embedding、W4 head及U8 logits。R3/R4只在本机用稠密FP32矩阵乘实现，输入输出合同与量化顺序明确，尚未实现于DSP。

普通 Linear 输入在此临时方案中可以有独立尺度，QKV和Gate/Up由同一 RMS 结果分别产生A8输入；这与旧优化流水的48个共享尺度不同，尚未作硬件流水迁移。SwiGLU和R4作为一个融合边界：保留Gate/Up输出U8，反量化并计算门控和R4临时累加，R4后一次性输出A8；不在R4之前插入一个会提前丢信息的额外U8量化。浮点/宽整数临时累加不等同于将残差或KV改为高精度存储。

## 数据流定位

在同一输入A8对照的首个冻结 M64 validation 窗口上，单独应用各边界的U8量化：

| 第二层位置 | 首位置RMS | 普通位置RMS | 普通位置量化后零比例 |
|---|---:|---:|---:|
| 完整R4后的Down输入 | 0.25385 | 0.01872 | 6.193% |
| Down输出 | 11.04779 | 0.07016 | 96.227% |
| 残差输出 | 11.05129 | 0.05351 | 87.643% |

平滑后的SwiGLU峰值22.875，经完整R4降至0.318359；这里比较的是同一窗口平滑后的R4前后，不是对原始模型的独立平滑消融。第二层Down输入普通位置量化NRMSE约4.185%，但后续输出/残差的跨token幅值差仍很大。Down输入的等价变换本来就应保持投影输出，因此不会自动消除真实Down输出中的首位置大信号。

后续层残差持续携带此信号，反复使用统一U8尺度会丢失普通token信息。只恢复Down输出/残差高精度的诊断将PPL降至27.8716，支持将下一步精度工作集中在残差表示及其量化合同。该诊断不代表批准了混合精度部署，也没有在本次引入前缀双尺度或动态尺度。

文本检查：输入A8浮点对照输出“The capital of France is Paris.”；完整整数参考输出“ theuparts, the time) for., more (,-- for. that in that. that, given”，不可用。PPL仍是主指标。

## 结果与限制

本次验证支持“平滑＋完整R4＋guided校准＋W4重建可以使Down输入的单尺度A8有效”，不支持“仅靠此方法就能使现有全部统一U8边界有效”。下一步应处理残差的跨token动态范围与存储/重定标合同；只继续修Down输入无法消除已测得的残差损失。

没有运行本次全2048上下文的SDK整数PPL或真机PPL，没有声称设备上R3/R4算术或速度已通过门槛。临时实现、旧SP2模式及历史正式性能基线分开保留。
